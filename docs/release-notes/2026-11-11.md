# 2026-11-11

## Hermes

- **A Hermes certificate setting written with a variable no longer breaks that connection while trocar is on.** When a
  provider's `ssl_ca_cert` in Hermes's `config.yaml` is written as `${NAME}` (or `${env:NAME}`), and NAME is set only in
  Hermes's own `.env`, trocar could not see which file it names: Hermes loads that file after it starts. trocar treated
  the setting as unset and read the connection, which Hermes then refused. trocar now passes such a connection on
  without reading it, and says which variable it could not see. A variable set in the environment Hermes starts with is
  read as before, now in both spellings.
