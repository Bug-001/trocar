## The board

- **The board opens again from browser history or a bookmark.** The page kept its key only for the tab that
  `trocar board` opened, so the same address opened later from history, a bookmark or a new tab showed
  "This page cannot read the board without its key" every time. The browser now keeps the key for the board's
  address. If the key stops working (it was replaced), the page drops it and asks you to run `trocar board` again.
