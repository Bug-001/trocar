# 2026-11-01

## The board

- **Selecting text no longer folds a row.** Dragging to select text inside an expanded row on Capture or Capture log
  closed the row on mouseup, and a plain click in the expanded part closed it too. Now a press that selects text
  (a drag, a double or triple click, Shift+click) opens and closes nothing anywhere on the board, rows open and close
  only from their head, and a click inside the expanded part leaves it open. The 5 s refresh no longer wipes a
  selection: a part of the page that holds your selection stays as drawn until you clear it, and meanwhile
  "Data read at" keeps the time of what is on screen. A refresh keeps the Technical details you opened and the
  control that had keyboard focus. Keys, links and buttons work as before.
- **The board opens again from browser history or a bookmark.** The page kept its key only for the tab that
  `trocar board` opened, so the same address opened later from history, a bookmark or a new tab showed
  "This page cannot read the board without its key" every time. The browser now keeps the key for the board's
  address. If the key stops working (it was replaced), the page drops it and asks you to run `trocar board` again.
