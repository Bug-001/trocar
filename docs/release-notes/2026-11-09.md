# 2026-11-09

## Uninstall

- **`trocar uninstall` says what it does in a few lines.**
  - The plan lists each of your files it takes trocar out of. Several files in one folder share one line, with their count.
  - Then one sentence covers what trocar deletes of its own, and one line covers what is kept and its size.
  - The receipt says it is done and what was kept.
  - Every file, key, backup and process is still printed with `trocar uninstall --details`.
  - `--json` is unchanged.
- **The uninstall question no longer says "Nothing was changed" just above itself.** An interactive `trocar uninstall` used to print "Nothing was changed. Run it with --yes to do it." right before `Proceed? [y/N]`. Now only `--dry-run` says that.
- **A refused `trocar uninstall` says why in one line, then the steps.** When capture is still on for an agent, a program may still be using trocar, or trocar's service does not answer, it says so in one line, adds "Nothing was changed.", then lists each step, in order. The full sentence is in `--details` and in the JSON `message`.

## On and off

- **`trocar on` and `trocar off` say the conclusion and what to do; `--details` prints the rest.**
  - The `on` plan is one line per agent and file of yours, with `new` on a file you have not said yes to before.
  - `off` counts the processes still passing through trocar per agent, without pids.
  - A file `off` could not undo, a fact it could not read, and a refusal stay in the default text, each with its command.
- **On macOS and Windows, `trocar on` names the agents to restart.** Processes started before capture was on are one line, as on Linux; their pids are in `--details` and the JSON `restart` key.

## All capture commands

- **`--details` on `install`, `on`, `off`, `status`, `uninstall`, `doctor` and `update`.** The short default text of each command is coming in the next changes, and `--details` will keep printing everything it leaves out. Until those land, every command but `uninstall` prints what it printed before.
