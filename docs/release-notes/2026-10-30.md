# 2026-10-30

## Command line

- **Harnesses are listed in the order of the names table.** The harness table of `trocar status`, the receipts of
  `on` and `off` when you name harnesses, and the `Known:` line of a mistyped name now list them as `claude-code,
  codex, opencode, kimi-code, deepseek-dsh, hermes, z-code`. Before, these listed `hermes` third. `trocar` and the
  standalone `trocar-off` now read the harness names from one table, so they cannot disagree.

## Capture

- **DeepSeek `dsh` is decrypted on macOS and Windows.** Every `dsh` connection through trocar was forwarded
  without capture, with `var-missing` when `NODE_EXTRA_CA_CERTS` was unset and `ca-not-in-file` when it named a
  file without the trocar root. The trocar plugin that `install` puts in `dsh` adds the trocar root inside the
  process, so trocar no longer looks at that setting to decide; it still uses the files it names to check the
  upstream's certificate.
