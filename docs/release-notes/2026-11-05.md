# 2026-11-05

## Queries

- **`trocar query` now answers cost and cache questions directly.** `trocar query overview` adds the estimated cost and
  the cache hit ratio, overall and per harness, and names the models that have no price in the table, so a total that
  leaves some calls out says which. The new `trocar query analysis --id <session>` gives one session's numbers: its
  estimated cost for the main conversation, subagents and background calls, the main conversation's cache hit and cache
  breaks with what each break cost, its failures and each step's price. Costs always use the prices in effect now, so
  editing `~/.trocar/pricing.json` moves them without reading any session again.
- **Session rows and lane steps say more.** Each row of `trocar query session` now has `cache`, the verdict on that
  call's cache, and its usage is split into tokens read from cache, written to cache, fresh and output. Each step of
  `trocar query lane` has `detail.tax`: how many characters of that step's context are tools, system prompt, history and
  the current task. The board does not show any of this yet; it looks the same as before. Answer files saved before this
  update keep their old shape, without these two fields, until the session is next read again after a version change.
