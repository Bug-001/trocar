# 2026-11-05

## Rules

- **`trocar rules` writes, tries, lists and removes rules, offline.** `rules add` checks a rule and adds it switched off,
  `rules test` runs it on captured records and sends nothing, and `rules`, `rules <name>` and `trocar query rules` say
  what each rule is and what it would cost. `rules disable`, `rules rm` and `rules off` stop rules. Every step has
  `--json`. A rule's regexes and scripts run in a separate process with Node's permission model, never in the daemon.
- **trocar now needs Node 22.13 or newer.** The permission model that keeps a rule's code away from the daemon starts
  there.
- **`trocar help rules` is the manual.** It says everything needed to write, try, list and remove a rule: every
  field, how to write a condition, the ten actions and where each one can stand, what each kind of rule makes the agent
  wait for, what a script receives and may do, and three complete examples that `trocar rules add` takes as they are.
  It opens with the warning that matters most to an agent: a hold on your own harness stops you at your next model
  call. `trocar rules enable` still refuses every rule in this version, and the manual says so.
