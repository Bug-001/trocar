# 2026-10-22

## `off` no longer lists programs that never went through trocar

- **Fewer programs "still connected" after `off`.** `trocar off claude-code` listed a Claude Desktop that was already
  running before capture was switched on, and never connected through trocar, as still connected. Such a program is
  no longer listed. A program is listed only when it started while capture was on, trocar saw it come through, or it
  re-reads its trocar setting while running (OpenCode, Z-Code) and was still running at `off`. On a machine installed by
  an older trocar the new rule arrives with `trocar update` (or `trocar install`), not with the next `on`.
- **`off` does not list programs as still trusting the certificate.** The certificate belongs to `trocar install`
  and `trocar uninstall`, so only `uninstall` reports the running programs that may still trust it until they restart.
- **Update `trocar-off`.** The standalone `~/.trocar/bin/trocar-off` carries the new rule; `trocar doctor` reports an
  older copy, and the next `trocar on` writes the new one.
