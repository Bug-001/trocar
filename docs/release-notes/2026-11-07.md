# 2026-11-07

## The board

- **After an update, the Sessions page shows the last list at once.** The list the board last showed is kept on disk,
  and an update used to set it aside, so the first open after an update waited while the list was rebuilt. The list
  from before the update is now shown at once, marked with its age, and is replaced when the new one is ready.
  Titles that list had not read yet say "Title not read yet" until then.
- Sessions made only of background calls (title generators, recaps) are hidden from the list by default; one line at
  the foot shows how many and brings them back.

## Known limits

- A session that the release before kept a replay page for, and that this release groups differently, shows that
  old page until the background cleanup removes it: the page is served as it was written and carries no check of
  which release wrote it.
