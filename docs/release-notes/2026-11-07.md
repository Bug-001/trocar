## Uninstall

- **`trocar uninstall` seals the records the collector was still writing.** The collector seals each full file of
  records as it goes, but the one it was writing when it stopped was left for its next start, and after an uninstall
  there is none: up to 128 MB stayed unsealed for good. The collector now seals that file before it exits, and
  `uninstall` waits while it reports progress (`sealing <segment>: n of m MB`). The receipt says
  `Sealed <segment> (n MB → m MB)`, or that the file stays unsealed until trocar runs again when the seal could not
  finish. `--purge-data` seals nothing, because the records are deleted afterwards.
