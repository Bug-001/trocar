# 2026-11-08

## On

- **`trocar on` keeps the hosts you bypass in your Windows user environment out of trocar.** `on` writes a `NO_PROXY`
  beside the proxy it sets: the local hosts, then the bypass list already in that file. It was meant to add the
  `NO_PROXY` set in your user or machine environment (System Properties › Environment Variables) as well, but did
  not read it, so traffic to those hosts went through trocar. It reads it now.
