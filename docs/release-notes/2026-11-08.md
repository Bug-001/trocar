# 2026-11-08

## Off

- **`trocar off` says a file you put back by hand is as it was.** When trocar had written two things into one file (VS
  Code's settings get a proxy key and an item in `settingsSync.ignoredSettings`) and you put the file back to how it
  was before `trocar on`, `off` said the file "is not what it was before" and kept a backup of it, while also saying it
  was already as it was. Every entry in such a file now counts as already undone, and its backup is removed.
