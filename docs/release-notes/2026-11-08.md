# 2026-11-08

## Off

- **`off` without an install record also takes out what `on` wrote next to the proxy setting.** On macOS and Windows,
  `on` also writes a bypass list next to Claude Code's proxy setting (`env.NO_PROXY`, `env.no_proxy` in `settings.json`), and
  adds `http.proxy` to VS Code's `settingsSync.ignoredSettings`. With the install record gone, `off` removed the proxy
  setting but left these in place, so a `settings.json` that `on` had created stayed behind holding only the bypass list.
  `off` now removes each one that holds exactly what `on` writes, and puts back your own value from trocar's backup of
  the file. A `settingsSync.ignoredSettings` entry you had before `on` stays. If you changed one of them after `on`, or
  trocar cannot read its backup, `off` leaves it and the receipt names it. A file left holding only `{}` is not deleted,
  and the receipt names it.
