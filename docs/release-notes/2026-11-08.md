# 2026-11-08

## Status

- **`trocar status` draws the Claude desktop app's route as it goes while its proxy settings address is refused.** When
  the app's setting still holds trocar's proxy settings (PAC) address from before this install's key, trocar refuses
  the app's request for it, and the app connects directly. The Routes block drew it through trocar; versions before the
  key drew it through your system proxy. It now draws it direct, marked inferred, and `status --json` gives that form
  `entry_intact: false` and `connected: false`, as the summary already said it was not captured. The board's
  technical details mark that hop inferred too: a hop is marked when the edge that reaches it is inferred, as
  `trocar status` already did.

## Install

- **`trocar install` says a plug-in or a setting it found already in place is intact.** Run again, install leaves alone a
  file that already holds what it would write; it changed no byte, but its receipt said "trocar's plug-in, placed"
  for DeepSeek dsh and pi (and the same for a config key), as if it had written them again. Those now say intact, as
  Kimi's launch command already did; a carrier is placed only when install wrote one of its parts.

## Off

- **`trocar off` says a file you put back by hand is as it was.** When trocar had written two things into one file (VS
  Code's settings get a proxy key and an item in `settingsSync.ignoredSettings`) and you put the file back to how it
  was before trocar wrote them, `off` said the file "is not what it was before" and kept a backup of it, while also
  saying it was already as it was. Every entry in such a file now counts as already undone, and their backups are
  removed. A backup that holds an edit you made between trocar's writes is still kept.
