# 2026-11-08

## Off

- **`trocar off` no longer notes a fallback when no collector is running.** `off` asks the collector for the process
  table and, when it cannot answer, reads it itself and says so. With no collector running there is nothing to ask:
  reading the table itself is the normal way, so `off` no longer notes it, as `trocar status` already did. When a
  running collector cannot answer, the note is still there.
