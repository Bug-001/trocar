# 2026-11-04

## The board

- **A title still being read says so.** Right after the board starts, the session list and the Overview's recent
  sessions showed "Untitled session" for sessions whose title had not been read yet, and real titles only on the next
  refresh. Those rows now show "Title not read yet" in muted text until the title arrives; "Untitled session" is kept
  for sessions that have no title. `trocar query sessions` gives such a row `title_source: "pending"`.
- **A replay you leave stops reading.** Leaving the replay right after moving to another step could still send that
  step's read a moment later. The step's reads now wait until you come back.

## Install and uninstall

- **The install plan names every file of the undo.** It named `~/.trocar/bin/trocar-off` alone, as "the undo that
  works without this source tree". On Windows install also writes `trocar-off.cmd` beside it, and a script install has
  no source tree. The plan now names each file, as "the undo that works even when trocar itself is broken".
- **The plan says what install leaves alone.** When an agent's certificate setting already names a file of yours, or
  names a file that is not yours, install leaves it as it is and records that. The plan now lists these under
  "Left as they are:", with the reason. A Set up from the board no longer lists a certificate block that is already in place.
- **A setting naming trocar's own file in another letter case is trocar's.** On Windows and macOS such a setting was
  read as your own file, and install added a certificate block to trocar's own bundle.
- **The uninstall receipt reads the same on Windows.** Directories end in `\` instead of `/`, and a file trocar
  created for its setting says what was taken out before saying the file is gone.
