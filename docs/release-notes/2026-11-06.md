# 2026-11-06

## Capture

- **trocar no longer keeps the password of its local proxy in the install record or in backups.** The install record
  now holds that password only as a fingerprint, so the record, and the backups made from your files, no longer
  carry a credential. One `on` writes each settings file once and keeps one backup of it, with your bytes from before
  trocar changed it. Backups made by an older trocar can still hold the password: `trocar doctor` names each one, and
  you can remove it.
- **A `NO_PROXY` of your own is no longer taken for your proxy.** With a `NO_PROXY` in the settings `trocar on`
  writes to (Claude Code's `settings.json`, for one) and no proxy of your own, trocar read that bypass list as the
  proxy to chain through, so the agent's requests failed where they went direct before. Trocar now takes only the
  proxy setting you had, and `trocar status` shows the upstream as direct.
