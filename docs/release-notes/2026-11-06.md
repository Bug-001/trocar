# 2026-11-06

## Off and uninstall

- **`trocar off` and `trocar uninstall` delete a file trocar created only if it still holds what trocar wrote.** A plugin,
  launch script or switch file that has changed since trocar wrote it, or that cannot be read, now stays where it is.
  The receipt lists it under what was left, with the reason, and the next run checks it again. Before, these files
  were deleted whatever they held. The program trocar moved aside for a wrapper follows the same rule.
