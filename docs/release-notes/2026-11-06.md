# 2026-11-06

## Turning capture on

- **`trocar on claude-code` on Windows sees a proxy your organisation set in Claude Code's managed settings again.**
  Claude Code 2.1.75 and later read managed settings only from `C:\Program Files\ClaudeCode`, and trocar looked only in
  `C:\ProgramData\ClaudeCode`, where older versions read them. trocar now checks both places. When either one sets
  `HTTPS_PROXY`, `on` leaves the Claude Code CLI and VS Code forms alone and `status` names the file, because a managed
  setting overrides trocar's entry.
