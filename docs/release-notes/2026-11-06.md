# 2026-11-06

## Status and doctor

- **Claude Desktop's own sign-in, update and download hosts are reported as forwarded by design.** `status` and
  `doctor` used to say that this form of Claude Code is not verified yet whenever the app talked to one of these
  hosts, which read as if nothing from the desktop app was decrypted. These connections now carry their own reason,
  `forward-only-host`, counted as expected; `not-verified` is left for forms that are not verified.
