# 2026-11-06

## Capture

- **Claude Desktop's connections to hosts on your proxy bypass list are no longer decrypted.** The proxy settings file
  trocar gives Desktop sends a bypass-list host through trocar first and direct only when trocar does not answer, so
  once the connection reached trocar it was decrypted like any other. An internal host that asks for a client
  certificate, or whose handshake fails through trocar's certificate, then had no way to connect. trocar now passes
  these connections on unread, straight to the host, and counts them on the board as connections to hosts on your
  bypass list. Hosts off the list, and the other agents, are captured as before.
