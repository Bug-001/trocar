# 2026-11-06

## macOS

- **On a case-sensitive volume, two agent files whose names differ only in case stay two files.** trocar compared
  every path on macOS without regard to case, so on a case-sensitive APFS volume it could take `Settings.json` for
  `settings.json` when it recorded, backed up or restored an entry. It now asks the volume: paths still match
  regardless of case on a case-insensitive volume, the default, and keep their case on a case-sensitive one.
