# 2026-11-06

## The command line

- **An `install` that cannot use the key store changes nothing.** On macOS without a login keychain (or on Windows when
  the key store cannot be used), `trocar install` stops before it writes anything: it no longer leaves `trocar-off`,
  an install record or a login entry behind. The exit code and the `key-custody-failed` error are as before.
