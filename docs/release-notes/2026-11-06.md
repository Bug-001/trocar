# 2026-11-06

## Capture

- **The collector's doors open sooner after login.** The engine used to read the OS trust store before its doors
  accepted a connection, a large part of its start-up. It now reads the store when the first connection that has to
  verify an upstream arrives, and keeps that set from then on. On macOS and Windows most connections verify against
  the agent's own set, so the store is often never read. Starting the engine and opening a door went from about
  35 ms to about 6 ms on a test Mac. A trust store that cannot be read is still recorded, with the same code, when
  the store is read.
