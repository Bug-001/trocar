# 2026-11-06

- **`trocar install` no longer writes over a file that is not trocar's.** When a plugin or extension trocar places
  was already at its path and trocar had no record of it, install wrote over it without a backup and recorded it as
  trocar's own. Now a file there is written over only when it carries trocar's mark (or sits in a folder of trocar's own under `~/.trocar/collector`);
  otherwise, or when it cannot be read, that carrier is skipped, the file is left byte for byte, the receipt names the
  path and why (code `not-trocars-file`, also in the plan before you confirm), and the run exits 1. The other carriers
  are installed. The pi and DeepSeek plugins now carry that mark too, so an existing pi or DeepSeek install rewrites
  those two plugin files once, on the next `trocar install`. An older one with neither the mark nor a record is
  skipped too, since trocar cannot tell it is its own: move it away or delete it, then run `trocar install`.
- **`trocar install` replaces a login entry under trocar's name that it has no record of** (the LaunchAgent plist, the
  Windows scheduled task, the Linux unit) instead of stopping: the plan says it replaces it, and the bytes that were there are kept in
  `~/.trocar/backup/` first.
