## The command line

- **`trocar on` names a file it cannot read in words.** When a file trocar installed for an agent (pi's extension,
  say) cannot be read, the note names the file and says it is not allowed to read, instead of Node's error message;
  `--json` keeps the error code in the note's `code`.
- **File errors read in plain words across `trocar on` and `trocar install`.** A file trocar could not read or write
  (an agent's settings file in a read-only folder, a certificate file it cannot open) is named with what went wrong:
  "not allowed to read", "not allowed to write", "not there". Node's error text is no longer printed; where the
  receipt has a `code`, it keeps the error code. A denied file on Windows reads the same as on macOS.
