## Uninstall

- **macOS `uninstall` names the launchd entry it cannot remove.** After `uninstall`, `launchctl print-disabled`
  still lists `"com.trocar.collector" => enabled`: `launchctl` has no command that removes it. The receipt now says so
  in a note, and the README's Uninstall section explains it. The entry is harmless: with no LaunchAgent file, it
  starts nothing.
