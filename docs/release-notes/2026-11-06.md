# 2026-11-06

## Capture

- **The OpenCode desktop app's main window process is no longer taken for OpenCode.** On macOS and Windows the app's own
  `OpenCode` process (on Windows also its helpers) is named like the CLI, but it only talks to the `opencode-cli serve` process it starts, which
  makes every model call. trocar now counts only that `opencode-cli` process as the desktop app, so `trocar status`
  no longer lists the window process as an OpenCode that is not seen or needs a restart, and after `trocar off` it is
  no longer one of the processes that keep trocar's door open. The OpenCode CLI is recognised as before.
