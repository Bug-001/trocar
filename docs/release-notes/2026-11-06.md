# 2026-11-06

## Capture

- **A host that cannot be reached is no longer a silent wait.** When an agent connects through trocar's door, its own
  connect timeout has already finished, because its connection to the door is up. A host that does not answer then
  holds the agent until the system gives up on the connection, about 75 s on macOS, and nothing said why. trocar now
  writes `upstream-slow` with `phase: connect` once the connection has taken more than 5 s, whether it is going to the
  host or to your own proxy. trocar still sets no limit on this wait and does not cut the connection.
