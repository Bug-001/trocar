# 2026-11-06

## Records

- **A compressed reply keeps its wire bytes.** When a reply arrives compressed, the record now holds the compressed
  bytes as they were on the wire beside the decompressed text. An older record of a compressed reply says in place
  that only the decompressed text is stored. In the request detail, a body shown decompressed, request or reply, is
  captioned "decompressed from <coding>" instead of "verbatim".
