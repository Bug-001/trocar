# 2026-11-06

## CLI

- **`trocar status | head` no longer crashes.** When the program reading trocar's output stopped early (`head`, `less`
  quit before the end, a closed pipe), trocar threw a `write EPIPE` error with a stack trace, possibly halfway through
  a command. The output that has no reader is now dropped, and the command finishes with its own exit code.
