# 2026-11-06

## Capture

- **`trocar status` no longer calls a process captured just because it started after `trocar on`, when its config
  place depends on an environment variable.** Codex reads `.env` under `CODEX_HOME`, so a Codex started with another
  `CODEX_HOME` than the one `trocar on` ran with reads a file without trocar's entry and is not captured. macOS and
  Windows do not show another process's environment, so such a process now reads "not seen yet" until its first model
  call, when trocar judges it at the door. An agent whose config place depends on no variable is judged as before.
