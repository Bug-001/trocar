# 2026-11-06

## Capture

- **Plain http from programs Claude Code starts is captured too.** `trocar on claude-code` set only `HTTPS_PROXY` in
  Claude Code's settings, so a tool or helper it started sent plain `http://` requests straight out. It now sets
  `HTTP_PROXY` as well, in both spellings, and `trocar off` takes it out again. A value of your own goes back as it
  was.
