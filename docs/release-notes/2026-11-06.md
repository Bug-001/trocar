# 2026-11-06

## Capture

- **`trocar status` no longer calls a process captured just because it started after `trocar on`, when its config
  place can be moved by an environment variable.** This affects Claude Code (`CLAUDE_CONFIG_DIR`), Codex
  (`CODEX_HOME`), OpenCode (`XDG_CONFIG_HOME`) and Hermes (`HERMES_HOME`): a process started with another value than
  the one `trocar on` ran with reads a file without trocar's entry. On macOS / Windows, which do not show another
  process's environment, these read "not seen yet" until their first model call, after which the door's verdict
  shows. Agents whose config place no variable moves are judged as before.
