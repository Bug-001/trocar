# 2026-11-06

## The board

- **The capture state's lamp now means the same thing everywhere.** "Capture has problems" lit the red lamp meant for a
  stopped service, and states that only say the board does not know (unreadable, unknown, not refreshed) lit an amber
  one. Now a stopped or silent service is red, problems and leftover changes are amber, capturing shows the green dot,
  and the not-known states show only the grey unlit dot, on the overview card and on the capture page alike.
- **A host's request list names every column.** The marks column (log only, length only, failed) is headed **Notes**,
  and each row's words sit on one line.
- **A tab showing "open the board with trocar board" reopens when you paste the link it prints into that tab.** It used
  to stay on that page until you refreshed it.
- **Following a session shows the newest step at once.** While following, the desk waited for the newest step's reply
  text before drawing that step, so the step number and the window stayed on the old step for as long as the text took
  to come: seconds right after a session was read for the first time, when it could read "1 / 1" while the session
  already held hundreds of steps. The desk now draws the new step within 150 ms of its arrival, and its reply text
  fills in when it comes, with no second read and no jump of the window.
