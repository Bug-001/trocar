# 2026-11-06

- **`trocar install` no longer writes over a file that is not trocar's.** When a plugin or extension trocar places
  was already at its path and trocar had no record of it, install wrote over it without a backup and recorded it as
  trocar's own. Now a file there is written over only when it carries trocar's mark (or sits in a folder of trocar's own under `~/.trocar/collector`);
  otherwise, or when it cannot be read, that carrier is skipped, the file is left byte for byte, the receipt names the
  path and why (code `not-trocars-file`, also in the plan before you confirm), and the run exits 1. The other carriers
  are installed. The pi and DeepSeek plugins now carry that mark too, so an existing pi or DeepSeek install rewrites
  those two plugin files once, on the next `trocar install`.
- **`trocar install` replaces a login entry under trocar's name that it has no record of** (the LaunchAgent plist, the
  Linux unit) instead of stopping: the plan says it replaces it, and the bytes that were there are kept in
  `~/.trocar/backup/` first.
- **`trocar install` names every file that still holds trocar's text from an install whose record is gone.** It used
  to fail with a generic `failed` code and name only the first such file. On Linux it now refuses with
  `error.code: "marked-without-record"`, lists each file in `problems`, and gives the way out in `error.command`:
  `trocar uninstall`, which takes that text out by trocar's own marks; then run `trocar install` again. Nothing is
  changed. `trocar on` refuses the same way. On macOS and Windows the carrier in such a file is skipped with the same code.
- **`trocar uninstall` also takes out trocar's marked text that its install record does not list**, at the places
  trocar knows for each agent, putting old values back from `~/.trocar/backup/`; the receipt lists each such file. One
  `trocar uninstall` now clears every file `trocar install` names in that refusal. `trocar uninstall --dry-run`, and the
  plan shown before you confirm, list those files too.
