# 2026-10-17

- macOS: an agent's connection is no longer left uncaptured when the machine is busy. The collector used to look up which process opened each
  connection with `lsof` against a 250 ms limit, and a slower answer made it forward that connection without capturing it — on a busy Mac a whole
  OpenCode session was lost that way. It now reads the kernel's TCP table (`netstat -anv -p tcp`, about 10 ms) and waits for the answer.
