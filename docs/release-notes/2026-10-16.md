# 2026-10-16

- `asight install` is its own command (D55): it installs the certificates once — on macOS / Windows a root made on this machine whose
  private key cannot be exported, put in your user root store (one OS prompt), and the certificate carriers each installed agent form reads; on
  Linux the collector CA and its trust entries. It prints the plan and asks first (`--yes`, `--dry-run`, `--json`). `asight collector install`
  now means `asight install`; plain `asight install` is no longer an alias of `asight on`.
- macOS / Windows: `asight uninstall` refuses while capture is on, or while a process started during an on window may still use a door; it names
  them and changes nothing — run `asight off` first. Offline, it undoes install in reverse and removes the root's key last.
