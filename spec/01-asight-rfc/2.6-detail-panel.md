# asight · RFC 2.6 — 原始数据面板 · 调用抽屉 · 请求详情

> **服务意图(A2)**:意图 ①(看懂 agent 行为)为主——给「回放骨([2.3](2.3-context-window.md))之外」的三样东西各一个宿主:*当前这一步的原始线上事实*(右页下部的原始数据面板:模型的回复、能回源的原始回复字节、请求参数、线格式、采集对客户端的影响)、*主对话之外的每一次调用*(调用抽屉)、*一条请求的头与逐字体*(请求详情部件,流量的 host 页用它);兼意图 ②(原始回复字节是步头「缓存」按钮里那四个用量数的回源处,数在 [2.2](2.2-call-turn-card.md),字节在这里)。
> **受众**:人(在骨之外深看某一步的原始回复与请求参数 / 某一次子 agent 或后台调用 / 流量里的一条请求);agent(据 `/api/session` 的 `steps[]` 与 `lanes[]`、`/api/block`、[4.4](4.4-server.md) `calls --ref` 渲染,**不碰 provider/harness 分支**)。
> **前置**:数据 = `/api/session`(源 NDJSON 装配,D24)的 `steps[]`(`norm`、`respRefs`、`nonBlockKeys`、`extraMessages`、`wire`、`error` / `errMsg` / `status`、`unparsed`、`paged_out`)与 `lanes[]`、`probes`;字节回源 = `/api/block`;单条请求 = [4.4](4.4-server.md) `calls --ref`;渲染宿主 = [1.2](1.2-shell-layout.md) 右页下部(`#rawpanel`)+ 视口底缘的调用抽屉(`#detail`);viewPin 的**内容与切换动作**由 [2.4](2.4-resource-explorer.md) 驱动、本模块只做**宿主 + 关闭/复位契约**;调用抽屉由 [2.1](2.1-track-widget.md) / [1.3](1.3-timeline-tracks.md) 的 tick 与 [1.2](1.2-shell-layout.md) 的 `call=` 路由打开,卡里写什么归 [2.2](2.2-call-turn-card.md) 调用详情卡;lane 种类的词归 [2.1](2.1-track-widget.md);块的保真标(证明规则)、调用保真行、未下发态归 [2.3](2.3-context-window.md);请求详情的宿主是 [1.10](1.10-traffic.md) 的 host 页;凭据的存储处置权威在 [4.1](4.1-capture-sources.md) §凭据处置;词与标记归 [1.5](1.5-states-aesthetics.md)。旧看板 `src/web/index.html` 的 `renderRawPanel` / `openDetail` / `renderControlView` 第一期照旧,第二期随文件删除(D18c;两期替换是)。

## Goal
给「忠实回放骨(2.3)+ 步头(2.2)」之外的三类观测一个统一宿主,MUST 不撕裂主线、不往通用视图塞 provider 分支(守卫:`test/web-v2/no-provider-branches.test.mjs`、`test/web-v2/harness-seam.test.mjs`):
1. **原始数据面板(`#rawpanel`)**:随播放头显示**当前这一步(主对话)的原始线上事实**——模型的回复(解析后的文本、工具调用、停止原因)与能回源的原始回复字节、请求里不属于上下文块的参数、调用打开期间客户端又发的消息、线格式与传输、采集对客户端的影响;并作为 [2.4](2.4-resource-explorer.md) 钉住一个资源时的**切换宿主**(viewPin)。用量的四个数与估价不在这里,在步头([2.2](2.2-call-turn-card.md))。
2. **调用抽屉(`#detail`)**:从视口底缘滑起,**深看主对话之外的一次调用**——子 agent、后台调用(安全审查、通知摘要、生成标题、保活检查、预热请求……)或一次 token 计数;卡的内容是 [2.2](2.2-call-turn-card.md) 的调用详情卡,输入逐块回源。
3. **请求详情部件**:一条请求(任何类别,模型调用也算)的请求行、头、逐字体、每侧的保真标注与凭据类头的遮挡;[1.10](1.10-traffic.md) 的 host 页用它,经 `calls --ref` 按需取单条。

## 前置定义(Definitions)
- **原始数据面板**:右页下部常驻面板,显示播放头所在**主对话这一步**能回源的原始事实。它和步头([2.2](2.2-call-turn-card.md))同指一步、不同 surface:步头给数(用量、估价、缓存判定、组成),面板给字节(回复、参数、线格式)。面板头写「原始数据 · 第 N 步」,N 按 [1.2](1.2-shell-layout.md) §编号。
- **viewPin(资源钉住态)**:原始数据面板的第二态——[2.4](2.4-resource-explorer.md) 点资源名时置位,面板改显该资源逐字内容;本模块提供宿主 +「回到原始数据」回退 + scrub 复位。
- **主对话之外的调用**:`lanes[].kind ≠ main` 的模型调用。种类、词、归行与花费分桶只按 [2.1](2.1-track-widget.md) 的 lane 种类表(`labels/replay.mjs : LANE_KIND`)。**token 计数**(`probes`,count_tokens)不是 lane、也不是模型调用,但它在 token 计数叠加轨上的 tick 同样在调用抽屉里打开。
- **调用抽屉**:视口底缘滑起的可关闭层,显示主对话之外的一次调用的调用详情卡([2.2](2.2-call-turn-card.md))与它的输入块。
- **请求详情部件**:一条记录(推理或非推理)的请求行、头、体与每侧标注的渲染部件(`traffic/request-view.mjs : requestDetailHtml()`),数据 = `calls --ref` 的单条记录,形状同 `src/view/control-wire.mjs` 的 `ctl`。
- **control-plane(session-less)**:harness 在会话周边发的**无 session 归属**调用——CC 侧无 `x-claude-code-session-id`(承 [3.4](3.4-session-identity.md) 身份信号)。多为**非 LLM 调用**。数据模型见 §C 末的 D9 注;呈现已移到流量页([1.10](1.10-traffic.md)),不再是会话选择器里的分组(D18c)。
- **凭据类请求头**:[4.1](4.1-capture-sources.md) §凭据处置点名的四个头 `authorization` · `x-api-key` · `cookie` · `proxy-authorization`(与服务端 `src/capture/redact.mjs : SECRET_HEADERS` 同一份,4.1 的「涉及」表写明它现在只用于识别)。都是 HTTP 通用名,不是某个 provider 的知识。

## Plan(选定方案 + 取舍)
**选定:一个常驻原始数据面板(默认态 = 这一步的原始线上事实)+ 一个可关闭的调用抽屉 + 一个请求详情部件(由流量 host 页托管)**;三者都只读,都**只读装配后的字段与 `calls --ref` 的记录**,lane 判定与类别划分留在服务端(`src/view/analyze.mjs` 的 lane、读取侧 harness 表推出的 D40 `traffic_class`),本部件只渲染结果。
- 原始数据面板不做「独立可关闭窗口」,而是**有默认态**:钉住的资源点「回到原始数据」或 scrub 都**回落到默认态**——避免出现「关掉了什么都不显示」的空面板。
- 面板只放**能回源的字节**:用量四个数、缓存判定与估价移到步头的「缓存」「≈ $」按钮([2.2](2.2-call-turn-card.md)):命不命中不值得在这么紧凑的空间里占篇幅,一个悬停展开的按钮就够。
- 深看用**滑起层**(`#detail`,`position:fixed` 底缘 `translateY`)而非侧栏第三列:主对话之外的调用是**偶发点开、看完即走**的深读,滑起 +「关闭」/ `Esc` dismiss 比常驻列更省版面(承 [1.2](1.2-shell-layout.md) 版面预算)。
- 会话之外的流量不再是会话选择器里的模式切换(`ctrlmode`),而是流量页的 host 下钻([1.10](1.10-traffic.md));请求详情是那里的部件:在流量页点进某个 host,就能看到这个 host 具体发过什么。
- 凭据类头逐字存(4.1),显示时默认遮挡、点了才露(显示时遮挡凭据类的头,点「显示」才露;服务端默认遮挡、按头名取一个值是 `calls --ref` 的形状)。

**备选(未选)**:① 把主对话之外的调用也画进中央回放骨——会把「主对话」与「侧线」混成一锅,违反 D2「行为回放为骨」的单主线;故侧线在 [1.3](1.3-timeline-tracks.md) 有叠加轨、在此有深看,骨只留 main。② 原始数据面板做成可完全关闭的浮窗——关掉即空、且要额外「重新打开」入口,不如「默认态 + 叠加态」自然。③ control-plane 混进会话列表按时间排——session-less 流会淹没真会话,且诱人误以为它们是某会话的一部分。④ 保留旧的 control 模式(会话选择器里的 `⚙ session-less` 组 + `ctrlmode` 分类列)——侧栏已把互不相交的东西分开,会话之外的流量在流量页,保存设置在设置页(D18c)。⑤ 用量四个数在面板与步头各放一份——同一事实两处显示。⑥ 凭据类头逐字显示——定稿是显示时遮挡、点了才露。
**取舍**:原始数据面板「默认态兜底」= 永不空手;深看滑起 = 深度可达又不常占版面;流量下钻 = 会话之外的请求可查但不污染回放台;遮挡是显示上的默认,不是隔离(见 §保真边界 2)。

## B. 调用抽屉:`#detail`(`openDetail`)
从视口底缘滑起的可关闭层(`#detail.open`;`translateY(101%)` ↔ `none`),按 `lanes[].kind` 上色边(`k-<种类>` 类名),**深看主对话之外的一次调用**。入口:[2.1](2.1-track-widget.md) / [1.3](1.3-timeline-tracks.md) 上点一个叠加轨的 tick(`replay/rails.mjs : selectTick()` → `openDetail(el, s, lane, i)`),或 [1.2](1.2-shell-layout.md) 路由的 `call=<记录 id>` 指向一次非主对话调用。dismiss:「关闭」或 `Esc`(`core/keys.mjs` 发出的 `v2:escape`,[1.2](1.2-shell-layout.md) §键盘)。

| 元素 | 屏上(例,虚构) | 来源 | 规则与守卫 |
|---|---|---|---|
| 卡 | 标题行、说明、回复或审查结论、用量与估价、技术细节 | [2.2](2.2-call-turn-card.md) §调用详情卡 | 卡里写什么归 2.2(守卫 `test/web-v2/call-card.test.mjs`);标题行的 lane 词取 [2.1](2.1-track-widget.md) `LANE_KIND`,服务端的 `lanes[].icon` 不用 |
| 回到主对话 | 「← 回到第 12 步」 | `replay/lanes.mjs : nearestByTs()` → `stepRef()` | 点了播放头移到那一步(按时间找的最近一步,标题行写「约在第 N 步」,[1.2](1.2-shell-layout.md) §编号);抽屉不关 |
| 关闭 | 「关闭」 | 固定文字;`v2:escape` | 关掉时清选中的 tick 与复审括号(`closeDetail()`) |
| 输入 | 「输入 · 14 个块」+ 每块一行:角色 · 种类 · 名字或预览 · 保真标 · 大小 | `lanes[].calls[i].flat[]` → `/api/block` | 点开取逐字;见下 |
| token 计数的输入 | 「请求体不在会话里,到 流量 页按「token 计数」类别逐条看(保存级别:全部)」 | `probes.series[].retention` | 三种:全部 / 只记日志 / 较早采集的记录,只存了长度;流量 host 页能逐条看(按类别「token 计数」,[1.10](1.10-traffic.md)) |

**输入块**(承 `replay/detail.mjs : inputHtml()`):
- 每个块一行,点开经 `/api/block` 取逐字字节(`replay/blocks.mjs : fillBody()`;取失败的行再点时重取)。块数 ≤ 40 时,短块(≤ 600 字符)自动打开;更多块时都不自动打开。
- 大小带单位:有 `chars` 写「字符」,只有 `bytes` 写「字节」,都没有写「大小未知」,从不写 0。不透明块(只有签名,没有明文)写「不透明 · 线上只有签名,没有明文」,不给一个像量出来的 0。
- 折叠标签写明被折的是什么:**证得逐字的块写「逐字 · N 字符 · 点开」,其余写它自己的保真标**(证明规则归 [2.3](2.3-context-window.md);D18c 修订,原句「折叠标签 MUST 标明被折的是逐字内容」会让没有证明的块也读成逐字)。

## Edge cases
- **无请求体的步**:探针 / 中断 call → 面板显「这一步没有采集到请求」,不空白。
- **viewPin 指向的资源不在当前这一步**:资源在早步进入/已 evict → `renderResourceView` 显「在这一步里找不到唯一对应的块(它更早进来的,或已被逐出)—— 点资源卡片在时间轴上定位它」引导用 [2.4](2.4-resource-explorer.md) 交互 1 定位,MUST NOT 静默空白;这一步的正文还没到 → 写「这一步的正文还没载入」,不写「找不到」(`test/web-v2/paged-out.test.mjs`「pinned resource: while the step's body has not arrived it says 还没载入, not 找不到 / 已被逐出; a loaded step without the block still says 找不到」)。
- **深看与 scrub 交互**:`#detail` 开着时 scrub 主线——`#detail` 是独立层,不随主线 playhead 变(它锚在被点的那次调用);但原始数据面板随 scrub 回默认态(§A 复位不变式),二者互不干扰。换页后抽屉按选中的 tick 重画(`replay.mjs : refreshDrawer()`)。
- **未下发的步**:`nonBlockKeys` 被清空、`norm` 只剩用量——看起来像「没有参数、没有回复」,其实是不在本页;按 §A 写未下发态,`respRefs` 仍可回源。
- **v0 记录**:`respRefs[].ref` 为空带 `why`、`nonBlockKeys` 为空(请求不是原文字符串)——原始回复写「没有可回源的字节」,请求参数写「这条记录没有可回源的请求参数」,回复带「◐ 解析后的回复」。
- **WebSocket 调用**:回复按消息分成多条 `respRefs`;调用打开期间客户端又发的消息(如打断)在 `extraMessages`,MUST 列出。
- **两种 probe**:服务端 lane `probe`(预热请求)与前端从 `probes.series` 造的 token 计数今天同叫 `kind:'probe'`;抽屉按来源分,不按这个字样(§B)。
- **服务商的值**:停止原因、线格式、厂商都是原值;不认识的厂商写「不知道」,不猜。
- **请求详情 · 读不到**:`calls --ref` 回原因(ref 不在采集根内、源文件不见了、记录读不出 `ctl.error`)→ 写原因 +「重试」,不显示空的体(这一层归 [1.10](1.10-traffic.md))。
- **同名的头出现两次 / 值是数组**:照存的样子逐个列出;凭据类的每一个都遮挡。
- **查询串里带凭据**:端点照存的样子显示;遮挡只按请求头名单(见 Extensions)。
- **DeepSeek / Codex 没有 control-plane 对应**:session-less 的流量是 harness 相关的——流量页对空的 host 表优雅降级([1.10](1.10-traffic.md)),本部件不硬编任何端点的存在性。

## Risk / 回滚
- 渲染是**纯函数**(这一步的装配字段 + `viewPin` + playhead → HTML;`calls --ref` 的一条记录 → HTML),用 T0 / T1 回归;改面板、抽屉、请求详情不动数据层,可独立回退到上一绿点。
- viewPin 宿主契约(复位/关闭)是本模块与 [2.4](2.4-resource-explorer.md) 的接缝;改契约 = 改接缝,两侧测试(本模块 #5 + 2.4 的资源卡测试)同守。
- 请求详情显示头与体:遮挡默认开;若 `calls --ref` 的遮挡出错(漏遮),前端的同一份名单仍会遮(两层);回退 = 撤掉 `calls --ref` 路由,数据不动。
- 第一期旧看板照旧,撤掉 `/` → `/v2/` 的跳转就回到旧看板([1.2](1.2-shell-layout.md) §迁移)。
