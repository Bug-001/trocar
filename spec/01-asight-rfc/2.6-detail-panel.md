# asight · RFC 2.6 — 右下可关闭 panel + 非核心流侧栏

> **服务意图(A2)**:意图 ①(看懂 agent 行为)为主——把「回放骨(2.3)之外」的两类东西给人一个专用宿主:*当前这步的原始 wire 事实*(右下 raw 面板)与*非主线的每一次 off-main 调用*(滑起深看 + 非核心流侧栏);兼意图 ②(raw 面板的 usage 分解 read·new-cache·fresh·out 是 cache 叠加的数字侧车)。
> **受众**:人(在骨之外深看某步原始流 / 某条侧线调用 / session-less 底噪);agent(据 [3.2](3.2-normalized-model.md) 的 `calls`/`usage`/`call_blocks` 与 `lane` 字段渲染,**不碰 provider/harness 分支**)。
> **前置**:数据源 = [3.2](3.2-normalized-model.md)(`calls.lane` 分主/非主、`usage` canonical、`request_bytes`);渲染宿主 = [1.2](1.2-shell-layout.md) 右页下部(`#rawpanel`)+ 视口底缘滑起层(`#detail`);viewPin 的**内容与切换动作**由 [2.4](2.4-resource-explorer.md) 驱动、本模块只做**宿主 + 关闭/复位契约**;非主线 tick 由 [2.1](2.1-track-widget.md)/[1.3](1.3-timeline-tracks.md) 触发;采集脱敏权威在 [4.1](4.1-capture-sources.md)。demo 的 `renderRawPanel`/`renderResourceView`(viewPin)、`openDetail`(滑起 `#detail`)、`renderControlView`/`controlLedger`/`openControlDetail`(control-plane)已实现此设计 ——本模块把它从「CC 单 harness 原型」定成读归一化行的 provider-agnostic 部件。

## Goal
给「忠实回放骨(2.3)+ 时间轴卡(2.2)」之外的三类观测一个统一宿主,MUST 不撕裂主线、不往通用视图塞 provider 分支:
1. **右下 raw 面板(`#rawpanel`)**:随播放头显示**当前主线 call 的原始 wire 摘要**(model · wire bytes · msgs/tools/system 计数 · usage 分解 read·new-cache·fresh·out),并作为 [2.4](2.4-resource-explorer.md) view 一个资源逐字内容时的**切换宿主**(viewPin)。
2. **滑起深看(`#detail`)**:从视口底缘滑起,**深看某一次非主线(off-main)调用**的逐字输入/系统规则/输出——安全监测 / count_tokens 探针 / 后台 aux(通知·标题生成·配额 ping)。
3. **非核心流侧栏(control-plane session-less)**:把**不属于任何会话**的底噪(telemetry / feature-flags / account / registry)单列成一个 session-less 视图,**排除在会话选择器之外**,captured but 不混进对话。

## Definitions
- **raw 面板(call raw digest)**:右页下部常驻面板,显示播放头所在**主线 call** 的原始 wire 事实摘要(非逐字全文,是计数+usage 的数字侧车);与 [2.2](2.2-call-turn-card.md) 时间轴卡同指一步、但**不同 surface / 不同高度**(卡在轴上原位折叠;raw 面板在右页常驻)。
- **viewPin(资源钉住态)**:raw 面板的第二态——[2.4](2.4-resource-explorer.md) 点资源名/👁 时置位,面板改显该资源逐字内容;本模块提供宿主 + `✕ call raw` 回退 + scrub 复位。
- **off-main call(非主线调用)**:`calls.lane ≠ main` 的调用(`subagent | monitor | aux | probe`,`aux` 再分 `notify | titlegen | quota`,泛化自 demo lane)。它们是 agent 主对话之外的侧线 LLM 调用。
- **control-plane(session-less)**:harness 在会话周边发的**无 session 归属**调用——CC 侧无 `x-claude-code-session-id`(承 [3.4](3.4-session-identity.md) 身份信号)。demo 分类:`control`(feature flags/experiments)· `account` · `registry`(MCP 注册表)· `telemetry`(用量/UI 分析批)· `other`。多为**非 LLM 调用**。

## Plan(选定方案 + 取舍)
**选定:一个常驻 raw 面板(有默认静息态 = call raw)+ 一个全局可 dismiss 的滑起层 + 一个 session-less 侧视图**;三者都**只读归一化行**,深看/侧栏的 provider 专属知识(lane 判定、control 分类)**留在 [3.1](3.1-adapter-contract.md) adapter**,本部件只渲染归一化结果。
- raw 面板不做「独立可关闭窗口」,而是**有默认态**:任何叠加态(viewPin)`✕` 或 scrub 都**回落到 call raw**——避免出现「关掉了什么都不显示」的空面板。
- 深看用**滑起层**(`#detail`,`position:fixed` 底缘 `translateY`)而非侧栏第三列:off-main 调用是**偶发点开、看完即走**的深读,滑起 + `✕ close`/`Esc` dismiss 比常驻列更省版面(承 [1.2](1.2-shell-layout.md) 版面预算)。
- control-plane 是**模式切换**(demo `ctrlmode`:隐右页、timeline 变分类列 + ledger),不是主视图里的一条轨——它 session-less、与会话正交,MUST NOT 污染会话选择器与时间轴。

**备选(未选)**:① 把 off-main 调用也画进中央回放骨——会把「主对话」与「侧线底噪」混成一锅,违反 D2「行为回放为骨」的单主线;故侧线在 [1.3](1.3-timeline-tracks.md) 有叠加轨、在此有深看,骨只留 main。② raw 面板做成可完全关闭的浮窗——关掉即空、且要额外「重新打开」入口,不如「默认态 + 叠加态」自然。③ control-plane 混进会话列表按时间排——session-less 流会淹没真会话,且诱人误以为它们是某会话的一部分。
**取舍**:raw 面板「默认态兜底」= 永不空手;深看滑起 = 深度可达又不常占版面;control-plane 独立模式 = session-less 底噪可查但不污染主线。

## A. 右下 raw 面板:双态(`renderRawPanel`)
常驻于右页下部([1.2](1.2-shell-layout.md) 右页 = 上 `#resexp`([2.4](2.4-resource-explorer.md))/ 下 `#rawpanel`)。

**默认态 · call raw digest**(`renderRawPanel`,无 viewPin 时):取播放头所在主线 `call`,显示——
- 头:`🩻 raw · call #N`。
- `model · <wire bytes> bytes wire`:来自 [3.2](3.2-normalized-model.md) `calls.model` + `request_bytes`。
- `msgs <n> · tools <n> · system <n>c`:该 call 上下文的 messages/tools 计数与 system 字符数(由 `call_blocks` 聚合 section 得出)。
- `usage · read <n> · new-cache <n> · fresh <n> · out <n>`:**MUST 读 [3.2](3.2-normalized-model.md) canonical usage**,映射固定为 `read=cache_read`、`new-cache=cache_write`、`fresh=input_uncached`、`out=output`。**provider 原生字段名 MUST NOT 泄漏到此面板**(承不变式 3;产品 MUST 走 canonical)。这四个数正是 [3.3](3.3-cache-model.md) cache 叠加的**数字来源**——面板是 cache 叠加的数字侧车,喂意图 ②。
- 无请求体的步(探针/中断):显 `no request captured for this step`,MUST NOT 空白。

**viewPin 态 · 资源逐字内容**:[2.4](2.4-resource-explorer.md) 的 `viewResource(step,resKey,label)` 置 `viewPin` 后,面板改由 `renderResourceView` 渲染该资源的逐字 `<pre>` + 头 `📄 <path>` + `✕ call raw` 回退键。**切换动作与内容解析归 [2.4](2.4-resource-explorer.md)**;本模块只保证宿主契约:
- **`✕ call raw` MUST 清 `viewPin` 并回落默认态**(demo `#rpx` onclick → `viewPin=null; renderRawPanel()`)。
- **scrub MUST 复位到 call raw**:`setPlayhead` 一进来就 `viewPin=null`(demo 注释「scrubbing returns the panel to the call raw」)——换步即离开资源钉住态,面板永远反映「当前步」。这是**宿主级不变式**:面板的态 MUST NOT 跨步粘住。

## B. 滑起深看:`#detail`(`openDetail`)
从视口底缘滑起的 dismissable 层(`#detail.open`;`translateY(101%)` ↔ `none`),按 `lane.kind` 上色边(`k-monitor`/`k-probe`/`k-aux`…),**深看一次 off-main 调用**。入口:[2.1](2.1-track-widget.md)/[1.3](1.3-timeline-tracks.md) 上点一个**非主线 tick**(demo `selectTick → openDetail(lane,i)`);同时它也是 control-plane 行的深看宿主(见 §C)。dismiss:`✕ close` 或 `Esc`(demo `closeDetail`)。

按 lane 分型深看(每型都带**该调用的逐字输入原文**):
- **`monitor`(🛡 安全监测)**:显 verdict + 监测的 `#1→#k` 范围 + **监测器的确切输入消息(原文)**——只把重复的 `<transcript>` 体**就地折叠**(`⟨verbatim conversation transcript⟩`),让人看到**真实结构**而非「描述」;再折叠监测系统规则(每次相同)。这是逐字保真的一个样板:**展示原文结构、只折不改**。
- **`probe`(👁 count_tokens 探针)**:标注「把**整段**上下文送去计数(逐字)、只回大小——是尺子不是回合,无模型输出、不计费」,给出测得 tokens 与它逼近的 `callRef(k)`。**这是被测 harness 自己发的 `count_tokens` 调用,asight 只经采集源观测、绝不代发**(不变式 1,[0.0](0.0-overview.md) §核心不变式:没有操作者动作时 asight 不发请求)。
- **`aux` 家族**:`notify`(📣 后台活动摘要 → 驱动 Desktop 推送,client 消费、不入对话)/ `titlegen`(🏷 会话短名的来源)/ `quota`(🔌 `max_tokens:1` keep-alive,回复被丢弃)——各显其 `input(原文)` 折叠 + 该子类的语义 lead。

> 深看的输入/输出 MUST 逐字(AC-1);超长体折叠(`collapse`)而非改写。折叠标签 MUST 标明被折的是逐字内容(如 `⟨verbatim … · click to unfold⟩`)。

## C. 非核心流侧栏:control-plane session-less(`renderControlView`)
会话选择器里一条 `⚙ session-less` 分组项(`__control__`)切入 `ctrlmode`:隐右页与骨,timeline 变**按类折叠的分类列**、ledger 变**观测到的 feature flags + 类目统计**。同一分组另有一项「采集健康」(D38):同样切入 `ctrlmode` 栅格,但数据来自 [4.4](4.4-server.md) `/api/capture-health`,不是归一化行;timeline 列按原因分组的失败记录,ledger 列当前条件,点行进 `#detail` 看元数据。它不是会话,不进会话分组。
- **头注**明性质:*session-less calls Claude Code makes around your conversations(no `x-claude-code-session-id`)· Captured but kept out of the conversation picker*。
- 每类(`control`/`account`/`registry`/`telemetry`/`other`)一个可折叠段,每行 = 一次调用的 `time · method · endpoint · status`;点行 → 复用 §B 的 `#detail` 滑起看**请求+响应**(`openControlDetail`)。
- ledger 抽出**真正有料的一撮**:观测到的 feature flags(`response.body.features` 展平),回答「你的 client 实际在跑哪些实验开关」——这是 session-less 底噪里最贴意图①的信号。
- **请求与响应体(D40)**:深看里请求体逐字显示,不再写「request body isn't decoded」。文本按原文显示在 `<pre>` 里,超长只折不改(同 §B 的 `collapse`,折叠标签写明「逐字 · N 字节」);二进制(`req_body_b64` 不带 `req_content_encoding`,或 `raw_b64`)显示「二进制 · N 字节 · 逐字存为 base64」与前 4 KiB 的十六进制;压缩体先由服务端按 `req_content_encoding` 解,解不出才标「压缩请求体未解码」;非 LLM 的 SSE 显示 `resp.raw` 原文,不显示 Anthropic 重建出来的空回答;每个体旁给出 `body_wire_bytes`。**显示上限(此前 spec 没写,审查 2026-10-07 补记)**:服务端只下发每个文本体的前 1 MiB 字符(`BODY_SHOW_CHARS`,不劈开代理对)、二进制体的前 4 KiB 作十六进制(`HEX_SHOW_BYTES`);超出时面板就地写「已截断显示 · 前 N / 共 M 字符」与「其余在源记录里」。这不是改写 —— 不发,不是改 —— 但它让「逐字显示」到 1 MiB 为止;更大的体要看全就得读源记录。另显示 `host`(SNI)与 `req_headers.host`,两者不同时并排标出(反代记录除外:那里 `host` 是上游、`Host` 头是客户端连反代的地址,按构造就不同,不是信号)。**不是整个体的体 MUST 说明白**(审查 2026-10-07,不变式 4):请求体被截在上限(`req_truncated`)或没传完(`req_partial`)、回复被截在上限,面板就地标「已截断」/「不完整」(`ctl.labels` 的 `req-incomplete`、`resp-truncated`),并写「只存了前 N / 共 M 字节」,折叠标签写「前缀,不是完整的体」而不是「逐字」;D40 之前 `raw_chars` 为 0 的记录(GET 没有体)显示「(empty)」,不是「只存了长度」。**session 之内的非推理调用不在此列**(审查 2026-10-07 纠正原先的「经 §B 的 `openDetail`,规则相同」,那句话与代码不符):它们的体照样存进采集记录(逐字,级别同上),但看板**没有**显示它们 —— `count_tokens` 的 probe 泳道只画测量值,详情里一句话说明体存在采集记录里(并按 `retention` 说明是全部 / 只记日志 / D40 之前只存了长度);session 内的 `other`(非 LLM、非 probe)只计数。只有 session-less 的调用在本节显示体。要显示它们需要一个按需取单条的端点(`count_tokens` 的体是上下文的副本,可达 MB 级,不能随会话载荷下发):**未做,留作 Extension,未定**。

> control-plane 是 session-less,**在归一化模型里无 `session_id` 归属**——归宿**已定(D9)**:落 `calls.class='control'` + `session_id NULL` + [3.2](3.2-normalized-model.md) `control_calls` 投影,[3.4](3.4-session-identity.md) 已注它不参与身份判定。分类(control/account/registry/telemetry)是**endpoint 级 provider 知识**,MUST 留 adapter([3.1](3.1-adapter-contract.md) 出归一化 `control_kind`),侧栏只渲染归一化类目;往侧栏塞 CC endpoint 字面判断 = 破适配缝(**需 RFC**)。

## D. 保存什么(D40)
`⚙ session-less` 组里与「采集健康」并列的第三项「保存什么」,同样切入 `ctrlmode` 栅格;数据来自 [4.4](4.4-server.md) `GET /api/retention`,不是归一化行;它不是会话,不进会话分组。
- **主表**:行 = harness(数据里见过的 ∪ 设置里有的),列 = 七个类别(`llm` · `token-count` · `session-sync` · `telemetry` · `files` · `account` · `other`)。每格:级别(`全部` / `只记日志`)+ 所选时间窗(24 h / 7 d / 全部,页头切换)的条数、线上体字节、存储字节;另有行合计、列合计。D40 之前的记录(`legacy-meta`)单列一行「D40 之前 · 只存了长度」,线上请求体字节照给,响应体字节写「未记录」。
- **页脚**:`~/.asight` 盘上占用(按目录分组:采集文件、封存文件、`sessions/` 分片副本、DuckDB、日志与其他)与封存比;「按类数字截至 T(上次 `asight etl`)」;没有 DuckDB 时按类格写「需要先跑 asight etl」,不写 0;封存后的按类数字标「估计」;最近几次修改(谁、何时、旧值 → 新值)。
- **改级别**:点格子里的级别切换,经 `POST /control/retention`;控制面没开(没有 `serve --control`)时切换钮置灰,改为显示可复制的命令 `asight keep <harness> <类别> <full|log>`。页头常驻一句「改动只影响之后开始的调用;已存的数据不删」(不变式 2)。设置文件读不出时,页头写原因与「两条采集路径现在按全部保存」。
- **适配缝**:harness 与类别都是归一化 id 与闭集名,页面不出现任何 host / 端点字面量(不变式 3)。

## 保真边界(必拒隐瞒 · 承不变式 4)
本模块展示多处**非逐字线上真相**,MUST 就地标注:
1. **非 LLM 调用的请求体(D40 改写)**:D40 起非 LLM 请求体与 LLM 同等逐字,完整时 MUST NOT 再标「非逐字」或「request body isn't decoded」。仍要就地标的只有:D40 之前的记录(`{raw_chars, verbatim:false}`,不带 `body_retention`)标「本条采于 D40 之前,只存了长度」——telemetry 尤甚:那时我们看不到上报了什么分析事件,只看到被接受的条数;操作者设为只记日志的(`body_retention:'log'`)标「只记日志 · 用户设置 <harness> · <类别>」;截断、未解码各标各的。MUST NOT 让这些没有体的调用被误读成「没发东西」或空回答。
2. **脱敏头(采集层)**:任何在这些面板 surface 的请求头都是**采集时已脱敏**的集合——`authorization` / `x-api-key` / `cookie` / `proxy-authorization` → `<redacted>`(承 [4.1](4.1-capture-sources.md) 采集安全、[3.1](3.1-adapter-contract.md) `req_headers(脱敏)`)。**被测程序的 token 永不进 panel、永不落记录**(OBSERVE-only 的安全推论:采集不泄密)。这既是保真边界(头非逐字)也是安全不变式。
3. **raw digest 是摘要不是全文**:call raw 态显示的是**计数 + usage**(model/bytes/msgs/tools/system/read·new-cache·fresh·out),**不是**该 call 的逐字上下文——逐字上下文在中央回放窗([2.3](2.3-context-window.md));面板头 `🩻 raw` 表意「wire 事实摘要」,MUST NOT 被当成完整线上 bytes。
4. **viewPin 内容截断**:资源逐字内容按显示上限截断(demo `clip(…,6000)`),宿主 MUST 透传 [2.4](2.4-resource-explorer.md) 的截断标记(`… (N chars total)` 类)= truncated 保真边界,MUST NOT 让截断冒充完整。
5. **`new-cache`(cache_write)可为 NULL**:provider 无写缓存概念时(DeepSeek)canonical `cache_write=NULL`,面板 MUST 显「—/NULL」而非 `0`(承 [3.2](3.2-normalized-model.md) 不变式:NULL ≠ 0 冒充)。

## Out-of-scope
- viewPin 的**资源解析 / 双交互 / only-seen 语义**→ [2.4](2.4-resource-explorer.md);本模块只做 viewPin 宿主 + 关闭/复位契约。
- 时间轴卡(每步 time/model/token/cost/cache 原位折叠)→ [2.2](2.2-call-turn-card.md);raw 面板与它同指一步、不同 surface,不重复卡的信息架构。
- 中央**逐字上下文回放**→ [2.3](2.3-context-window.md);cache **叠加语义/断点/TTL** → [3.3](3.3-cache-model.md);raw 面板只给数字,不算断点。
- 非主线 tick 的**排布/触发**→ [2.1](2.1-track-widget.md)/[1.3](1.3-timeline-tracks.md);右页/滑起层**外壳与边界** → [1.2](1.2-shell-layout.md)。
- `lane` **怎么判**(哪次调用属 monitor/probe/aux)、control **怎么分类** → [3.1](3.1-adapter-contract.md) adapter;本部件只读归一化 `lane`/类目。
- 表怎么被查(SQL)→ [3.5](3.5-query-layer.md);表结构 → [3.2](3.2-normalized-model.md)。

## 影响面

## Edge cases
- **无请求体的步**:探针 / 中断 call → raw 面板显 `no request captured`,不空白(demo `.rpempty`)。
- **viewPin 指向的资源不在当前 call**:资源在早步进入/已 evict → `renderResourceView` 显「not resolvable to a single block in this call — click the card to locate it」引导用 [2.4](2.4-resource-explorer.md) 交互 1 定位,MUST NOT 静默空白。
- **深看与 scrub 交互**:`#detail` 开着时 scrub 主线——`#detail` 是 off-main 独立层,不随主线 playhead 变(它锚在被点的那次 off-main 调用);但 raw 面板随 scrub 回 call raw(§A 复位不变式),二者互不干扰。
- **control-plane 空**:`/api/control` 空 → 类目列空,显占位而非崩;离开 `ctrlmode` MUST 强制全量重渲(demo `controlSig=null`,否则残留 session 头)。
- **超大 control 类目**:每类只显最近 N(demo 80)+ `… older not shown`,不让底噪洪水淹没(承 [3.5](3.5-query-layer.md) 分页契约)。
- **DeepSeek/Codex 无 control-plane 对应**:session-less 底噪是 harness 相关(CC 有一撮配置/遥测端点;Codex/DeepSeek 未必)——侧栏 MUST 对空类目优雅降级,不硬编 CC 端点存在性。

## Risk / 回滚
- 渲染是**纯函数**(`call 行` + `viewPin` + playhead → HTML;`control 记录` → HTML),用固化真实 trace 回归;改面板/深看/侧栏不动数据层,可独立回退到上一绿点(render gate)。
- viewPin 宿主契约(复位/关闭)是本模块与 [2.4](2.4-resource-explorer.md) 的接缝;改契约 = 改接缝,两侧测试(本模块 #2 + 2.4 point 4)同守。
- control 分类误差属 adapter([3.1](3.1-adapter-contract.md))范畴,回滚在那边;本部件对坏/缺类目 MUST 优雅降级(占位 + 标注),不 throw。
