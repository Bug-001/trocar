# asight · RFC 2.5 — 左栏 outline 导航

> **服务意图(A2)**:意图 ①(**本步上下文的目录**——把 [2.3](2.3-context-window.md) 那一列可能几百块的忠实窗口,压成 tools/system/messages 三组可跳的骨架,让人一眼看清"这一步上下文由什么拼成"、并一键跳到任一块/turn)+ 意图 ② 的**轻钩**(cache-break 行显本步命中 %、点跳窗口的 cache marker;数值真相来自 [3.3](3.3-cache-model.md))。
> **受众**:人(据目录快速定位本步上下文里的某工具 / 某 system 段 / 某 user 查询)+ agent(据 [3.2](3.2-normalized-model.md) 的 `call_blocks`/`block_contents` 的 `section`/`role`/`kind`/`preview` 生成目录条,**不重解析原始请求、不回退 provider 专属分支**)。
> **前置**:块数据 = [3.2](3.2-normalized-model.md)(`call_blocks` 有序 + `block_contents` 的 `section`/`role`/`kind`/`preview`/`cache_control`/`volatile`);宿主容器 = [1.2](1.2-shell-layout.md)(`#ctxnav` 在 `#leftpage` 的 `<main>` 内、居窗口 `#ctxwin` 之左——**不是独立第四栏**);跳转目标窗口 = [2.3](2.3-context-window.md)(`.cblk[data-bi]` + `#cachebrk` marker);cache % 真相 = [3.3](3.3-cache-model.md);资源生命周期**已拆去右页** = [2.4](2.4-resource-explorer.md)。承 demo `renderContextNav`/`navGroup`/`humanTurns`/`messageTurns`/`jumpToBlockIndex`/`openTurnFor`。

## Goal
给 [2.3](2.3-context-window.md) 的忠实窗口配一个**本步(playhead 当前 call)上下文的目录**:tools 组(逐工具)/ system 组(逐块 + 缓存徽标 + 字符数)/ messages 组(按 turn 列 user 查询)/ 一行 cache-break(命中 %),点任一条即跳到窗口对应块;跳到**折叠 turn 里**的块会先展开该 turn 再定位。outline **只管"本步上下文结构"**——资源在整条 session 里的进出生命周期已拆到右页资源管理器([2.4](2.4-resource-explorer.md)),二者 MUST NOT 混。承 demo 单 harness 验证,泛化到跨 provider(承 [3.1](3.1-adapter-contract.md)/[3.2](3.2-normalized-model.md))。

## Definitions
- **outline / `#ctxnav`**:看板左侧的目录容器,随 playhead 重渲(scrub 即换),头写 `this context · #<playhead+1>`(承 demo `navz`)。**作用域 = 本步单 call**,非跨 session。
- **nav 组(`navGroup`)**:一个可折叠分组(head:图标 · label · 计数;body:子条列表),开合态存 `navOpen`(承 demo `Set(['sys',…])`,system 默认展开)。
- **子条(`.navsub`)**:一个可跳条目;`data-jumpfi=<flat index>` 指向窗口里对应 `.cblk` 的块序。
- **turn 条**:messages 组内一条 = 一个**人写 user 查询**(承 demo `humanTurns`:剥掉 `<system-reminder>` 后仍非空的 `user·text` 块);点它跳到该 turn 的查询块。
- **cache-break 行**:非分组的单行,label `cache break`、计数位显本步命中 %(`cache_read/total_input`,来自 [3.3](3.3-cache-model.md)/[3.2](3.2-normalized-model.md) canonical usage),点它跳窗口的 `#cachebrk` marker。

## Plan(选定方案 + 取舍)
**选定**:**看板内嵌左栏目录 · 三组 + cache-break 行 · 条目从 canonical 列生成 · 点条跳窗口(折叠 turn 先展开)。** outline 与忠实窗口共处一个 `<main>`、读**同一份** `call_blocks` 序,故 `data-jumpfi` 与窗口 `.cblk[data-bi]` 天然对齐,跳转不飘。
**备选(未选)**:① **独立第四栏**(与左右页并列)——挤占回放骨主舞台、且目录与其索引的窗口分屏,注意力割裂(违 [1.2](1.2-shell-layout.md) 的左右页 B 布局);② **把资源生命周期也塞进本栏**(demo v0 曾如此)——"本步结构"与"跨 session 进出"两种时间尺度混在一栏,读者分不清"这一步有什么" vs "整条 session 里这文件何时进出",故 B-split 拆去 [2.4](2.4-resource-explorer.md);③ **目录即渲染真相**(在 outline 里展开块全文)——那是窗口([2.3](2.3-context-window.md))的职责,outline 塞全文会诱导"目录=真相"误判、且与窗口重复。
**取舍**:outline 是**导航投影**(preview/计数/%),不是回放层——零全文冗余、与窗口读同序 → 跳转永不错位;逐字真相只在窗口([2.3](2.3-context-window.md))。

## 部件结构(承 demo)

### 定位:看板内嵌左栏(必拒做成第四栏)
`#ctxnav` 长在 `#leftpage` 的 `<main>` 内、`#ctxwin` 之左(承 [1.2](1.2-shell-layout.md):`<main>` = outline `#ctxnav` + 中央看板 `#ctxwin`)。它**不是**与左右页并列的独立栏——它是回放骨内部的目录侧条。窄屏(≤820px)可另隐 outline 而外壳左右堆叠仍成立(承 [1.2](1.2-shell-layout.md) responsive)。

### 作用域:本步上下文(随 scrub 重渲)
outline 描述的是 **playhead 当前 call** 的上下文结构:`setPlayhead → renderContextNav`(承 demo),scrub 到别步即整栏换。无 call 的步(probe / 中断)→ 整栏清空(承 demo `if(!call){ nav.innerHTML='' }`)。**MUST NOT** 把跨 session 的资源进出画进本栏(那是 [2.4](2.4-resource-explorer.md) 的"across the session")。

### 三组 + cache-break 行
读本 call 的有序块(demo 现为 `linearContext` 的 `flat`;**产品改读 [3.2](3.2-normalized-model.md) `call_blocks`+`block_contents`**),按 `section` 分组:
- **tools 组(⚙)**:逐工具列名;MCP 工具标 `🔌`、普通标 `⚙`(承 demo `b.mcp`)。点条跳该工具定义块。空 → `no tools in view`。
- **system 组(▤)**:逐 system 块,列 `label` + 徽标 **⟐**(`cache_control` 非空 = 声明断点)/ **↻**(`volatile` = per-call nonce)+ 字符数 `Nc`(承 demo `sysKids`)。徽标 MUST 从 canonical 列(`cache_control`/`volatile`)读,**MUST NOT 在前端重嗅 provider 专属正则**(billing-header 等)——那属 adapter([3.1](3.1-adapter-contract.md))职责(**破此缝 = 需 RFC 才放行**,不变式 3;判据同 [2.3](2.3-context-window.md) 徽章)。
- **messages 组(💬)**:按 turn 列**人写 user 查询**(`🗣 <preview>`,承 demo `humanTurns`+`preview` 剥 system-reminder、slice 90)。点条跳该查询块。空 → `no plain-text user turns in view`。
- **cache-break 行(⚡)**:单行,计数位 = 本步命中 %(`round(cache_read/total_input*100)`),点跳窗口 `#cachebrk` marker。**数值 MUST 取自真实 usage([3.3](3.3-cache-model.md)/[3.2](3.2-normalized-model.md) canonical),MUST NOT 在本栏用 byte-diff 臆测断点**(demo 已证 byte-diff 会撒谎,见 [2.3](2.3-context-window.md))。

### 跳转联动:目录 → 窗口(折叠 turn 先展开)
点子条 → `jumpToBlockIndex(fi)`:**先 `openTurnFor(fi)`**——若该块落在 messages 段某**折叠 turn** 内(`messageTurns` 里 `turnOpen` 未含),先把该 turn 加入 `turnOpen` 并重渲窗口,再把目标 `.cblk` 展开、`scrollIntoView(center)` 并短暂高亮(承 demo)。cache-break 行走 `jumpToAnchor('cachebrk')` 滚动到 marker。**这是 outline 的核心价值:目录条与窗口块序同源(读同一 `call_blocks`),点条必落对块。**

### 与资源生命周期的拆分(B-split · 承 2.4)
demo 里 `renderContextNav` 一函数**双填**:`#ctxnav`(本步目录)+ `#resexp`(跨 session 资源生命周期 `lifecycleNav`)。**产品拆:本模块(2.5)只出 `#ctxnav` 目录;`#resexp` 的资源生命周期归 [2.4](2.4-resource-explorer.md)**;`data-navtoggle`/`data-jumpfi`/`data-navstep` 等跳转/开合 handler 的接线是可共享的工具函数,但 2.5 只 wire 自己的 `#ctxnav`。**资源条 MUST NOT 漏进 outline**(现渲染闸已反向断言,见验收)。

## 跨 provider 泛化(承 3.1/3.2)
demo 只跑 Anthropic、且每步现解析 `linearContext(call.rec.request)`、cache % 直读 Anthropic 原生字段名(`cache_read_input_tokens` 等)。**产品改从归一化行渲染**:分组读 `block_contents.section`(tools/system/messages;Codex `instructions`→system、`input[]`→messages 已由 adapter 归一)、`role`/`kind`/`preview`/`cache_control`/`volatile`;cache % 读 canonical `usage.cache_read`/`usage.total_input`([3.2](3.2-normalized-model.md))。→ **加 provider 只加 adapter,本栏零改**(AC-3)。

## Out-of-scope
- 块**全文回放** / 折叠展开 / 保真标 / cache 徽章**语义** → [2.3](2.3-context-window.md)(本栏只出徽标**镜像**+跳转锚,不画块体)。
- cache 数值真相 / 断点判据 → [3.3](3.3-cache-model.md);块**怎么解析** / `section` 归一 → [3.1](3.1-adapter-contract.md);表 DDL → [3.2](3.2-normalized-model.md)。
- **资源在整条 session 的进出生命周期**(files opened / only-seen / capabilities / context resets)→ [2.4](2.4-resource-explorer.md) 的 `#resexp`,**不在本栏**。
- 时间轴 / scrub / playhead 定位 → [1.4](1.4-central-board.md) + [2.1](2.1-track-widget.md);外壳左右页 / 宿主槽位 → [1.2](1.2-shell-layout.md)。

## 保真边界(承不变式 4,[0.0](0.0-overview.md) §核心不变式 · 必拒隐瞒)
outline 显示的是**派生导航投影**——`label` / `preview`(剥 system-reminder + slice 90)/ 字符数 / 命中 %,**非线上 payload 逐字**;它是**导航层**,同顶栏([1.2](1.2-shell-layout.md))。逐字真相在窗口([2.3](2.3-context-window.md))。故:
- tools 组只列**名字**(schema 文本本就未逐字采集,承 [2.3](2.3-context-window.md)/[3.2](3.2-normalized-model.md) `faithfulness=metadata`)——**MUST NOT** 让 tools 条看着像完整工具定义。
- preview 是截断/折空白的**摘要**,**MUST NOT** 让人误以为是块全文;点条落窗口才见逐字(且非 verbatim 块在窗口就地标 faithfulness)。
- 无需在每条 outline 逐字标注(它本就是导航投影),但 **MUST NOT 让这些投影看起来像线上原始字段**。

## 影响面
[2.3](2.3-context-window.md) 窗口的**目录侧条**;读 [3.2](3.2-normalized-model.md) 的 `call_blocks`/`block_contents`(`section`/`role`/`kind`/`preview`/`cache_control`/`volatile`)+ canonical `usage`;跳转依赖 [2.3](2.3-context-window.md) 的 `.cblk[data-bi]`/`#cachebrk`;宿主槽位在 [1.2](1.2-shell-layout.md) `#ctxnav`;与 [2.4](2.4-resource-explorer.md) 共处 B-split(前者 `#ctxnav`、后者 `#resexp`)。**改分组维度 / 徽标来源 / 跳转锚 = 触不变式 3/4 与 AC-3 的落点 → MUST 走[0.1](0.1-engineering-rules.md) 的 grep-spec 自对照闸。**

## 验收(可跑 check)
**现有闸(committed)**:

**本模块新测 MUST 断言**:
1. **三组 + cache-break 行在位**:render 后 `#ctxnav` 含 `tools`/`system`/`messages` 三组 head 与 `cache break` 行;各组计数与本 call `block_contents` 按 `section` 计数一致;cache-break 行 % == `round(cache_read/total_input*100)`(取 canonical usage,**非 byte-diff**)。
2. **跳转同源(必拒错位)**:outline 每条 `data-jumpfi` MUST 落在本 call 块序的合法区间、且指向窗口存在的 `.cblk[data-bi]`;对一个位于**折叠 turn** 的 fi,`openTurnFor(fi)` 返回真且把正确 turn 置入 `turnOpen`(数据级断言,规避 DOM shim 的 querySelector 空返)。
3. **拆分(承 1.2 · 必拒混淆)**:`#ctxnav` 内**仅**本步条目(tools/system/messages/cache-break),资源生命周期(files opened / only-seen / context resets)**MUST NOT** 出现在 `#ctxnav`(现闸反向断言升级为显式验:资源条只在 `#resexp`)。
4. **徽标/% 从 canonical 列(不变式 3)**:构造 `call_blocks.cache_control≠null` → system 条现 ⟐;`volatile=true` → 现 ↻;`grep` outline 渲染代码**无** provider 专属正则(billing-header 等)驱动徽标或 %;喂一条 Codex 归一化行(`instructions`→system、`input[]`→messages)→ 同三组渲染、**前端主干 `git diff = 0`**(AC-3)。
5. **保真边界(必拒隐瞒)**:tools 组只列名(无 schema 文本);turn 条 preview 已剥 `<system-reminder>` 且截断——断言其**不含**块全文(仅摘要)。

## Edge cases
- **无 call 的步**(probe / 中断):`#ctxnav` 清空,不崩(承 demo)。
- **纯 system-reminder 的 user 块**:`humanTurns` 过滤掉(outline messages 组只列**人写查询**)→ 该块在窗口存在、却不在 outline 列出;且 messages 组 head 计数用**块数**、子条列**人写查询数**,二者可不等——这是有意的(目录聚焦人意图),但 **计数语义须与整合者确认**(见返回的 open-question)。
- **无工具 / 无人写查询**:各组显 `no tools in view` / `no plain-text user turns in view`(承 demo),不空手。
- **超长工具列表 / 超多 system 块**:分组折叠可扛;视口虚拟化留 Extension。
- **compaction 步**:outline 只反映该步(compaction 后)的本步结构;"context resets"事件条属 [2.4](2.4-resource-explorer.md) 的 `#resexp`,**不在本栏**(compaction ≠ fork,承 [3.4](3.4-session-identity.md))。
- **首 call `cache_read>0`**(跨 session 暖前缀):cache-break 行如实显该 %,不当异常(承 [3.3](3.3-cache-model.md))。

## Risk / 回滚
本栏是**纯渲染函数**(归一化行 → nav DOM),用固化真实记录回归;失败回退上一绿点。**最大风险 = 目录与窗口块序失同步(`data-jumpfi` 对不上 `.cblk[data-bi]`)→ 跳错块**:回滚策略 = 强制 outline 与窗口读**同一份** `call_blocks` 序,不各自解析;或 **徽标/% 回退到前端嗅 provider 特征**(违不变式 3,必拒)→ 降级为只读 canonical 列,宁可少显不可前端瞎猜。

## Extensions
- outline 内**过滤/搜索**(按名/段跳大列表);一键 collapse-all。
- **scroll-spy**:窗口滚动时 outline 高亮当前可见块(双向同步)。
- 长工具/长 system 列**视口虚拟化**。
- turn 条挂**回合动作摘要**(承 demo `messageTurns` 的 `t.acts`:`N tool · think · result`),目录即见该 turn 干了什么。
- messages 组计数改为"turn 数 vs 块数"可切换(收敛上述 edge-case 的计数歧义)。
