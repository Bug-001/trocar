# asight · RFC 1.3 — 排轴(时间轴 · 多轨)

> **服务意图(A2)**:主要意图 ②——把每步上下文的**体量 + 组成 + cache 命中**编码成可扫视的轨道(承 [3.3](3.3-cache-model.md));并承意图 ①——**按步轴本身就是 scrub 的对象**(时间轴 = 回放的骨,喂 [1.4](1.4-central-board.md))。这是"行为回放为骨 · cache 为叠加层"(D2)在轴上的兑现。
> **受众**:人(在轴上一眼定位"哪步爆上下文 / 哪步 cache 断了"再点进去)+ agent(据此把 [3.2](3.2-normalized-model.md) 的 `calls`/`usage`/`cache_events` 渲成轨)。
> **前置**:步序与 lane 来自 [3.2](3.2-normalized-model.md)(`calls.seq`/`calls.lane`/`calls.compaction`);cache 数值真相来自 [3.3](3.3-cache-model.md);subagent lane = 父血缘、compaction ≠ fork 见 [3.4](3.4-session-identity.md);轨道**部件实现**(柱/tick/缩放/hover/click→card)在 [2.1](2.1-track-widget.md)。

## Goal
用一条**按步 LLM 调用**的横轴,把一条 session 编码成:**主轨** = 每步一柱(柱高 = 上下文体量,柱内多色段 = 类型组成)· 主轨下 **cache 带** = 每步命中率 · 可勾选的**叠加轨**(subagent / monitor / aux / probe)。三轨**共享同一 /N 步轴**、左对齐,让"体量、组成、cache、旁路事件"在同一时刻纵向对齐、互为注解。

## 前置定义(Definitions)
- **步轴(step axis)**:横轴单位 = 主 lane 的第 N 次 call(`calls.seq`),**非墙钟等距**——scrub 的最小单位。N 柱等宽,每柱占 `1/N`。
- **主轨 context 柱(context bar)**:主 lane 每步一柱;柱高 ∝ 该步 `usage.total_input`(真·上下文体量)。
- **段组成(composition)**:一柱内按类型(tools/system/user/assistant/thinking/tool_use/tool_result/image)堆叠的多色段——**比例是估算(保真边界,见下)**。
- **cache 带(cache band)**:主轨正下方、与柱 1:1 对齐的一行细格,每格 = 该步 `cache_read/total_input` 的三档着色。
- **叠加轨(overlay lane / rail)**:主 lane 之外的每条 lane(subagent/monitor/aux/probe),各占一行,勾选/展开显示。
- **共享网格(shared grid)**:每行 = 固定左 **gutter**(轨道标题)+ 右 **plotting lane**(柱/格/tick)。gutter 定宽,plotting lane 弹性;主轨、cache 带、每条叠加轨同宽 gutter → 列对齐。

## Plan(选定方案 + 取舍)
**选定:一条 /N 步轴 · 三类轨共享网格 · 主轨骨 + cache/叠加为层。**
- 横轴锚定**主 lane 的 call 序**(非墙钟),N 柱 flex 等宽各占 `1/N`;叠加轨上的旁路事件用 `xOf(ts)→(i+frac)/N` 绝对定位,落到对应主柱的**左沿**——柱(等距)与 tick(时间插值)**收敛到同一 /N 轴**。
- 布局用 CSS grid `grid-template-columns: <gut> 1fr`,`<gut>` 在 `#saw` 与 `#rails` 取同一值(140px);轨道标题进 gutter(省水平宽度),RKIND 长描述**移到标题 tooltip**。
- 主轨 = 回放的骨(点它 = scrub 到该步,承 [1.4](1.4-central-board.md));cache 带贴着主轨(每步随手可读命中);其余 lane 是**可勾选叠加层**,想看行为看骨、想看 cache/旁路才勾亮。

**备选(未选)**:① **墙钟等距轴**——旁路事件绝对准,但主柱会被密集调用挤成不可 scrub 的乱麻,且"按步"才是 agent 的决策单位;② **每类轨各一条独立时间轴**——各自缩放不再对齐,失去"同一时刻纵向对照"这一核心价值;③ **cache 作独立主视图(与行为并列可切换)**——违反 D2(一条主线承载两目的),首页撕裂。
**取舍**:牺牲叠加轨的墙钟精度(tick 落到最近主步的左沿,是"对齐到步"不是"对齐到毫秒"),换来三轨恒定对齐 + 单一 scrub 对象。旁路事件的精确墙钟仍在 card/detail 里如实给。

## 轴与网格(对齐不变式)
- **列对齐(MUST)**:主轨、cache 带、坐标轴、每条叠加轨 MUST 是同一 grid 的行,共享**同一 gutter 宽**;plotting lane 起点因此逐行对齐。gutter 宽由 [1.2](1.2-shell-layout.md) 定义,1.3 MUST NOT 各行自算宽度。
- **/N 收敛(MUST)**:主柱按 flex 均分 `1/N`;叠加轨 tick 按 `xOf(ts)=(i+frac)/N` 定位。二者 MUST 引用**同一个 N = 主 lane call 数**与**同一 `xOf`**——换算不一致 = 轨间错位(视觉撒谎)。同 `ts` 的旁路事件落到主柱 i 的左沿(`frac=0`)。
- 坐标轴行只标 `call #1 · 中 · call #N`(步标,非时刻);墙钟在柱/ tick 的 tooltip 与 card 里给。

## 主轨 context 柱 + 段组成
- **柱高 = 真值**:`h ∝ step.total_input / peak`(peak = 本 session 各步 `total_input` 最大值)。`total_input` = canonical `usage`(`input_uncached + cache_read + cache_write`,见 [3.2](3.2-normalized-model.md))——**真·上下文体量,非估算**。
- **段组成 = 估算(保真边界 · 必拒隐瞒)**:柱内按 8 类(tools/system/user/assistant/thinking/tool_use/tool_result/image,映射 [3.2](3.2-normalized-model.md) 的 `block_contents.section/role/kind`)堆叠着色。产品用**各类块的 UTF-8 字节数作 token 占比代理**(服务端 `compBuckets()` 逐 call 预烘进 `comp`,`callComp()` 读它,没有才本地按块算)——**段的相对比例是估算,不是逐字 token 计量**。承不变式 4:UI MUST 就地标注"组成为估算(按字节占比,非 token)";MUST NOT 让人误读段比例为精确 token 分布。provider 均不给 per-block token,故产品沿用估算,但**标注不可省**。
- 色板固定复用(段颜色 = 图例 = [2.3](2.3-context-window.md) 回放里同类块的强调色),跨轨/跨视图同色同义。
- **错误步**:`stop_reason=error`/中断 → 柱降为固定矮红条 + `⚠` 角标(不画组成,体量无意义)。
- **✂ compaction 标在柱**:`calls.compaction=true` 的步,柱上挂 `✂` 角标。compaction 是**同一 session 内换血**(标在柱),MUST NOT 渲成 fork/新轴(承 [3.4](3.4-session-identity.md) 的 compaction ≠ fork)。

## cache 带(承 3.3)
- 主轨正下方一行,与柱 **1:1 同 flex 轴对齐**;每格 = 该步 `hit_ratio`,三档:**绿 = 命中复用 ≥0.7 · 琥珀 = 部分 ≥0.3 · 红 = 冷/断 <0.3**(错误步 = 红)。
- **数值取真实 usage(必拒臆测)**:`hit_ratio = cache_read/total_input` 来自 canonical `usage`/`cache_events`(承 [3.3](3.3-cache-model.md) 真相规则),MUST NOT byte-diff 结构猜。
- **保真边界(自动缓存 provider)**:带上的**数值**(命中率)三家都真;但 OpenAI/DeepSeek 无声明断点,"在哪断"仅 `structural_divergence`(结构参考,非权威)——若 UI 在带上暗示断点位置,MUST 标"结构参考"。Anthropic 有 `declared_breakpoints` = 真实断点,可如实标。
- **保真边界(canonical,不漏适配缝 · 需 RFC 才破)**:1.3 MUST 读 canonical(`usage.cache_read`/`cache_events.hit_ratio`),MUST NOT 直读 provider 原生字段名(如 Anthropic `cache_read_input_tokens`)——那会把适配缝漏进前端(不变式 3)。

## 叠加轨(overlay lanes)
- 主 lane 之外每条 lane 一行:`subagent`(🧬 独立上下文流,tick)· `monitor`(🛡 逐字复审上下文,tick,可带 `⚑` flag 数)· `aux`(notify/titlegen/quota 等杂项,tick)· `probe`(👁 count_tokens 量测,用**迷你柱 pbar** 按 token 高度而非圆点 tick)。canonical lane 集 = `main|subagent|monitor|aux|probe`([3.2](3.2-normalized-model.md));notify/titlegen/quota 是 `aux` 子类。
- **勾选/折叠显示**:每条轨标题可折叠(gutter 内 ▸/▾);**subagent 扇出(>1 条)默认收进一条折叠组轨**(review/eval fan-out 会淹没主轨),展开才逐条列。产品的"勾选叠加轨"(见 [1.1](1.1-product-definition.md)/[00](0.0-overview.md) 模块图)与此同义 = 显隐叠加层。
- **RKIND 提示进 tooltip**:每类轨的用途描述(如 monitor="逐字上下文,hover tick 看复审了什么")挂在标题 `title=`,不占水平宽度。
- **保真边界(probe)**:`probe` 是 `count_tokens` 量测调用,**非对话 payload**——它测的是"若此刻发出会多大",UI MUST 标"量测,非线上请求",MUST NOT 混入对话步计数。
- **跨轨联动(承回放骨)**:hover 一个 monitor/probe tick → 主轨点亮它"复审到第几步"的柱(reviewed)+ 一条括号;点 tick → scrub 主轨到最近时刻 + 弹该 lane call 的 detail。此联动让叠加轨解释主轨,是"层注解骨"的具体形态。

## overview+detail brush 导航(D13 · focus+context)
大 session 下"一屏 N 柱"不可读,但**撕裂 /N 对齐 = 视觉撒谎**(不变式贯穿本模块)。选定**经典 overview+detail(focus+context)**:排轴主体(`#saw`+`#rails`+cache 带+ticks)= **detail(focus)**,只渲当前视窗 `[lo,hi)` 内的 call;其正下方一条全-session **overview 概览条(context)**,上盖一个可拖拽/拉宽的**半透明 brush**,brush 覆盖的步区间 **就是** detail 的显示区间。这是 D13 从"min-width+横滚"改定的导航式(旧案见 git 史)。
- **detail 重标定(MUST · 承 /N 收敛)**:视窗 `[lo,hi)`(`0≤lo<hi≤N`,整步边界)下,detail 的 `xOf` 取视窗内位置 `(i-lo)/(hi-lo)`;主柱、cache 格、叠加轨 tick、坐标轴刻度 MUST **全部**引用同一 `xOf` 与同一 `[lo,hi)`——**同轴锁步**(错位=撒谎)。柱轴的"等宽 1/(hi-lo)"与 tick 轴的时间插值仍收敛到同一 view 轴(/N 收敛不变式在视窗内继续成立)。
- **overview 概览条(context)**:横跨整条 session `[0,N)`;**step 少(N≤60)= 每 call 一柱**(高 ∝ `total_input`,承主轨语义,可读逐柱);**step 多 = streamline**(折线 / 面积;N≤240 逐点即逐步,N>240 桶聚合降采样),桶聚合降采样时 MUST 就地标「**采样显示**」(承保真边界不变式 4——概览非逐柱真相,MUST NOT 让人误读为每步)。overview 高度小(缩略),不重复段组成/cache 细节,只给"哪里高、哪里断"的地形。
- **brush 视口(MUST)**:overview 上一个半透明矩形 = 当前 `[lo,hi)` 映射到 `[lo/N,hi/N]`。**拖 brush 体 = 平移**(`[lo,hi)` 整体滑,宽不变);**拖 brush 左/右沿 = 缩放**(改单边,`hi-lo` 变)。拖动 MUST 实时驱动 detail 重渲(或等价 transform),二者恒一致——**brush 位置 = detail 视窗**是本导航的核心不变式。视窗有下限(`hi-lo≥1`)与钳位(`[0,N]`)。
- **playhead 同步(MUST)**:playhead(承 [1.4](1.4-central-board.md))落在 overview 上按 `pos/N` 定位、恒可见(即使当前 detail 视窗未含它——让人知道"回放点在视窗外的哪边");detail 内若 playhead 在 `[lo,hi)` 则照常高亮,否则贴最近边并给"在窗外"提示。scrub 到窗外的步 SHOULD 自动把 brush 平移到含该步(follow 模式;承 1.4 状态机)。
- **取舍**:overview 牺牲逐柱精度(多 step 时降采样)换全局地形恒可见 + 单一拖拽同时给缩放(拖沿)与平移(拖体);detail 保住逐柱 + /N 锁步。相比旧案(min-width+横滚)不需水平滚动条、且给"我在整条 session 的哪一段"的 context——这正是 focus+context 之名。读取上限与本导航(显示视窗)正交;**长 session 在不撑爆内存下的显示**由 [3.5](3.5-query-layer.md) 的分页契约与 [4.3](4.3-parse-index-cache.md) 承担,本模块保证语义,不认领存储优化。

## Edge cases
- **N 巨大(长 session)**:柱宽 `1/N` 趋近 0 → **v1(D13):overview+detail brush 导航**(见上节)——detail 只渲视窗 `[lo,hi)` 内的柱(逐柱可读),overview 概览条给全局地形 + brush 缩放/平移;overview 多 step 时降采样 streamline 并标「采样显示」,probe 轨仍 `MAX=300` 采样并标。页面 body 不横滚(承下条),detail 也不靠横滚——靠 brush 收窄视窗。1.3 保证语义(视窗内等宽、全轨对齐)不因降采样/视窗切换破。
- **叠加轨事件早于/晚于主轴端点**:`xOf` 钳到 `[0,~1)`;越界事件贴端点,tooltip 给真实墙钟,不外溢柱区(承页面 body 不横滚)。
- **单步 session(N=1)**:一柱占满、cache 带一格;轴标 `#1`。
- **无叠加轨**:`#rails` 显"no other lanes",主轨 + cache 带独立成立。
- **cache 字段缺失**(DeepSeek `cache_write=NULL`)→ `hit_ratio` 仍由 `cache_read/total_input` 得;带容 NULL,MUST NOT 拿 0 冒充(承 [3.2](3.2-normalized-model.md))。
- **compaction 后柱高骤降**:合法(换血),照真显示,不当异常/不误建 fork。

## Risk / 回滚
排轴是**纯投影**(归一化表 → SVG/DOM),无副作用:换编码方案回退渲染层即可,源真相(NDJSON)与派生表不受影响。cache 三档阈值(0.7/0.3)是显示参数,可独立调而不动数据层。段组成估算若日后有 per-block token 真值,替换 `compBuckets()` 的字节代理即可、标注同步收紧;在此之前**估算标注 MUST 常驻**。
