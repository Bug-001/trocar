# asight · RFC 4.4 — 本地服务(serve 前端 + 查询传输)

> **服务意图(A2)**:意图 ①② 的**公共传输底座**——把 [3.2](3.2-normalized-model.md) 的表 / [3.5](3.5-query-layer.md) 的具名查询结果**无损送达前端**,再把前端静态资产喂给浏览器。它不产生真相,只搬运真相;是 AC-1(逐字上下文到得了前端且传输层没改字节)、AC-2(usage 到得了 cache 叠加)的"最后一公里"。
> **受众**:人(核对单机 / 只读 / loopback 三条边界是否守住)+ agent(据此实现零依赖本地服务)。
> **前置**:查询集与接口形状在 [3.5](3.5-query-layer.md)、表在 [3.2](3.2-normalized-model.md)、写侧(ETL 填数)在 [4.2](4.2-storage-etl.md);本文件定 3.5 的传输方式(已成 **D11**,写回 [00-overview](00-overview.md) 追踪表)。

## Goal

给这台个人仪器一个**零依赖、单机、只读**的本地服务:①静态 serve 自建前端(index.html + 模块 + 资产);②把 [3.5](3.5-query-layer.md) 的具名只读查询暴露成 provider 中立的 JSON 端点,供前端 scrub / 叠加 / 回放取数。**为何现在**:"服务端读 NDJSON → 返 JSON、浏览器渲染"这条最简链路已在真实 CC 采集上跑通,本文件把它固成契约。

## 前置定义(Definitions)

- **传输层(transport)**:前端与归一化数据之间搬字节的那一层。**与查询语义正交**:查询"取什么"是 [3.5](3.5-query-layer.md),传输"怎么把结果送到浏览器"是本层。
- **具名端点(named endpoint)**:一个 HTTP 路由 = [3.5](3.5-query-layer.md) 一条具名查询的传输封装;入参 = 查询参数(session id 等),出参 = provider 中立 JSON。前端 MUST NOT 绕过端点直连存储。
- **live-poll(拉取轮询)**:前端周期 `fetch` 当前状态 JSON 的模型(demo:session 1500ms、控制面同频、静态资产 4000ms 热重载)。**拉,不推**——无 SSE / WebSocket / server-push;服务不持会话状态、不主动发起任何东西。

## Plan(选定方案 + 取舍)

**定 3.5 的传输方式(D11)。** 两条路:

- **(A) 服务端执行查询,HTTP 返 JSON**〔选定 / 默认〕——查询在服务端跑(demo 现为"读 `calls.ndjson` 返记录数组",产品化后为"服务端对 DuckDB 跑 [3.5](3.5-query-layer.md) 具名查询返结果集"),浏览器只渲染。个人仪器**单机最简**:一个零依赖进程、无客户端 SQL 引擎、无 Wasm 冷启动、端点即契约。demo 已证其可行。
- **(B) 浏览器内 DuckDB-Wasm**〔备选 / 未选,留 Extension〕——把 Parquet 灌进浏览器,大 session 客户端跑 SQL、免每次 scrub 往返。代价:Wasm 装载 + 内存、把 schema 细节推向前端(与"适配缝不漏进前端"张力)、跨 session 全库分析要把全库搬进浏览器。

**取舍**:先走 (A) 打通全链路、稳住 [3.5](3.5-query-layer.md) 端点契约;**判据触发才升级 (B)**——单条 session 大到"每步 scrub 的服务端往返成为交互瓶颈"、或要在浏览器里做重交互式全库分析。契约设计上让二者**可换而不改前端**:前端只认[3.5](3.5-query-layer.md) 的具名查询结果形状,不认它来自 HTTP 还是 Wasm —— 传输是可替换实现,不是前端可见分支(护 [00-overview](00-overview.md) 不变式 3)。

> **已定(D11)**:(A) 服务端 HTTP 返 JSON = v1 落地路径;(B) DuckDB-Wasm = Extension,仅在判据触发(单 session 大到服务端往返成交互瓶颈 / 需浏览器内重交互式全库分析)时升级,且前端契约不变。已写回 [00-overview](00-overview.md) 追踪表。

## 服务形状(demo 实证的契约)

**零依赖 · 单进程 · loopback。** 仅用 `node:http/fs/path`,`server.listen(PORT, '127.0.0.1')`(demo 端口 `ATRACE_DASH_PORT` 默认 9800)。**MUST 只绑环回**;对外暴露(`0.0.0.0` / 反代出机)直接触碰"多用户 / 云端分享"Non-Goal → **必拒**(为合法远程开发而暴露 = **需 RFC 才放行**,且须先解 Non-Goal)。

**只读 · 写只经 ETL。** 服务 MUST NOT 写任何存储 —— 源 NDJSON 或派生 DuckDB/Parquet 一律不碰;写侧全走 [4.2](4.2-storage-etl.md) ETL。服务改写源 = 违反 [00-overview](00-overview.md) 不变式 2(逐字源真相 / 派生不覆盖源)→ **必拒**。承 [3.5](3.5-query-layer.md)「访问模式 MUST 只读」。

**OBSERVE-only(顺带锚定)。** 本服务只把**已采集的字节**在 loopback 上重放给自建前端,永不 originate LLM 请求、永不用被测 token 调用任何上游 → 平凡满足不变式 1,但接口设计 MUST NOT 留任何"回放即重放到上游"的口子。**此只读契约不因 D16 松动**:主动模式(见 [5.1](5.1-active-mode-reserved.md))是**独立服务/进程/模式 + 消费者授权门**,MUST NOT 在本观测 server 上开重放到上游的口子——本服务永远只读。

**控制面(opt-in · D26)。** 网页要能开/关**透明监测**(装采集 CA + steer + 开机自启)+ 显示当前转发目标——但这是 **mutation**,与上面的只读数据面冲突([4.4](4.4-server.md):66「读写模式改动=需 RFC」)。**D26 放行方式**:控制端点 **opt-in**(`asight serve --control` / `ASIGHT_CONTROL=1`),**默认关** → 默认部署里数据面**依旧纯只读**(server gate 断言不触)。开启后新增 **仅这三个**端点,直接对应底层 onboard 命令、**只 arrange 采集不 originate**(OBSERVE 不破):`GET /control/status`(只读:监测态 + **转发到的 API 端点** + CA 信任态,承 [4.1](4.1-capture-sources.md) 四问)· `POST /control/monitoring {on|off}`(→ `atraceOn`/`atraceOff`,CA import-only 用户级 · D22 + 用户级 launchd 自启对称装/撤)。**安全门 MUST**:仅 loopback + **Host allowlist**(挡 DNS-rebind)+ **CSRF token**(GET 下发、POST 经自定义头核验,挡跨源盲打)+ Origin 校验。**数据面端点仍全是只读 GET**;控制面与数据面**同进程可,但契约分离**——数据面永不因控制面变可写。gate = `test/server-control.test.mjs`(默认关时无控制口 · 开时三重门齐备 · on/off 幂等)。

**端点(demo 现状 → 产品映射)。** 均 `content-type: application/json; charset=utf-8` + `cache-control: no-store`:

| demo 路由 | 干什么 | 产品化归属 |
|---|---|---|
| `GET /` `/index.html` `*.mjs` `*.html` | 静态 serve 前端(`no-store`) | 静态资产(见下热重载) |
| `GET /api/projects` | 枚举 project→session 列表 + 人类标题 | [3.5](3.5-query-layer.md) session 选择器 / fork 树查询 |
| `GET /api/session?project=&id=` | 返该 session 的 `records`(calls)+ `probes` 序列 + `meta` | [3.5](3.5-query-layer.md) 排轴 / 回放 / cache 叠加取数 |
| `GET /api/control?class=` | 返 session-less 控制面流量(telemetry / flags / registry…) | 非核心流侧栏([2.6](2.6-detail-panel.md);session 之外的旁路,读 3.2 `control_calls` 投影) |
| `GET /api/files` `/api/trace` | legacy 日文件回退 | 淘汰,不进产品契约 |

> **保真边界(承 [00-overview](00-overview.md) 不变式 4)**:demo `/api/session` 直接返**原始解析记录**,归一化 `analyze()` 跑在**浏览器**里 —— 即 demo 是"服务端读文件 + 客户端 analyze"的混合体,**不是**成品的"服务端跑 SQL"。产品化 (A) 把 analyze/查询挪到服务端、端点返 [3.2](3.2-normalized-model.md) canonical 结果集;两者的传输契约同形,但**心智别混**:demo server 之薄不代表产品 server 之薄。此差异**必标**,勿让读者以为 demo 端点已是查询层。

**人类标题的来源(保真边界)。** session 显示名不来自线上采集字节,而是服务读**被测 harness 自己的本地存储**(demo:`~/.claude/projects/<slug>/<id>.jsonl` 的 `customTitle`/`aiTitle`,按 mtime 缓存)拼出来,好让看板与 harness 显示同名。**MUST 标为便利标签(外部来源 · 非逐字线上真相)**,UI MUST NOT 让它冒充采集到的上下文。跨 provider 时各 harness 标题来源不同 → 归各自 adapter([3.1](3.1-adapter-contract.md)),服务只消费"标题"这个中立字段。

**provider 中立(护适配缝)。** 端点出参 MUST 讲 [3.2](3.2-normalized-model.md) 的 canonical 词汇(sessions/calls/blocks/usage/…),provider 专属字段名 MUST NOT 泄漏进 JSON 契约或路由;加 provider **不新增 provider 专属端点** → 破此缝 **需 RFC**(不变式 3)。

**路径安全。** 所有外部段过 `path.basename`(demo `safeSeg`)+ 拒 `..`;静态只 serve 前端目录内文件。越出存储 / 前端目录读文件 = **必拒**。

**live-poll 与热重载。** 传输**无状态**:每请求独立返当前快照,服务不记会话游标;前端拉取驱动"空→live 无缝转正"(承 [1.5](1.5-states-aesthetics.md) 空+live 轮询)。`no-store` 是**正确性要求**,非优化:live-poll MUST 永不吃到 HTTP 缓存的陈旧响应,采集字节 MUST 永不落进任何中间缓存。demo 另有 4000ms 资产轮询做开发期热重载(`fetch('/index.html',{cache:'no-store'})`),产品可留作 dev-only。

**健壮性。** `uncaughtException`/`unhandledRejection` 记日志但**不倒**(仪器要在长采集里活着);`EADDRINUSE` 明确报错退出(端口冲突不静默半死)。承 [1.5](1.5-states-aesthetics.md) 对空 / 超长 / 多 harness 状态的容忍。

## Out-of-scope

- 查询"取什么"([3.5](3.5-query-layer.md))、表结构([3.2](3.2-normalized-model.md))、ETL 填数与增量([4.2](4.2-storage-etl.md))、解析 / 索引 / 缓存([4.3](4.3-parse-index-cache.md))、采集拿字节([4.1](4.1-capture-sources.md))。
- 前端部件渲染(2.x);本层只把数据递到部件门口。
- (B) DuckDB-Wasm 的落地(Extension)。

## 影响面

前端所有取数经此层;端点形状 = 前后端接缝。改端点契约 = 改 [3.5](3.5-query-layer.md) 传输封装,牵动全部 2.x 部件取数 → 走 [00-overview](00-overview.md) [0.1](0.1-engineering-rules.md) 的 grep-spec 自对照闸。绑定地址 / 读写模式的改动触碰 Non-Goal 与不变式 1/2/3,升级为需 RFC / 必拒。

## 验收(可跑 check · 含新测试要求)

**现有闸**:
- `test/web/dashboard-render.mjs`(产品 render gate):DOM shim 下驱动**真实** render 管道(render→renderSaw/renderRails/renderContextWindow/…),断言各面板填充 + 中央上下文窗口**逐字等于**装配请求(AC-1)。**注意**:它把 **冻结的 canonical 载荷**(服务端 `sessionView` 输出)直接注入渲染、`fetch` 被 stub 成永不 resolve —— **绕过了 HTTP 传输**,只证"给对 canonical 能渲染对",不证"服务把 canonical 送对"。

**server gate = `test/server.test.mjs` + `test/view/board-http.test.mjs`(已建 · 2026-07-16 · 覆 HTTP 边界缺口)** —— 用固定 fixture 存储在临时 loopback 端口启 `src/server.mjs`,已断言下列 **1–7 全部**(#5 的并发 poll×append 自洽快照在 board-http 里断言):
1. **传输逐字(AC-1 过线)**:`GET /api/session` 返回的记录里逐字字段(system/messages 块文本、raw payload 锚)经客户端解析后**与 fixture `calls.ndjson` 源字节逐字 diff = 0**(JSON 再编码 MUST NOT 丢字节 / 改义;元数据字段除外且带 `faithfulness`)。这把 render gate 的 AC-1 从"进程内"延伸到"过 HTTP 线"。
2. **头部**:所有响应带 `cache-control: no-store` + 正确 `content-type`。
3. **路径穿越**:`id=../../…`、`/..%2f…` 静态请求被拒,不返存储 / 前端目录外的任何文件。
4. **只绑 loopback**:服务仅在 `127.0.0.1` 可连;非环回接口连不上。
5. **只读**:一次请求周期内存储文件 mtime/inode 不变;并发 poll 与 [4.2](4.2-storage-etl.md) append 同时发生时,读到的是自洽快照(不半行、不串行损坏)。
6. **404**:未知路由 / 缺失 session 返 404,不 200 空壳冒充。
7. **provider 中立**:返回 JSON 的键是 [3.2](3.2-normalized-model.md) canonical,无 provider 专属字段泄漏(护不变式 3)。

**产品全绿线 = `npm test`(node:test)**,已把 server gate(`test/server.test.mjs` + `test/view/board-http.test.mjs`)+ render gate(`test/web/dashboard-render.mjs`)+ 采集/ETL/adapter 各闸串成一条覆盖采集→存储→**传输**→渲染整条链的离线绿线(取代 demo 的 `run-selftest.sh`)。验收 #5「并发 poll 与 ETL append 同时读到自洽快照」已在 board-http 断言(源 NDJSON 读经 `readRecords` 逐行 `try/catch`,半行丢弃、不串行损坏)。

**源可为目录(多物理源 · 2026-07-17 · 承 D20)。** `ASIGHT_SOURCE` 既可是单个 NDJSON,也可是**一个目录**——`makeRecordLoader` 读目录内**每个 `*.ndjson`**(非递归,绝不下探 `~/.atrace` 的 GB 级 dump),逐文件 `readRecords` **独立流式**读入再拼接(峰值单串 = 最大单文件,守 4.4:91 / D24(i));session 归组按 [3.4](3.4-session-identity.md) 线上信号在 board 下游做(承 **D20**:采集只按物理源分文件、不按 session 预分流)。落地事实:`~/.atrace/asight/` 汇 `codex-capture.ndjson`(反代 tee)+ `claude-capture.ndjson`(产品 MITM,见 [4.1](4.1-capture-sources.md)),**一个 9810 的 session 选择器并列列出两 harness 的 session**(🖥 CC-Desktop / ⌨ Codex)。memo `sig` = 目录内各文件 `size.mtime` 串联 → 任一 append/新文件即失效重算。gate = `test/server-dir-source.test.mjs`。

## Edge cases

- **大 session × (A)**:每步 scrub 的服务端往返若成瓶颈 → 这正是升级 (B) 的判据触发点(记度量,别提前优化)。分页 / 惰性契约承 [3.5](3.5-query-layer.md)。**`/api/session?cursor&limit` 游标契约已落地(2026-07-16,承 [3.5](3.5-query-layer.md))**:重载荷(`rec`/`flat`/`norm.text`)只回窗口内 call、全 call 轻量 meta 恒回、窗口外标 `paged_out`;前端虚拟化按需分页取窗口是"别提前优化"的下游(demo 复用板默认取全量、行为不变)。
- **超大 trace 的内存**:demo 现把整条 `calls.ndjson` 读进内存返给浏览器,已撞 V8 ~512MB 字符串上限(见 `atrace-ops-hazards` / commit 8fb1aed);demo 的**只读最近 ~200MB 尾 + 截断标**是 **v0 止血**,非产品方案。产品从根上免除全量入内存:**① [3.2](3.2-normalized-model.md) `content_hash` 去重**——同一上下文块跨百 call 只存一次(杀掉 append-only 的二次方增长源头);**② (A) 服务端只回当前视图所需的页/单 call**(不再整条下发,承 [3.5](3.5-query-layer.md) 分页/惰性);**③ D6 前端虚拟化**——只渲可见 DOM;**④ [4.3](4.3-parse-index-cache.md) 解析/索引缓存**。故产品前端**永不**持有整条 trace,截断/上限不再需要。
  - **回源 resolver MUST 惰性(2026-07-16 · 承 D24(i))**:AC-1 全文回源([3.5](3.5-query-layer.md) `callContext` → `src/query/source.mjs`)MUST NOT 把整个源文集载入内存。**当前缺陷**:`buildResolver` 启动即把**每条记录的 `req_body` 全量塞进 Map** → 常驻 RAM ≈ 源总字节 ≈ **O(N²)**(躲过单串 512MB 上限,但**非**聚合 RAM,与本条 ② 的意图相悖)。**修复**:建 `recordId→文件字节偏移`索引,每次回源 `fs.read(fd, buf, 0, span, offset)` + slice——per-step 只读**当前视图那点字节**,常驻 RAM 降到 O(N) 个小索引项。**board→DuckDB 迁移 gate 在此**(D24):resolver 未惰性前,DB-源全文回放仍背同一 O(N²) 常驻内存。
- **poll 与 append 竞态**:ETL 正 append 时前端在 poll → 读到自洽快照即可(NDJSON 行原子;半行丢弃如 demo `readNdjson` 的 `try/catch` 逐行容错)。
- **端口占用**:`EADDRINUSE` 显式退出(非静默),onboard 需可换端口(env 覆盖)。
- **标题源缺失 / 改名**:harness 本地 store 无该 id → 标题 `null`,前端回退到 id 短码(demo 已如此);标题非真相,缺了不影响回放。
- **控制面流量**:session-less 旁路([2.6](2.6-detail-panel.md)),与核心 session 回放解耦,MUST NOT 混进 session 端点。

## Risk / 回滚

传输层是**纯搬运**(无状态、只读、纯函数式请求→响应):改端点不动数据,可即时回退;(A)↔(B) 因契约同形可整体替换而不动前端。绑定地址 / 读写权限是安全敏感面,改动 MUST 过 grep-spec 闸并由人核对(触 Non-Goal / 不变式 1/2/3)。

## Extensions

- **(B) DuckDB-Wasm 传输**:已定为 **Extension(D11)**,判据触发后引入,前端契约不变(同形结果集)。
- **单价表 = 可编辑配置(D14)**:服务端存可编辑 `pricing.json`(或等价配置),经端点(如 `/api/pricing`)或随结果集供给;cost = `usage × 单价` 派生,不落归一化表。承 [2.2](2.2-call-turn-card.md)。
- 更多 harness 的本地标题源接入(照 [3.1](3.1-adapter-contract.md) adapter 提供中立"标题",服务不新增分支)。
