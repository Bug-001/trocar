# asight · RFC 1.5 — 关键状态 + 审美

> **服务意图(A2)**:①②**共享的呈现层横切**——不新增功能,而是定义所有 1.x/2.x 视图**在边界数据下如何退化**(关键状态)与**长什么样**(审美);把"招牌视觉"钉成一套跨视图一致的视觉语言,直接支撑 ①(逐字看板)②(多色排轴叠加)。
> **受众**:人(核对每个边界态都有明确、不误导的处理)+ agent(据此实现渲染退化分支与主题 token,不各视图自造)。
> **前置**:壳/顶栏在 [1.2](1.2-shell-layout.md);排轴在 [1.3](1.3-timeline-tracks.md);中央看板在 [1.4](1.4-central-board.md);状态里"是不是空/错/多"的判定字段来自 [3.2](3.2-normalized-model.md)(`faithfulness`/`error`/`compaction`)与 [3.4](3.4-session-identity.md)(`confidence`)。语法来源 = [00-overview](00-overview.md) D2(行为回放为骨·cache 叠加)/ D6(借 Perfetto/时间旅行/LLM-obs)。

## Goal
两件事,一处定死:
1. **关键状态矩阵**:枚举"数据不理想"的态(空 / 超长 / 多 harness / 控制台 session-less / 中断错误 / compaction),各给**一个确定的、不误导人的退化处理**——尤其:非逐字的地方 MUST 就地标(承不变式 4)。
2. **审美维度**:明暗双态的**语义色 token**、等宽/无衬线**排版分工**、以及"招牌视觉 = 多色排轴 + 逐字看板"的视觉语汇——让三家 provider 的 session 在**同一镜头**下同构呈现。

这两件事已经跑通;本文件把其**已实现的设计**固化为产品约定,非描述文件本身。

## Definitions
- **关键状态(key state)**:渲染管线必须显式分支的**边界数据形态**(≠ 正常态)。每个态 = 触发条件 + 退化处理 + 保真标注。
- **语义色 token**:`--bg/--panel/--fg/--accent/--green/--amber/--cyan/--purple/--pink/--red…`(demo 14 个)。色**不硬编码**,只经 token;明暗两套值切换。
- **context-type 配色**:上下文块**按 kind 固定映射到色**(与 [3.2](3.2-normalized-model.md) `block_contents.kind` 对齐),排轴堆叠柱与看板块共用:`tools=amber · system=purple · user=accent · assistant=green · thinking=pink · tool_use=cyan · tool_result/image=dim`。

## Plan(选定方案 + 取舍)
**选定**:**状态退化集中在渲染层的少数分支函数**(demo:`renderEmpty` / `render` 里 `!anchor` 早退 / `ctrlmode` 类切换 / 柱高与 `.err` 类),**审美全经 CSS 变量 + 语义类**(无内联颜色)。明暗:`:root` 存暗色默认 → `@media (prefers-color-scheme:light)` 覆写 → `:root[data-theme=…]` 手动覆盖**两向都赢** OS 偏好(承 artifact 主题规范)。
**备选(未选)**:① 每视图各自处理空/错态——退化不一致、漏标保真;② 单一主题硬编码色——换主题要改各处、且盲人。
**取舍**:集中分支 + token 化让"加一个态 / 换一套色"是**一处改动**;`data-theme` 覆盖层留出手动切换钩子而不锁死 OS 联动。**代价**:demo 尚**未**接 JS 切换器(只有 CSS 覆盖选择器就位)——列 Extension。

## 关键状态矩阵(demo 已实现)

| 状态 | 触发(判定字段/条件) | 退化处理(demo realized) | 保真标注 |
|---|---|---|---|
| **空·无 session** | picker 无可选 / 无 project | `renderEmpty("No sessions captured yet…run through the MITM")`;清空所有面板(saw/rails/ctxwin/nav/resexp/rawpanel/cacherow) | — |
| **空·session 无 LLM call** | `!anchor`(无 main lane) | `renderEmpty("No LLM calls traced yet")` + stats 清空;**早退**,不渲染骨 | — |
| **空·某步无请求** | error/probe 步无 `rec.request` | 看板出 "No request captured for this step (a probe or an interrupted call)" | 标"无请求",不留白骗人 |
| **超长·千 call** | anchor.calls 极多 | **D13 overview+detail brush 导航**([1.3](1.3-timeline-tracks.md)):detail 只渲 brush 窗 `[view.lo,view.hi)` 的柱(逐柱可读)、overview 概览条给全局地形 + brush 缩放/平移(step 多降采样 streamline 标「采样显示」);probe tick **抽样** `MAX=300, step=⌈n/300⌉`;**整条 rail 点击取时间最近的窗内真 call**(窗内每 probe 可达,不止渲染出的 tick) | detail 靠 brush 收窄非横滚;抽样 tick ≠ 全量;点击命中真值(非近似) |
| **超长·长块** | 块正文 > 阈值(demo `COLLAPSE=600` 折叠、`20000` 截断) | 上下文块**惰性填充**(默认 collapsed,展开才 `fill` 正文);正文 >20000 char → `slice(0,20000)+"… (N chars total)"` | **截断 = 保真边界,MUST 标 total 字数**;kind=tools **新 trace 逐字 schema**(D15,展开渲染 `input_schema`)、**旧 trace 只元数据**(`schema text not retained`)亦标 |
| **超长·多 subagent lane** | `subs.length>1` | 多条短 subagent 轨**归一到 ONE 折叠组轨**(默认收起),不淹没对话骨 | — |
| **多 harness / provider** | `sessions.harness/provider`(demo:`meta.entrypoint`) | 顶栏 `agentChip` 标 provider·入口(`🟠 Claude Code · Desktop/CLI`);picker `optgroup` + `🖥/⌨` 图标 | 由**归一化字段**驱动,通用视图**不按 provider 分叉**(承不变式 3) |
| **控制台·session-less** | 无会话 id 的流量(CC 无 `x-claude-code-session-id`) | `body.ctrlmode`:隐藏 saw/rails/右页,切 timeline+ledger;按 control/account/registry/telemetry/other 分类;**排除出会话 picker** | telemetry 事件体**未上采集**,标 "request body isn't decoded for non-LLM calls; the response is" |
| **中断 / 错误 call** | `response.status≠200` | **红柱**(固定矮高 20px)+ `::after "⚠"`;`errStats()` 汇 "N×status (retries)" 红字;rail 上红 `.errtick` | — |
| **compaction** | message_count 骤降(**推断**,非显式;见 [3.4](3.4-session-identity.md)) | 柱 `::after "✂"` + 红 compaction 事件 | 推断态,`confidence=medium`,UI MUST 可区分"确证 vs 推断" |

> **保真边界(必拒隐瞒)**:上表每个"标注"列非装饰——truncated / metadata(tools schema)/ telemetry-body-not-captured / compaction-inferred 都是**未逐字保真**的点,数据层已带 `faithfulness`([3.2](3.2-normalized-model.md))/ `confidence`([3.4](3.4-session-identity.md)),UI **MUST 就地渲染标记**;让人误以为看到完整线上真相 = **必拒**。

## 审美维度(demo 已实现)
1. **明暗双态(SHOULD 一致)**:全色经 ~14 个语义 CSS token;`:root` 暗默认 → `@media (prefers-color-scheme:light)` 亮覆写 → `:root[data-theme="dark"|"light"]` 手动覆盖**双向压过** OS 偏好。新增 UI **MUST NOT** 内联颜色,只引 token(否则一套主题下必然出盲点)。
2. **排版分工(SHOULD)**:等宽 `--mono` **专供** id / 数值 / token 数 / 时间 / endpoint / hash(`idchip`/`rc`/`cbchars`/`sawaxis`/`stepno`…);无衬线 `--sans` 供叙事文案。两栈**不混用**——等宽是"这是机器事实"的视觉信号。
3. **招牌视觉(★ 服务 ①②)**:
   - **多色排轴**:每 call 一根**按 context-type 分段堆叠**的柱(`CT_ORDER` + 图例 swatch),一眼看出这步上下文由什么构成、什么随步变化 → 喂 ②。
   - **逐字看板**:正中是 byte-verbatim 的上下文窗(逐字回放,AC-1)→ 喂 ①,是产品的"示波器屏"。
   - **Perfetto/Nsight 语汇**:固定左 gutter(`--gut:140px`,轨道标题右对齐)+ 时间对齐 lane(`.trow` grid、`xOf()` 定位 tick/pbar);多轨、可折叠、时间同轴。
   - **时间旅行 scrub**:playhead + `←/→` 键 + `.bar.cur` 高亮 + reviewed bracket(承 D2 骨 / D6 借"时间旅行 scrub+diff")。

## 影响面
横切**全部 1.x/2.x 视图**:任何视图新增/改渲染 MUST 复用本文件的状态分支约定与色 token,不自造空/错态、不内联色。改语义色映射或状态集 = 改共享呈现契约 → 走[0.1](0.1-engineering-rules.md) 的 grep-spec 自对照闸。

## 验收(可跑 check)
**已有闸(MUST 持续绿)**:

**本模块 NEW 测试 MUST 断言(补进 render 闸或新文件)**:
1. **空态**:喂零 call / 无 anchor 的 trace → `ctxwin` 含 `.empty` 且 saw/rails/resexp/rawpanel **全被清空**(不残留上一 session chrome)。
2. **错误态**:含 `status≠200` 的 call → 对应柱带 `.err` 类与 `⚠`,该步看板出 "No request captured"; `errStats()` 文案含该 status。
3. **超长·截断保真**:喂正文 >20000 char 的块 → 展开后正文以 `"… (N chars total)"` 收尾(**截断必标 total**);tools 块——D15 verbatim trace 展开见 `input_schema`、旧 v0 trace 正文含 `schema text not retained`(per-block badge 区分)。
4. **超长·虚拟化**:喂 >300 probe 的 lane → 渲染 tick 数 ≤ `MAX(300)`,但按任意 x 调 nearest-click 解析出的 call index **命中真值**(非四舍五入到抽样点)。
5. **明暗覆盖**:`:root[data-theme="light"]` 存在时,其 token 值**压过** `@media(prefers-color-scheme:dark)`(两向都测);且全表色仅经 token(grep 渲染输出**无**内联 `#hex`/`rgb(`)。
6. **多 harness 字段驱动**:agentChip 文案**仅由归一化 `harness/provider` 字段推出**;喂 Codex/DeepSeek 归一化行,通用视图 DOM 结构**不因 provider 改**(AC-3 呼应,证适配缝不漏进前端)。

## Edge cases
- **空 + live 轮询**:空态下轮询继续,新数据到 MUST 无缝转正常态(demo:`ctrlmode` 离开时 `controlSig=null` 强制全量重渲染,防旧 session header 卡住)——状态切换 MUST 清净残留。
- **错误柱同时 compaction**:`.err` 与 `.compact` 标记可并存(status 优先视觉,✂ 仍标)。
- **超长 + 多 subagent**:两态叠加时组轨折叠优先,避免 rail 区被 fan-out 淹没。
- **主题切换瞬时**:CSS-only 切换无重排数据;若日后接 JS 切换器,MUST 只切 `data-theme` 属性、不重跑 render(纯样式)。
- **控制台 telemetry**:响应体是 accepted-count 而非原事件——UI 已标,MUST NOT 让人误读成"看到了上报内容"。

## Risk / 回滚
状态退化与配色是**纯呈现**,不碰源真相(NDJSON)与归一化表——回滚任一态/主题只改渲染层,数据无损。风险点单一:**漏标保真**(截断/元数据/telemetry 未标)= 违反不变式 4 → 由上列 NEW 测试 3、错误态测试兜底,回归即挡。

## Extensions
- **JS 主题切换器**:接一个 toggle 写 `data-theme`(覆盖选择器已就位),持久化偏好——不在 v1 render 闸内,补测再上。
- **无障碍**:色盲安全副色/图案编码 context-type(现纯色区分);高对比模式(多一套 token)。
- **provider 徽标**:多 harness 态下 agentChip 换真 provider 图标(Anthropic/OpenAI/DeepSeek),仍**字段驱动**、不分叉视图。
- **人工纠正 UI**:compaction/合成 session 的低 `confidence` 态允许人工确认/改判(承 [3.4](3.4-session-identity.md) Extension)。
