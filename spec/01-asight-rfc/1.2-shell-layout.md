# asight · RFC 1.2 — 外壳布局

> **服务意图(A2)**:意图 ①(**左页 = 回放骨**的宿主 + 顶栏按 session 导航)+ 意图 ②(**右页 = 叠加为翼**:资源管理器 + 原始流 panel 的宿主)。外壳是让两意图**同屏共存**的框架——D2「回放为骨 · 叠加为层」的空间兑现。
> **受众**:人(核对「骨占主舞台 · 翼常驻不喧宾 · 同名 session 不混」是否成立)+ agent(据此建 header DOM 槽位 + 左右页容器 + harness 查表)。
> **前置**:fork/branch 判定 [3.4](3.4-session-identity.md);顶栏所读列 [3.2](3.2-normalized-model.md);被托管部件 1.3/1.4/2.4/2.5/2.6;审美变量 [1.5](1.5-states-aesthetics.md)。

## Goal
定义 asight 的**外壳(shell)**:一根顶栏(harness 身份 · path · session 标题 · fork/分支)+ 左右两页(左=回放骨,右=叠加翼)+ 二者间**可调边界**,并给 session-less 控制面留一个降级模式。外壳只搭骨架与投影顶栏,**不装被托管部件的内容**(那些各归其模块)。

## 前置定义(Definitions)
- **外壳 / shell**:header + `#pages`(左右页 + divider),所有 1.x/2.x 部件的宿主容器。
- **左页 / left page(回放骨)**:`#leftpage` —— 排轴(1.3)+ 叠加轨(1.3)+ outline(2.5)+ 中央看板(1.4)。意图① 的舞台。
- **右页 / right page(叠加翼)**:`#rightpage` —— 资源管理器(2.4)+ 可关闭原始流 panel(2.6)。意图② 的翼。
- **可调边界 / divider**:`#divider`,左右页配比交给人的分隔条。
- **顶栏身份块 / identity block**:`.ident` = agentChip · sessTitle/sessMeta · forkChip。

## Plan(选定方案 + 取舍)
**选定**:**B = 左右页 · 左回放骨 / 右叠加翼 · 可调边界 · 控制台模式隐右页 · 窄屏上下堆叠。**
**备选(未选)**:① 单页 + 右侧抽屉浮层——叠加翼与回放骨**不能同屏并看**,违 D2「回放为骨 · 叠加为层」的同屏诉求;② 三栏固定等宽——资源翼挤占回放骨主舞台,窄屏无法优雅退化;③ tab 切换「回放 / 资源」——撕裂「一条主线承载两目的」(D2)。
**取舍**:左右页让**骨占主舞台、翼常驻可视又不喧宾**;可调边界把主/翼配比交给人;控制面另开模式,不污染会话外壳。

## 顶栏(top bar · 身份块)
自左而右:品牌标 → 会话选择器 `#fileSel`(project · session,按项目 optgroup 分组;entrypoint 图标 🖥 Desktop / ⌨ CLI;`🧬` 标含子 agent;call/probe 计数;末尾挂 `⚙ session-less` 组)→ 身份块 `.ident`(`max-width:52vw`)→ live 指示 + 采集健康指示 `#caphealth`(D38:采集器 / CA / 旧采集的状态与最近 24 h 的失败数,永不留空;有自己的轮询,不随「live」勾选停;不依赖 `--control`;点开进 `⚙ session-less` 组的「采集健康」项,状态见 [1.5](1.5-states-aesthetics.md))+ spacer + stats(turns / 🛡 monitors / 👁 probes / 🧬 subagents / ✂ compactions / peak ctx / 错误重试)。

- **agentChip**(`#agentChip`)——**留他 harness 缝的锚点**。demo 现渲 `🟠 Claude Code · Desktop` / `· CLI`(由 `meta.entrypoint` 分 desktop/cli),缺省 `🟠 Claude Code`。emoji+色+label **MUST 由 `sessions.harness`/`entrypoint`([3.2](3.2-normalized-model.md))查表得**;MUST NOT 把单 harness 硬编码成外壳分支(**适配缝不漏进前端 · 需 RFC 才放行**)。加 harness = 加一行查表(Codex / DeepSeek 各自色),**不碰外壳骨**——这正是 AC-3 在外壳层的兑现点。CC 的 Desktop/CLI 分型对应 [4.1](4.1-capture-sources.md) 采集源差异(Desktop 只能 MITM、CLI 可反代)。
- **sessTitle / sessMeta**(`#sessTitle` / `#sessMeta`):标题(缺 → `untitled session` / `—`);meta = `project_path`(或 slug)· `idchip`(session_id 前 8 字符,mono、最暗)。idchip = **同名 session 的消歧键**(承 [3.4](3.4-session-identity.md))。
- **forkChip**(`#forkChip`)——默认隐;两路**独立信号**叠加(demo):
  - `🧬 N branch(es)` when `A.stats.subagents > 0` —— 本 session spawn 的子 agent 分支(承 3.4「子 agent = parent 血缘,非 fork」)。
  - `⑂ N× same-name` when `projectsFlat` 里同 title 的 session > 1 —— 「别的 session 同名 → 疑似 fork / 不同分支;idchip 消歧」。
  - 二者可并显(` · ` 连);tooltip 就地释义。
  - **保真边界(承 3.4 · 必拒隐瞒)**:`⑂ same-name` 是**纯启发式推断**(仅按标题字符串相等),**非确证血缘**;`🧬 branches` 才是 CC 侧 `cc_is_subagent`+prompt 认亲的血缘(confidence medium/high)。外壳 **MUST 视觉区分「确证血缘 vs 同名猜测」**(承 3.4 的 `native_id_confidence`),MUST NOT 让 same-name chip 冒充确证 fork。Codex 有显式 `forkedFromId` → 该信号**升级为确证 fork 树入口**(3.4),不再是 same-name 猜测。
  - **判定逻辑权威在 [3.4](3.4-session-identity.md)**;本模块只管**视觉呈现**(承 3.4 Out-of-scope「顶栏视觉在 1.2」)。

**保真边界(顶栏整体)**:顶栏显示的是**派生元数据**(title / id 截断 / 计数 / fork 推断),非线上 payload 逐字——这是**导航层**,不是回放层。无需逐字标注,但 MUST NOT 让这些投影**看起来像线上原始字段**(逐字真相在左页中央看板 1.4 / 原始流 panel 2.6)。

## 左右页(B 布局)+ 可调边界
- **`#pages`**:header 下的主区,flex 横排,`flex:1;min-height:0`。
- **`#leftpage`(回放为骨)**:`flex:1` 纵列 —— `#saw` 排轴(1.3)+ `#rails` 叠加轨(1.3)+ `<main>`(outline `#ctxnav` 2.5 + **`#maindiv` 边界** + 中央看板 `#ctxwin` 1.4)。意图① 的容器。
- **`#divider`(左右页可调边界)**:6px 竖条,`cursor:col-resize`,虚线纹,hover 转 accent。分隔左右页的**可调边界**。
  - **realized(已接线)**:demo 现已接 Pointer Events 拖拽 → 设 `--rightpage-w`(CSS 变量驱动 `#rightpage` 宽),带 `MIN=220`/`MAX` 夹取 + `localStorage['atrace.split.rightpage']` 持久化 + 双击复位;shim 无 `setPointerCapture` 时 try/catch 静默(不炸 render 闸)。
- **`#maindiv`(outline↔中央看板可调边界)**:`<main>` 内 outline(`#ctxnav`)与中央看板(`#ctxwin`)间的第二根竖 gutter,同款 `col-resize` + Pointer 拖拽 → 设 outline 列宽(CSS 变量,如 `--outline-w`,默认 270)+ `MIN`/`MAX` 夹取 + `localStorage['atrace.split.outline']` + 双击复位。承 Q1(outline↔center 也要可调);同 `#divider` 的防御(shim 静默)。**两根边界互不耦合**:各自 CSS 变量 + 各自持久化键。
- **`#rightpage`(叠加为翼)**:`flex:none;width:320px` 纵列,`border-left`。上 = `#resexp` 资源管理器(2.4,`flex:1` 滚动)+ 下 = `#rawpanel` 可关闭原始流 panel(2.6,`max-height:42%`,`.rpx ✕` 关闭 / 切回 call raw)。意图② 的容器(资源生命周期 + 原始数据流)。

## 外壳模式(shell modes)
- **session mode**(默认):左页 + divider + 右页全在。
- **control mode**(session-less / control-plane,`body.ctrlmode`):选中 `__control__`(无 `x-claude-code-session-id` 的 session-less 流量)→ `body.ctrlmode #rightpage,#divider{display:none}` **隐右页 + divider**,左页 `<main>` 切成 timeline+ledger 栅格。承 **D9**([0.0-overview](0.0-overview.md))+ [2.6](2.6-detail-panel.md) §C:session-less 控制面流量**捕获但排除出会话选择器**(`calls.class='control'`,不进 `sessions`)。往返离开时 `controlSig=null` 强制全 re-render,防陈旧 session 顶栏残留。
  - **保真边界**:control-plane 的 telemetry **事件体不在线抓**(只有 response = accepted count),非 LLM 调用**只存响应体**(承不变式 4)。该标注归 2.6/4.1;外壳只负责「此模式隐右页」。

## 窄屏(responsive)
- `@media(max-width:900px)`:`#pages` 转纵堆(`flex-direction:column`),右页 `width:auto` + `max-height:38vh` + `border-top`(非 border-left),divider 隐 → **上下堆叠,翼降到骨下方**。
- 更窄(≤820px):`<main>` 的 outline `#ctxnav` 另隐(归 1.4/2.5),外壳左右堆叠仍成立。
- 明暗双态由 `:root` / `@media(prefers-color-scheme)` / `[data-theme]` 变量驱动;外壳只**消费变量**,MUST NOT 硬编码颜色(审美权威在 [1.5](1.5-states-aesthetics.md))。

## 影响面
外壳是所有 1.x/2.x 部件的**宿主容器**,顶栏读 `sessions`([3.2](3.2-normalized-model.md))的 `harness / entrypoint / title / native_id / 血缘`列。改外壳骨(左右页结构 / 顶栏槽位)= 波及每个被托管部件 → 慎(走[0.1](0.1-engineering-rules.md) 的 grep-spec 自对照闸);加 harness 只碰 agentChip 查表、不碰骨。

## Edge cases
- **空 session**:`renderEmpty` → 左页 `#ctxwin` 空态文案,右页 `#resexp`/`#rawpanel` 清空;顶栏 sessTitle=`—`、forkChip 隐。
- **超长 title**:sessTitle `text-overflow:ellipsis`;`.ident` `max-width:52vw` 夹取,顶栏 `flex-wrap` 兜底换行,不撑破。
- **同名 session 巨多**:`⑂ N×` 只给计数入口,不在 chip 内展开列表(列表归选择器 / 3.5)。
- **control mode 往返**:`controlSig=null` 强制全 re-render,防旧顶栏残留(见上)。
- **divider 拖到极窄/极宽**:接线后 MUST min/max 夹取,防右页压没或吃光回放骨。

## Risk / 回滚
外壳是**纯布局 + 顶栏投影**(读归一化列渲染,无状态变更),改动可按 CSS / 槽位独立回退。两根 divider drag 已接线(CSS 变量 + localStorage),纯加法、可单独回退(删 handler + 变量回落默认宽)。harness 查表加行是纯数据,回退 = 删行。
