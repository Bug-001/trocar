# asight · RFC 1.2 — 外壳:侧栏 · 页头 · 回放台布局

> **服务意图(A2)**:意图 ①② 的宿主。左侧栏把互不相交的区分开,只做导航;回放台以外每屏一个只放屏名、范围和读取时间的页头;回放台沿用 B 布局(左页 = 回放骨,右页 = 叠加翼),用会话头代替页头。D2「回放为骨 · 叠加为层」的空间兑现不变。
> **受众**:人(核对:侧栏只导航;页头和会话头不放统计;保真事实看得见;骨占主舞台,翼常驻不喧宾)+ agent(据此建侧栏、路由、页头、会话头、左右页容器与 harness 查表)。
> **前置**:看板词表、标记、关键状态矩阵、数据规则 [1.5](1.5-states-aesthetics.md);命中、估价、缓存判定 [2.2](2.2-call-turn-card.md)(`core/metrics.mjs`);lane 种类表 [2.1](2.1-track-widget.md);血缘判定 [3.4](3.4-session-identity.md);服务端补充 `sessions` 的 `title_source` · `/` 的静态托管 · `sessions` 的多 harness 字段 [4.4](4.4-server.md) §看板 v2 需要的补充;决策 D18c([0.0](0.0-overview.md))。

## Goal

定义 asight 看板的外壳:
- 左侧栏只做导航:总览 · 会话 · 采集 · 流量 · 设置。它不写状态、计数和新闻。
- 回放台以外,每屏顶上一个页头:屏名或面包屑、范围控件、「数据读于 HH:MM:SS」。统计、结论和说明放进它们所说明的那张表或卡片里。
- 回放台沿用 B 布局:会话头 → 排轴与叠加轨 → 左页(大纲 | 中栏)与右页(资源在上、原始数据在下),两根可拖的竖边界。会话头只放身份和导航;会话的统计放在一个信息按钮后面;这个会话哪里不全,写在会话头下面一行看得见的字里。
- 定下路由与参数、「第 N 步」的编号、弹出层的行为、断点、harness 图标,以及 v2 怎样取代 `src/web/index.html`。

外壳只搭骨架。各屏的内容归各自的单元(见 Out-of-scope)。

## 前置定义(Definitions)

- **外壳 / shell**:侧栏 + 内容区。内容区一次挂一屏。
- **侧栏 / sidebar**:左边一条导航栏。顶上是品牌标,下面五个区,区下挂子页,另有一个收起按钮。可收成 52 px 的窄栏(只剩图标)。
- **区 / area**:侧栏的一项。五个区互不相交:总览 · 会话 · 采集 · 流量 · 设置。
- **页头 / page head**:回放台以外每屏最上面的一行。只有三样部件:屏名(或面包屑)· 范围控件 · 「数据读于」。
- **页头区 / head zone**:页头,加上页头和这一屏第一张表或卡片之间的一切。
- **会话头 / session head**:回放台最上面的一行,代替页头。
- **会话保真行**:会话头下面一行安静的字,列出这个会话哪里不全。有事实才出现。
- **信息按钮 / ⓘ**:一个按钮;悬停、键盘聚焦或点击时打开一个弹出层。
- **弹出层 / popover**:按钮旁边浮出的一小块,只放文字和链接。
- **说明气泡 / tooltip**:悬停或聚焦在一个元素上时出现的一句说明。
- **提示 / toast**:浮在原地、几秒后自己消失的一句话,不推动布局。
- **左页 / 右页 / 边界**(沿用):左页 `#leftpage` = 排轴 `#saw` 与叠加轨 `#rails`([1.3](1.3-timeline-tracks.md) / [2.1](2.1-track-widget.md))+ 大纲 `#ctxnav`([2.5](2.5-outline-nav.md))+ 中栏(步头 [2.2](2.2-call-turn-card.md) 与上下文窗 `#ctxwin` [2.3](2.3-context-window.md) / [1.4](1.4-central-board.md)),意图 ① 的舞台;右页 `#rightpage` = 资源(2.4)+ 原始数据面板(2.6 §A),意图 ② 的翼;边界 = `#maindiv`(大纲 | 中栏)与 `#divider`(左页 | 右页)两根可拖的竖条。
- **步 / 调用**:见 §编号。词义以 [1.5](1.5-states-aesthetics.md) §看板词表 为准。

## Plan(选定方案 + 取舍)

**选定 A(外壳):左侧栏 + 内容区。** 理由:侧栏把互不相交的东西分开,空间利用率更高。

**备选(未选)**:
1. 一根顶栏(改写前的本单元:品牌、会话选择器、身份块、采集健康指示、统计挤在一行)——不相交的东西挤在一起,统计占了标题的位置。
2. 侧栏每项下面写状态句、计数、小灯(原型的做法)——否决:侧栏不直接放「有什么报错」「有什么新闻」;这些事项归 dashboard,点 dashboard 里的事项进到相应的子页去处理。
3. 内容区顶上一条全站横条,在「采集服务停了」「asight 挡住了 agent 的网络」时出现——同一句话否决;D38② 要的「在看板上看得到」已由首页 = 总览和采集页满足。

**首页 = 总览,也是侧栏第一项**。理由:侧栏不写状态、又没有横条以后,打开 asight 第一眼看到的那一屏,是采集失败唯一看得见的地方;D38② 要求失败「在看板上看得到」,不能只靠「没有记录」推出。深链(`#/replay/…`)照常直接打开。没装、也没采到东西时,总览显示「开始使用」([1.7](1.7-overview-dashboard.md))。

**选定 B(回放台):沿用 B 布局。** 左页 = 回放骨,右页 = 叠加翼,两根可调边界,窄屏收起右页。理由:回放台沿用既有设计,中栏放整个上下文。

**备选(未选,沿用)**:① 单页 + 右侧抽屉浮层——叠加翼和回放骨不能同屏并看,违 D2;② 三栏固定等宽——资源翼挤占回放骨,窄屏没法退化;③ tab 切换「回放 / 资源」——撕裂「一条主线承载两目的」(D2)。

**取舍**:导航和状态分开,状态只在总览和采集页。标题位置只放身份,统计放进按钮后面——统计性的话不出现在标题或小标题里(会干扰读者),overall 的统计结果归 dashboard;会话标题也不拿大片地方放总结句,改成一个悬停能看到这些信息的按钮。保真事实不进按钮,留在看得见的一行(不变式 4)。

## 页头与页头区

回放台以外每屏一个页头,从左到右只有三样部件:

| 部件 | 来源 | 说明 |
|---|---|---|
| 屏名,或面包屑 | 固定文字;host 页的面包屑 =「流量 › <agent chip> › <host>」,中段是 agent chip(路由里的 harness 经 `harnessKey()`),末段是路由里的 host | 面包屑的每段是链接 |
| 范围控件 | 路由参数(如 `window`) | 只在这一屏有范围时出现;选项由该屏的单元定 |
| 「数据读于 HH:MM:SS」 | 这一屏最后一次成功读取的本地时间 | 读不新了,按 [1.5](1.5-states-aesthetics.md) 的过期规则显示 |

- **页头区里没有句子,也没有数字**(见 Plan 取舍)。统计、结论、覆盖说明、「不全」说明,都放在它们所说明的那张表或卡片里(表注行)。守卫:`test/web-v2/shell.test.mjs`——每一屏、每一种夹具状态下,页头的 DOM 只由上表三样部件组成;页头和第一张表或卡片之间没有文字节点。
- **新鲜度**:一屏的数据来源混在一起时,页头只说「数据读于」;凡是来自具名查询的数,在它自己那张卡片或表的表注行里带「截至 <as_of>」。守卫:各屏单元的测试(`test/web-v2/overview.test.mjs`、`test/web-v2/traffic.test.mjs`、`test/web-v2/settings.test.mjs`)。
- 回放台没有页头,用会话头(§会话头)。

## 顶栏(top bar · 身份块)
自左而右:品牌标 → 会话选择器 `#fileSel`(project · session,按项目 optgroup 分组;entrypoint 图标 🖥 Desktop / ⌨ CLI;`🧬` 标含子 agent;call/probe 计数;末尾挂 `⚙ session-less` 组)→ 身份块 `.ident`(`max-width:52vw`)→ live 指示 + 采集健康指示 `#caphealth`(D38:采集器 / CA / 旧采集的状态与最近 24 h 的失败数,永不留空;有自己的轮询,不随「live」勾选停;不依赖 `--control`;点开进 `⚙ session-less` 组的「采集健康」项,状态见 [1.5](1.5-states-aesthetics.md))+ spacer + stats(turns / 🛡 monitors / 👁 probes / 🧬 subagents / ✂ compactions / peak ctx / 错误重试)。

- **agentChip**(`#agentChip`)——**留他 harness 缝的锚点**。渲 `🟠 Claude Code · Desktop` / `· CLI`(由 `meta.entrypoint` 分 desktop/cli),缺省 `🟠 Claude Code`。emoji+色+label **MUST 由 `sessions.harness`/`entrypoint`([3.2](3.2-normalized-model.md))查表得**;MUST NOT 把单 harness 硬编码成外壳分支(**适配缝不漏进前端 · 需 RFC 才放行**)。加 harness = 加一行查表(Codex / DeepSeek 各自色),**不碰外壳骨**——这正是 AC-3 在外壳层的兑现点。
- **sessTitle / sessMeta**(`#sessTitle` / `#sessMeta`):标题(缺 → `untitled session` / `—`);meta = `project_path`(或 slug)· `idchip`(session_id 前 8 字符,mono、最暗)。idchip = **同名 session 的消歧键**(承 [3.4](3.4-session-identity.md))。
- **forkChip**(`#forkChip`)——默认隐;两路**独立信号**叠加:
  - `🧬 N branch(es)` when `A.stats.subagents > 0` —— 本 session spawn 的子 agent 分支(承 3.4「子 agent = parent 血缘,非 fork」)。
  - `⑂ N× same-name` when `projectsFlat` 里同 title 的 session > 1 —— 「别的 session 同名 → 疑似 fork / 不同分支;idchip 消歧」。
  - 二者可并显(` · ` 连);tooltip 就地释义。
  - **保真边界(承 3.4 · 必拒隐瞒)**:`⑂ same-name` 是**纯启发式推断**(仅按标题字符串相等),**非确证血缘**;`🧬 branches` 才是 CC 侧 `cc_is_subagent`+prompt 认亲的血缘(confidence medium/high)。外壳 **MUST 视觉区分「确证血缘 vs 同名猜测」**(承 3.4 的 `native_id_confidence`),MUST NOT 让 same-name chip 冒充确证 fork。Codex 有显式 `forkedFromId` → 该信号**升级为确证 fork 树入口**(3.4),不再是 same-name 猜测。
  - **判定逻辑权威在 [3.4](3.4-session-identity.md)**;本模块只管**视觉呈现**(承 3.4 Out-of-scope「顶栏视觉在 1.2」)。

**保真边界(顶栏整体)**:顶栏显示的是**派生元数据**(title / id 截断 / 计数 / fork 推断),非线上 payload 逐字——这是**导航层**,不是回放层。无需逐字标注,但 MUST NOT 让这些投影**看起来像线上原始字段**(逐字真相在左页中央看板 1.4 / 原始流 panel 2.6)。

- **`#maindiv`(outline↔中央看板可调边界)**:`<main>` 内 outline(`#ctxnav`)与中央看板(`#ctxwin`)间的第二根竖 gutter,同款 `col-resize` + Pointer 拖拽 → 设 outline 列宽(CSS 变量,如 `--outline-w`,默认 270)+ `MIN`/`MAX` 夹取 + `localStorage['atrace.split.outline']` + 双击复位。承 Q1(outline↔center 也要可调);同 `#divider` 的防御(shim 静默)。**两根边界互不耦合**:各自 CSS 变量 + 各自持久化键。
- **`#rightpage`(叠加为翼)**:`flex:none;width:320px` 纵列,`border-left`。上 = `#resexp` 资源管理器(2.4,`flex:1` 滚动)+ 下 = `#rawpanel` 可关闭原始流 panel(2.6,`max-height:42%`,`.rpx ✕` 关闭 / 切回 call raw)。意图② 的容器(资源生命周期 + 原始数据流)。

## 外壳模式(shell modes)
- **session mode**(默认):左页 + divider + 右页全在。
- **control mode**(session-less / control-plane,`body.ctrlmode`):选中 `__control__`(无 `x-claude-code-session-id` 的 session-less 流量)→ `body.ctrlmode #rightpage,#divider{display:none}` **隐右页 + divider**,左页 `<main>` 切成 timeline+ledger 栅格。承 **D9**([0.0-overview](0.0-overview.md))+ [2.6](2.6-detail-panel.md) §C:session-less 控制面流量**捕获但排除出会话选择器**(`calls.class='control'`,不进 `sessions`)。往返离开时 `controlSig=null` 强制全 re-render,防陈旧 session 顶栏残留。
  - **保真边界**:D40 起非 LLM 调用的请求体与 LLM 同等逐字存;D40 之前的记录只存了请求体长度(telemetry 那时只看得到 response = accepted count),操作者设为「只记日志」的类别没有体,二者都要就地标(承不变式 4)。该标注归 2.6/4.1;外壳只负责「此模式隐右页」。同一组里另有「采集健康」与「保存什么」两项(D38 / D40,见 [2.6](2.6-detail-panel.md) §C / §D)。

## Edge cases
- **空 session**:`renderEmpty` → 左页 `#ctxwin` 空态文案,右页 `#resexp`/`#rawpanel` 清空;顶栏 sessTitle=`—`、forkChip 隐。
- **超长 title**:sessTitle `text-overflow:ellipsis`;`.ident` `max-width:52vw` 夹取,顶栏 `flex-wrap` 兜底换行,不撑破。
- **同名 session 巨多**:`⑂ N×` 只给计数入口,不在 chip 内展开列表(列表归选择器 / 3.5)。
- **control mode 往返**:`controlSig=null` 强制全 re-render,防旧顶栏残留(见上)。
- **divider 拖到极窄/极宽**:MUST min/max 夹取,防右页压没或吃光回放骨。

## Risk / 回滚
外壳是**纯布局 + 顶栏投影**(读归一化列渲染,无状态变更),改动可按 CSS / 槽位独立回退。两根 divider drag(CSS 变量 + localStorage)纯加法、可单独回退(删 handler + 变量回落默认宽)。harness 查表加行是纯数据,回退 = 删行。
