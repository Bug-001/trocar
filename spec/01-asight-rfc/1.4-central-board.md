# asight · RFC 1.4 — 中央看板(★ 招牌视图)

> **服务意图(A2)**:意图 ①(看懂 agent 行为)——中央看板是 asight 的**首页与骨**:把某一步真正发给模型的**完整上下文逐字回放**在正中;顺带承意图 ②——cache 断点/命中就地叠在同一条回放上(承 [3.3](3.3-cache-model.md))。它是对齐闸里 ①=1.4+[2.2](2.2-call-turn-card.md)+[2.3](2.3-context-window.md) 三模块中的**装配者**,兑现 [1.1](1.1-product-definition.md) 的 AC-1(逐字忠实)。
> **受众**:人(核对"我这一步看到的就是线上真相,不是某 SDK 抽象过的对话")+ agent(据此装配 board、按步 scrub 驱动、把叠加轨事件挂回同一时间线)。
> **前置**:装配序与块模型/保真字段承 [3.2](3.2-normalized-model.md)(`call_blocks` 顺序 · `block_contents.section/role/kind/faithfulness`);cache 就地标的数值真相承 [3.3](3.3-cache-model.md);块级渲染部件是 [2.3](2.3-context-window.md);左内嵌 outline 是 [2.5](2.5-outline-nav.md);scrub 来源(时间轴)是 [1.3](1.3-timeline-tracks.md);外壳/顶栏是 [1.2](1.2-shell-layout.md);session 导航语义承 [3.4](3.4-session-identity.md)。

## Goal

给一条 session 的**任一步**呈现一个**唯一的、忠实的上下文窗口**——正中一栏,按装配序 `tools → system → messages` 逐字回放这一步真正送给模型的全部输入,左侧内嵌该窗口的 outline。**按步 scrub**(←/→/Home/End 或时间轴点击)即换到另一步的窗口。cache 断点/命中与保真边界**就地叠在**这条回放上,不另开"原始 JSON 对照栏"——**窗口本身就是 ground truth**(承 demo `renderContextWindow`:"no separate raw column")。

> **永久核心不变式(非 near-term 妥协)**:中央看板对**原上下文的逐字忠实呈现是本产品的立身之本**,不是过渡态优化。**AC-1**(窗口重建 = 源 bytes,`diff=0`)是**永久核心验收**;凡非逐字处 MUST 就地标保真边界(不变式 4);**tools schema 亦须逐字**(见 **D15**,不再是 metadata 例外)。测试 / 验收 / 后续 RFC / **D7 自演化**MUST 持续守住这条——任何以「够用 / near-term」为由降解忠实呈现 = **必拒**。

## 前置定义(Definitions)

- **board(中央看板)**:session 模式下正中的那一栏 = 当前 playhead 步的**唯一忠实上下文窗口** + 就地叠加标记 + 左内嵌 outline。
- **step / playhead / scrub**:一步 = 一次 call([3.2](3.2-normalized-model.md) `calls.seq`);playhead = 当前停在哪步;scrub = 在时间轴上移动 playhead。scrub 是 board 的唯一驱动信号。
- **TURN**:messages 段里以一条**人类 user-text**(query)开头、延续到下一条 query 前的一组块——承载该轮的 assistant call turn(`thinking / tool_use / text`)与回答它的 `tool_result`。board 把 messages 分组成可折叠的 TURN 卡片。
- **骨 vs 叠加**:骨 = 忠实回放(承 D2);叠加 = cache 断点/命中、保真标、勾选轨带进来的额外事件(如安全监测)——**叠在同一条回放上,不撕成两块屏**。
- **保真边界(faithfulness)**:块的 `verbatim / metadata / opaque / summarized / omitted / truncated`([3.2](3.2-normalized-model.md));非 verbatim 的 MUST 就地标(承不变式 4)。

## Plan(选定方案 + 取舍)

**选定(承 D2:行为回放为骨 · cache 为叠加层 · 一条主线)**:board = **每步一个忠实上下文窗口**,`tools→system→messages` 装配序;messages 按 query 分组成折叠 TURN 卡;cache 断点/命中与保真边界**内联**在块流里;compaction 自然换掉整窗;左内嵌 outline;按步 scrub 驱动。

**备选(未选)**:
- ① **忠实窗口 + 另一栏原始 JSON 对照**——冗余且诱导"窗口是渲染稿、JSON 才是真相"的误读;demo 已否决(窗口即真相,无独立 raw 列)。
- ② **两块并列可切换的 board**(行为一块 / cache 一块)——违反 D2"一条主线承载两目的,首页不撕裂";cache 是叠加不是并列主线。
- ③ **messages 拉平成一长条块列**(不分 turn)——百块成墙、看不出"哪轮 query 触发了哪串 tool_use/result",丢掉 call-turn 结构。

**取舍**:一条回放同时喂 ①②——想看行为读骨、想看 cache 就近读内联标;TURN 分组把"墙"折成"每轮一张卡",默认只展开最新一轮,历史轮折叠但一键可开。**代价**:board 的交互态(哪些 turn 展开、outline 展开)是 UI 局部状态,须定清 scrub 时如何演化(见下 §折叠语义)。

## 板的组成与装配(承 demo,产品泛化)

### 装配序 · 逐字回放(骨)
窗口严格按 [3.2](3.2-normalized-model.md) `call_blocks.seq` 铺:`tools → system → messages`。每段一个 section header(⚙ TOOLS · ▤ SYSTEM · 💬 MESSAGES + 计数)。每块一张可折叠行(`ctxBlock`):头显 role · kind-tag · 短预览 · 字符数;点开惰性填正文(`ctxBody`,承 demo 惰性 body,超长按显示上限截断并**标 truncated**)。system/messages 的正文 MUST 是**线上原始字节**(承 AC-1);block 的 `section/role/kind` 全部读归一化字段,**board MUST NOT 按 provider 分支**(适配缝不漏进前端,需 RFC 才可破 · 承不变式 3)——跨 provider 的块渲染细节下沉到 [2.3](2.3-context-window.md)。

### messages → TURN 卡片(骨的可读结构)
`messageTurns`:一条人类 user-text(剥掉 `<system-reminder>` 后仍非空)开一个 TURN,延续到下一条 query;无 query 打头的前缀块归入 `(context / tool results)` 卡。折叠头显 query 预览 + 该轮动作摘要(`N tool · think · result`)+ 块数。**默认只展开最新一轮**(`turnOpen` 只含末轮),历史轮折叠。

**折叠语义(已定 D12)**:turn 的折叠态**按其 anchor 块 `content_hash` 记忆**(3.2 去重 / cache-break 键)——用户展/折一个 turn → 该 hash 进持久集(localStorage);**跨 scrub 存活**:渲某步时,每个 turn 的开合 = 查其 anchor hash(在集里则按用户态,否则默认「末轮展开、余折叠」);compaction 改写上下文 → 新 hash → 该 turn 自然当作新的(正确)。另给「全展 / 全折」便捷。**不靠 turn 索引**(索引跨步会漂移);demo 的 `turnOpen`+`lastTurnCall` reset-on-scrub 是 v0 雏形,产品升级为 content_hash 记忆。

### cache 断点/命中 · 就地标(叠加,承 [3.3](3.3-cache-model.md))
数值真相取**真实 usage**、非 byte-diff 臆测(承 3.3 MUST):
- 块级徽章:`⟐ cache bp`(provider 声明的断点,如 Anthropic `cache_control` 落在此块)、`↻ per-call nonce`(volatile 块:每 call 变字节却不入 cache key,如 CC billing nonce)。
- 前缀断点标 `⚡`(承 demo `cacheMarker`),按真实 usage 分三态诚实措辞:**整窗重算**(首块即变 → 无可复用前缀,红)/ **前缀真复用**(read>0,上方 N 块 cache-identical)/ **过期重建**(结构前缀相同但 read=0 & write>0 → TTL 过期,非"没缓存")。
- **保真规则(必拒违反)**:volatile 块 MUST 被断点计算跳过(不因 nonce 变字节误触发断点);cache 态 MUST 源自 usage,MUST NOT 用纯 byte-diff 冒充边界(demo 已证 byte-diff 会撒谎)。

### 保真边界 · 就地标(叠加,承不变式 4)
每块按 `faithfulness` 就地标,**MUST NOT 让人误以为看到的是完整线上真相**:
- **metadata(保真边界)**:tools 段——schema 全文不逐字留,只存 `name + params + descChars`;board 就地写"schema text not retained"(承 demo `ctxBody` tools 分支)。
- **opaque(保真边界)**:`thinking.signature`、`reasoning.encrypted_content` 等不可读密文——标 opaque,不冒充明文。
- **truncated(保真边界)**:超显示上限的长块——标"…(N chars total)",提示非全文。
- **summarized(保真边界)**:compaction/客户端摘要产物(如 DeepSeek 客户端摘要)——标 summarized,区别于线上逐字。

### compaction 自然换整窗
compaction = 同一 session 内换血(**非 fork**,承 [3.4](3.4-session-identity.md))。它使这一步的 messages 前缀被摘要重写 → 窗口内容自然整体不同于上一步,`⚡` 落在首条 message 块(tools+system 存活)、显示整窗重算。board **无须**为 compaction 特判分支,它是回放的自然结果。

### 左内嵌 outline + 勾选叠加轨 hook
board 左侧内嵌**本步上下文的 outline**([2.5](2.5-outline-nav.md)):tools / system / messages 各组 + cache-break 命中率行,点击跳到窗口内对应块(必要时先展开其所在 TURN)。**资源生命周期(跨步)MUST NOT 挤进 outline**——它属右页资源管理器(承 demo B-split;render 门禁断言 outline 不含 "across the session")。勾选叠加轨([1.3](1.3-timeline-tracks.md))时,选中某轨的 tick → board 就近**高亮/定位**对应块或步(如安全监测轨:CC 自身的 security-monitor 调用是**被观测**流量,选中它时 board 高亮它复核的上下文区间)。

### 按步 scrub 驱动
唯一驱动 = playhead。`setPlayhead → 重渲染窗口 + outline`;←/→ 单步、Home/End 跳首末。scrub 是纯函数式重放(同一 playhead 同一记录 → 同一窗口),无副作用写回源。

## 验收(可跑 check)

**本模块新测 MUST 断言(在渲染门禁上加断言)**:
- **装配序**:窗口内 section 顺序恒为 `tools → system → messages`;messages 段存在时必被分组成 TURN。
- **折叠语义(D12)**:turn 折叠态按 anchor `content_hash` 记忆、跨 scrub + 重载存活(localStorage)、compaction 自然重置;未触碰 turn 默认末轮展开;+ 全展/全折。
- **cache 就地标真相**:断点落在真实 usage 推出的位置——构造三态各一(整窗重算 / read>0 前缀复用 / read=0&write>0 TTL 过期),断言渲染出对应措辞;**volatile 块(↻ nonce)MUST NOT 触发断点**(billing nonce 变字节而 cache-identical)。
- **保真标**:每个非 verbatim 块 MUST 带 faithfulness 标——断言 tools 块渲染 "schema text not retained"(metadata),opaque/truncated 块带对应标;**无标即 fail**(承不变式 4)。
- **compaction**:compaction 步的窗口内容整体异于上一步且 `⚡` 落首条 message 块(整窗重算),未误建 fork。
- **跨 provider 无分支(AC-3 相关)**:喂一份归一化的 **Codex / DeepSeek** fixture(非 CC),board 同样点亮 `.cblk`/TURN/outline,且渲染路径**无 provider 专属分支**(适配缝不漏进前端)。
- **AC-1 逐字扩展**:由窗口重建的 system+messages 块字节,与 NDJSON 源对应字段 `diff = 0`(metadata 块除外且已标)。

## Edge cases
- **无请求的步**(probe / 被 interrupt 的 call):窗口显式空态"No request captured for this step",非报错、非空白(承 demo)。
- **超大 session**:窗口只渲当前步的 flat(非全 session);TURN 折叠 + 惰性 body 控 DOM 量。长块按显示上限截断并标 truncated。
- **首步 cache_read>0**:跨 session 暖前缀(tools+system 跨会话字节相同),合法,标"first captured call · warm cross-session prefix",不当异常(承 [3.3](3.3-cache-model.md))。
- **跨 scrub 折叠记忆(已定 D12)**:按 turn-anchor `content_hash` 记忆(非 turn 索引),跨 scrub + 重载存活;compaction 新 hash → 新 turn 回默认态。边角:两个 user-query 文本完全相同的 turn 会共享 hash → 共享折叠态(罕见,可接受;需要时用 hash+序号消歧)。
- **纯自动缓存 provider(OpenAI/DeepSeek)**:无声明断点 → `⟐` 不出现,`⚡` 的结构前缀标注 MUST 就近注"结构参考,非真实边界"(承 [3.3](3.3-cache-model.md))。

## Risk / 回滚
board 是**纯函数重放**(记录 + playhead → DOM),无写回源(源真相不可被 UI 覆盖 · 不变式 2)。渲染逻辑改动用固化真实记录跑渲染门禁回归即验;折叠/cache 标改动可独立回退,不影响存储层。**OBSERVE-only 红线**:board 只渲**被观测**流量;demo 面板显示的 count_tokens 探针是**被测 harness 自己发的、asight 只经采集源观测**(见 [2.6](2.6-detail-panel.md) §probe)。任何由 asight **主动发起**请求(量上下文再展示等)= 必拒,MUST NOT 进 v1 board。
