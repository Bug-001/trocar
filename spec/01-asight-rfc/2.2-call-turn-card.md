# asight · RFC 2.2 — call-turn card

> **服务意图(A2)**:意图 ①(看懂 agent 行为)——每步/每轮一张**摘要卡**,一眼看清"这一步做了什么、花了多少 token/钱、cache 命中几成",点开即坠入逐字回放;顺带把 ② 的 cache 命中作为卡上一枚 metric 抛出。是 A3 对齐闸里 ①=1.4+2.2+2.3 的中间层。
> **受众**:人(核对卡上摘要够不够看懂一步、且没冒充线上真相)+ agent(据此渲染卡,数据经 [3.5](3.5-query-layer.md) 取自 [3.2](3.2-normalized-model.md))。
> **前置**:卡**只读不拥有真相**——身份/lane 来自 [3.4](3.4-session-identity.md);token/cache 数值来自 [3.3](3.3-cache-model.md) Tier 1(canonical `usage`);逐字块内容归 [2.3](2.3-context-window.md);取数走 [3.5](3.5-query-layer.md)。卡挂在 [1.4](1.4-central-board.md) 的 scrub 骨上、由 [2.1](2.1-track-widget.md) 的 tick 点选聚焦。

## Goal

给回放骨上的**每一步(turn / lane-call)一张摘要卡**:头部一行讲清"是谁、什么时刻、往上下文加了什么"(query 预览 + 动作摘要 `N tool · think · result` + 块数),折叠态省地、**原位展开**即见该轮的逐字块([2.3](2.3-context-window.md));非主轨的 lane-call(monitor / probe / aux / subagent)点开是一张**详情卡**,列该 call 的时间 / 模型 / token / 花费 / cache / verdict / 输出。卡是**digest 层**——把线上真相压成人可扫读的一行,真相始终一次展开可达。

## Definitions

- **turn(轮)**:主轨消息流里,从一条**人类 user-text 消息(query)**起、到下一条 query 止的一段,携带其间 assistant 的 call-turn(thinking / tool_use / text)与回应它的 tool_result(承 demo `messageTurns`)。turn 是主轨卡的单元。
- **call-turn card(摘要卡)**:包住一步的**digest 信封**——头(身份 + query 预览)+ 动作摘要 + metrics(token / 花费 / cache-hit)+ 折叠控件;逐字块内容坐在卡 body 里、由 [2.3](2.3-context-window.md) 渲染。
- **lane-call 详情卡**:非 main 轨的一次 call(lane ∈ {subagent, monitor, aux, probe},见 [3.2](3.2-normalized-model.md) `calls.lane`)的点开卡(承 demo `openDetail`)——按 lane 类型差异化呈现其输入(原文)+ 输出 + 度量。
- **动作摘要(action summary)**:`N tool · think · result` 形态的一行,由该轮块的 canonical `kind` 计数派生(`tool_use`/`server_tool_use` 计数、`thinking` 有无、`tool_result` 有无;承 demo `t.acts`)。**派生自逐字块、非新真相**。
- **花费(cost)**:`Σ(canonical usage 角色 × 本地单价)` 的**本地估价**,非线上事实(见下「花费」节)。

## Plan(选定方案 + 取舍)

**选定:卡 = 纯 digest 信封,真相委派。** 卡自己只渲染"摘要 + metrics + 折叠框架";逐字块交 [2.3](2.3-context-window.md),原始 request/usage 面板交 [2.6](2.6-detail-panel.md),数值判据交 [3.3](3.3-cache-model.md)。卡读 canonical 列(kind / lane / usage),**不认 provider 原生字段**。
**备选(未选)**:① 卡自渲染块全文(把摘要和逐字揉进一个渲染路径)——省一次委派,但卡一旦改文案就可能篡改逐字 bytes,直接威胁 AC-1(逐字回放),且把 [2.3](2.3-context-window.md) 的职责撕进 2.2;② 卡直读 provider 原生 payload 拼摘要(如 demo 早期读 `rq.tools`/Anthropic 字段名)——加 provider 就得在卡里加分支,**违反适配缝不漏进前端(不变式 3,需 RFC 才放行)**。
**取舍**:digest 与逐字分层 → 卡可轻量/虚拟化(D6),truth 单一来源在 3.2/3.3;卡读 canonical → 换 provider 卡形状不变(AC-3)。

## 卡结构(承 demo,泛化到跨 provider)

**主轨 turn 卡**(承 demo `.cwturn`)——三件、折叠原位:
1. **头(`.cwturnhd`)**:折叠箭头(▾/▸)+ query 预览 + 动作摘要(`.qk`)+ 块数徽标(`.cwturnn` = 该轮块数)。有人类 query 的轮以 `🗣` 起、纯上下文/工具结果轮以 `⋯` 起并标 `(context / tool results)`。
2. **body(`.cwturnbody`)**:该轮的逐字块序列,**由 [2.3](2.3-context-window.md) 渲染**;折叠态 `display:none`。
3. **折叠态(D12)**:点头切换该 turn 的记忆态(按 anchor `content_hash` 存持久集,localStorage);默认**最新一轮展开**、其余收起;**跨 scrub / 重载存活**(不再 scrub 即重置),compaction 新 hash 自然回默认;+ 全展/全折便捷。demo 的 `turnOpen`+`lastTurnCall` reset-on-scrub 是 v0 雏形。

**lane-call 详情卡**(承 demo `openDetail`,按 lane 差异化):
- **monitor(🛡 安全检查)**:`verdict: clear/flagged`(flagged 红 / clear 绿)+ "reviewed call #1 → #k" + **该 call 的确切输入消息(原文)**,其中重复的 `<transcript>` 体**原位折叠**(只折可复现的大块,保结构可见)+ monitor system 规则折叠。verdict 文本 = 该 monitor call 的 assistant 输出块(逐字),卡只做 clear/flagged 轻解析。
- **probe(👁 count_tokens 量尺)**:measured N tokens + "payload ≈ 某 call 附近的 message_count / system chars / tool_count / 线上字节"。标注"一把尺,不是一轮——无模型输出、不计费"。
- **aux 家族**(notify / titlegen / quota / 通用):按子类给一行 lead(活动摘要 / 生成的标题 / keep-alive ping 且回复丢弃 / 通用模型+输出)+ persona + 输入(原文)折叠。
- **subagent**:独立上下文流的一次 call,点开进其自身的卡/回放(血缘归 [3.4](3.4-session-identity.md))。

> **跨 provider(适配缝)**:动作摘要的 `kind`、lane 分类、usage 角色**全来自 canonical**([3.2](3.2-normalized-model.md));Codex/DeepSeek 的 session 落进同一 canonical 后,卡形状/渲染路径**零改**即点亮(AC-3)。往卡里塞任一 provider 专属分支 = **需 RFC 才放行**(不变式 3)。

## 花费(本地估价 · 保真边界)

- **算法**:`cost = Σ_role (canonical_usage[role] × price[provider, model, role])`,角色取 [3.2](3.2-normalized-model.md) `usage` 的 `input_uncached / cache_read / cache_write / output`(承 demo `costOf` + `PRICING` 四价:input / output / cache-write / cache-read)。demo 已实现估价函数(`costOf`/`usd`,Anthropic opus/sonnet/haiku 四价),**尚未接入卡片渲染**——本 RFC 定其接入形态。
- **保真边界(必拒隐瞒)**:花费**不是线上事实**——provider 不在 wire 上返回金额;它是 asight 用**本地、可编辑的单价表**乘 canonical usage 估出的。卡上花费 MUST 就地标"≈ 本地估价"(承不变式 4);MUST NOT 让人误读为账单真相。单价表是**配置/视图层资产**,非归一化模型的一列——**cost MUST NOT 进 [3.2](3.2-normalized-model.md) 冒充采集到的真相**(逐字源真相,必拒)。
- **跨 provider**:单价表按 `(provider, model)` 扩展(Anthropic/OpenAI/DeepSeek 各自 $/Mtok,cache-read/write 折扣不同);DeepSeek `cache_write=NULL`(无写缓存概念,承 [3.2](3.2-normalized-model.md))→ 该项按 NULL 略过,不填 0 冒充。

## schema-税 · 段权重(承 D17② · 保真边界)

卡上/上下文头一枚 metric——把该步**重发的上下文按 assembly 段拆权重**:`tools · system · history · task` 四段各占多少**字节 /(估)token** + 一条迷你堆叠条 + culprit 一行。兑现研究基底痛点 #5「tool/MCP schema 税」:每请求在任何 user 消息前先吃掉多少窗口(真实 CC session 实测:tools 段早期占比可达 **53%**、中位 ~10%),常规输出里不可见。

- **段划分(render-time 投影,不入 schema)**:`tools`/`system` = 同名 section;messages 段再二分——`task` = 最新人类 user-text 轮及其在途动作(承 [2.3](2.3-context-window.md) turn 分组 / demo `messageTurns` 末轮),`history` = 其前全部块。history/task 是对 messages 段的**渲染期二分**,**MUST NOT 往 [3.2](3.2-normalized-model.md) 加列**(不变式 3)。
- **字节 = 内容真数(D15 后 tools 可测)**:段字节 = 该段各块 **verbatim 内容的 UTF-8 字节和**(demo `flatBytes` + `TextEncoder`)。它是**模型可见的内容字节**,与 `calls.request_bytes`(含 JSON scaffolding)**同量级但非逐位相等**——故读出的是**段间占比**(谁在 user 消息前吃满窗口),非绝对 wire 总额。**D15 起 tools schema 逐字采集** → tools 段权重首次可从真实字节测量;**D15 前旧 trace** 的 tools 段仅元数据估算,就近标(不变式 4)。
- **token = 估算(char/4 proxy · 必标)**:provider 只回**整包** token、不回按段 token;故段 token 是 asight 的本地字符代理估算,DOM MUST 就近标「≈tok 估算 / 字节=内容真数」。整包 token 才是真数(usage)——卡 MUST NOT 让人误读段 token 为线上事实。
- **culprit 一行**:堆叠条下给「最大段 = tools(N 字节,X%,每步重发)」,把「谁在 user 消息前吃满窗口」点出来。**逐块级归因(哪个 block 撑爆)→ [2.3](2.3-context-window.md)**;跨步增长曲线 → [1.3](1.3-timeline-tracks.md)。

## 上下文增长 Δ(承 D17② · 保真边界)

上下文头一行 growth Δ:`重发前缀 Δ = X 字节(vs 上一 call)` + **点名增量主导段**(如「+34K,mostly history」)。兑现研究基底痛点 #4「成本超线性涨却无法归因到某一步」。demo `growthLine(tax,prevTax,brk)` = 相邻两 call 段字节差、取 |Δ| 最大段为主导。**诚实上限(承 [1.1](1.1-product-definition.md))**:asight **点元凶(诊断),裁剪归 harness**——文案 MUST 是「增量来自 X」而非「应删 X」,就近标「诊断非裁剪(裁剪归 harness)」。**compaction 换血**(`brk.cause==='compaction'`)MUST 标「整窗重写,非线性追加」,MUST NOT 报一个巨大 Δ 误导成逐块新增。首 call 无 Δ。逐块级归因 → [2.3](2.3-context-window.md)。

## 保真边界一览(卡上哪些非逐字 · UI 必标)

| 卡上元素 | 保真等级 | 真相在哪 |
|---|---|---|
| 花费(cost) | **本地估价**(非 wire 事实) | 无线上金额;canonical usage × 本地单价 |
| query 预览 | **truncated + cleaned**(剥 `<system-reminder>`、截 ~90 字) | 完整逐字块一次展开可达([2.3](2.3-context-window.md)) |
| 动作摘要 `N tool · think · result` | **summarized**(块 kind 计数派生) | 逐字块在 body([2.3](2.3-context-window.md)) |
| monitor `verdict: clear/flagged` | **derived**(输出块轻解析) | 输出块原文逐字(卡内 monmsg) |
| token / cache-hit | **verbatim usage**(真相,非估) | canonical `usage`([3.3](3.3-cache-model.md) Tier 1) |
| schema-税 段权重(D17②) | **字节=内容真数(非逐位 wire)/ 段 token=char-proxy 估算** | 段字节从 verbatim 内容重算;段 token 无线上真相 |

> token 与 cache-hit 是**真数**(来自真实 usage),**不**是保真边界——卡 MUST 显示真值、MUST NOT 二次臆算(承 demo v11 教训:cache 数字取真实 usage 不 byte-diff 猜)。

- 时间轴柱 / tick 点选定位 → [2.1](2.1-track-widget.md)、[1.3](1.3-timeline-tracks.md);scrub 骨与"勾轨加事件" → [1.4](1.4-central-board.md)。

- 资源(文件/MCP/skill)生命周期 → [2.4](2.4-resource-explorer.md);取数 SQL 形状 → [3.5](3.5-query-layer.md)。

## 影响面

上游:读 [3.5](3.5-query-layer.md) 的 "call card(2.2)" 查询(`usage` + `cache_events` + `calls` 的 time/model/lane + `call_blocks` 的 kind 计数 + `block_contents.preview`)。宿主:[1.4](1.4-central-board.md) 沿 scrub 排卡,[2.1](2.1-track-widget.md) tick→聚焦卡。改**卡布局/文案** = 前端本地改,不触中心契约;但**新增一个取自新列的卡字段** = 动 [3.2](3.2-normalized-model.md) → 走[0.1](0.1-engineering-rules.md) 的 grep-spec 自对照闸。

## 验收(可跑 check)

- **既有闸(MUST 保持绿)**:渲染闸 `test/web/dashboard-render.mjs`——已在多个 playhead 位断言 messages 分组成 `.cwturn` 卡且 raw 面板含 usage(canonical read/new-cache/fresh/out),并跑 AC-1 逐字断言(system/message 块 byte-verbatim)。本模块任何改动 MUST NOT 让这些转红。
- **本模块 NEW 测试(在渲染闸内扩,针对固化真实/样本 trace)MUST 断言**:
  1. **动作摘要正确**:构造含 ≥1 `tool_use` + `thinking` + `tool_result` 的一轮 → 卡头动作摘要 == `N tool · think · result`(N=工具计数)、块数徽标 == 该轮 `items.length`。
  2. **委派逐字(AC-1 不被卡篡改)**:卡头 query 预览剥了 `<system-reminder>` 且截断,**但**展开 body 里的块与 NDJSON 源逐字 diff = 0(卡 MUST NOT 改块 bytes;逐字断言由 [2.3](2.3-context-window.md) 承接,本测试验"卡不越界改写")。
  3. **花费标注保真边界**:卡上花费 DOM 携"≈ 本地估价"标记;花费值 == canonical usage × 本地单价(可复算);且 `cost` **不出现在** [3.2](3.2-normalized-model.md) 任一表列(grep DDL 断言)。
  4. **token/cache-hit == 真值**:卡上 token、cache-hit% == 该 call 真实 `usage`(与 [3.3](3.3-cache-model.md) AC-2 同源),非二次臆算。
  5. **lane 差异化**:monitor 卡 verdict(clear/flagged)== 其输出块解析;probe 卡显 measured tokens、标"不计费";aux 卡显 model+输出。各按 `calls.lane` 正确分流。
  6. **适配缝(AC-3)**:喂一条 Codex 或 DeepSeek 样本 → 卡形状/渲染路径不变即点亮;**卡 DOM 里不出现任一 provider 原生字段名**(如 `cache_creation_input_tokens`、`prompt_cache_hit_tokens`)——只出现 canonical 语义。
  7. **schema-税段权重(D17②)**:`segTax(flat)` 把上下文拆 tools/system/history/task 四段——tools-schema 巨大的构造 trace → culprit==tools 且 tools 段 >50%;四段百分比和 ≈100;含旧轮 + 末轮的 messages → history/task 两子权重皆 >0。渲染:`.cwtax` 堆叠条 + culprit 一行在上下文头、`.cwsecw` 段权重在段 header;token 估算带「字节=内容真数 / ≈tok 估算」保真标(DOM 可断言)。demo 已验:真实 session tools 段 6–53%(早高晚低,history 增长)。
  8. **上下文增长 Δ + 块级首现(D17②)**:`growthLine(tax,prevTax,brk)`——首 call 无 Δ;有 prevTax → 显 `re-sent Δ` + 主导段 + 「诊断非裁剪」标;`brk.cause==='compaction'` → 显「compaction rewrote history · not a linear append」。`ctxBlock(b,i,prevKeys)`——新块(key 不在 prevKeys)带 `◆ new`,复用块与首 call 无标。渲染:非首 step 的 `#ctxwin` 含 `.cwgrowth`。

## Edge cases

- **无人类 query 的轮**(纯 tool_result 续跑):以 `⋯ (context / tool results)` 起,不误标成 query 轮(承 demo)。
- **超长 query / transcript**:预览截 ~90 字;lane 卡里重复大块(monitor 的 `<transcript>`)**原位折叠**而非描述替代,保结构可见。
- **interrupted / 半包 call**([3.1](3.1-adapter-contract.md) 的 error 行):卡如实标"⚠ interrupted",不显伪造 usage/花费。
- **probe/keep-alive**:probe 是量尺(无输出、不计费)、quota 是 `max_tokens:1` 回复丢弃——花费/输出 MUST 如实标"不计费 / 已丢弃",不混入主轨成本。
- **缺 usage**(某 provider 某步未返 usage):token/cache-hit/花费显 `?` 或留空,MUST NOT 填 0 冒充真数。

## Risk / 回滚

卡是**纯读渲染**(归一化行 → DOM),无副作用;用固化真实 trace 跑渲染闸做回归,改坏即回退上一绿点。花费单价表改动只影响估价显示、可独立回退,且因标了"本地估价"不污染真相层。

## Extensions

- 卡上更多可选 metric(reasoning token 单列、duration、stop_reason),照 canonical 列加、不加 provider 分支。
- 花费:接入单价表编辑 UI + 跨 provider 成本对比(挂 ② 的跨 session 分析,[3.5](3.5-query-layer.md))。**单价表 = 可编辑配置(D14)**:provider 只回 token usage(无 $ 单价),单价是外部可变量 → 存**可编辑配置**(如 `pricing.json`),cost = `usage × 单价` 派生,**MUST NOT 入归一化模型**(cost 是本地估算,非源真相)。
- 新 harness/provider:canonical 落齐即复用同一卡,零改前端(承 AC-3)。
