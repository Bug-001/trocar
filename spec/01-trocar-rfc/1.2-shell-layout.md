# trocar · RFC 1.2 — 外壳:侧栏 · 页头 · 回放台布局

> **服务意图(A2)**:意图 ①② 的宿主。左侧栏把互不相交的区分开,只做导航;回放台以外每屏一个只放屏名、范围和读取时间的页头;回放台沿用 B 布局(左页 = 回放骨,右页 = 叠加翼),用会话头代替页头。D2「回放为骨 · 叠加为层」的空间兑现不变。
> **受众**:人(核对:侧栏只导航;页头和会话头不放统计;保真事实看得见;骨占主舞台,翼常驻不喧宾)+ agent(据此建侧栏、路由、页头、会话头、左右页容器与 harness 查表)。
> **前置**:看板词表、标记、关键状态矩阵、数据规则 [1.5](1.5-states-aesthetics.md);命中、估价、缓存判定 [2.2](2.2-call-turn-card.md)(`core/metrics.mjs`);lane 种类表 [2.1](2.1-track-widget.md);血缘判定 [3.4](3.4-session-identity.md);服务端补充 `sessions` 的 `title_source` · `/` 的静态托管 · `sessions` 的多 harness 字段 [4.4](4.4-server.md) §看板 v2 需要的补充;决策 D18c([0.0](0.0-overview.md))。

## Goal

定义 trocar 看板的外壳:
- 左侧栏只做导航:总览 · 会话 · 采集 · 流量 · 设置。它不写状态、计数和新闻。
- 回放台以外,每屏顶上一个页头:屏名或面包屑、范围控件、「数据读于 HH:MM:SS」。统计、结论和说明放进它们所说明的那张表或卡片里。
- 回放台沿用 B 布局:会话头 → 排轴与叠加轨 → 左页(大纲 | 中栏)与右页(资源在上、原始数据在下),两根可拖的竖边界。会话头只放身份和导航;会话的统计放在一个信息按钮后面;这个会话哪里不全,写在会话头下面一行看得见的字里。
- 定下路由与参数、「第 N 步」的编号、弹出层的行为、断点、harness 图标,以及看板怎样托管在 `/`。

外壳只搭骨架。各屏的内容归各自的单元(见 Out-of-scope)。

## 前置定义(Definitions)

- **外壳 / shell**:侧栏 + 内容区。内容区一次挂一屏。
- **侧栏 / sidebar**:左边一条导航栏。顶上是品牌标,下面五个区,区下挂子页,另有一个收起按钮。可收成 52 px 的窄栏(只剩图标)。
- **区 / area**:侧栏的一项。五个区互不相交:总览 · 会话 · 采集 · 流量 · 设置。
- **页头 / page head**:回放台以外每屏最上面的一行。只有三样部件:屏名(或面包屑)· 范围控件 · 「数据读于」。
- **页头区 / head zone**:页头,加上页头和这一屏第一张表或卡片之间的一切。
- **会话头 / session head**:回放台最上面的一行,代替页头。
- **会话保真行**:会话头下面一行安静的字,列出这个会话哪里不全。有事实才出现。
- **信息按钮 / ⓘ**:一个按钮;悬停、键盘聚焦或点击时打开一个弹出层。
- **弹出层 / popover**:按钮旁边浮出的一小块,只放文字和链接。
- **说明气泡 / tooltip**:悬停或聚焦在一个元素上时出现的一句说明。
- **提示 / toast**:浮在原地、几秒后自己消失的一句话,不推动布局。
- **左页 / 右页 / 边界**(沿用):左页 `#leftpage` = 排轴 `#saw` 与叠加轨 `#rails`([1.3](1.3-timeline-tracks.md) / [2.1](2.1-track-widget.md))+ 大纲 `#ctxnav`([2.5](2.5-outline-nav.md))+ 中栏(步头 [2.2](2.2-call-turn-card.md) 与上下文窗 `#ctxwin` [2.3](2.3-context-window.md) / [1.4](1.4-central-board.md)),意图 ① 的舞台;右页 `#rightpage` = 资源(2.4)+ 原始数据面板(2.6 §A),意图 ② 的翼;边界 = `#maindiv`(大纲 | 中栏)与 `#divider`(左页 | 右页)两根可拖的竖条。
- **步 / 调用**:见 §编号。词义以 [1.5](1.5-states-aesthetics.md) §看板词表 为准。

## Plan(选定方案 + 取舍)

**选定 A(外壳):左侧栏 + 内容区。** 理由:侧栏把互不相交的东西分开,空间利用率更高。

**备选(未选)**:
1. 一根顶栏(改写前的本单元:品牌、会话选择器、身份块、采集健康指示、统计挤在一行)——不相交的东西挤在一起,统计占了标题的位置。
2. 侧栏每项下面写状态句、计数、小灯(原型的做法)——否决:侧栏不直接放「有什么报错」「有什么新闻」;这些事项归 dashboard,点 dashboard 里的事项进到相应的子页去处理。
3. 内容区顶上一条全站横条,在「采集服务停了」「trocar 挡住了 agent 的网络」时出现——同一句话否决;D38② 要的「在看板上看得到」已由首页 = 总览和采集页满足。

**首页 = 总览,也是侧栏第一项**。理由:侧栏不写状态、又没有横条以后,打开 trocar 第一眼看到的那一屏,是采集失败唯一看得见的地方;D38② 要求失败「在看板上看得到」,不能只靠「没有记录」推出。深链(`#/replay/…`)照常直接打开。没装、也没采到东西时,总览显示「开始使用」([1.7](1.7-overview-dashboard.md))。

**选定 B(回放台):沿用 B 布局。** 左页 = 回放骨,右页 = 叠加翼,两根可调边界,窄屏收起右页。理由:回放台沿用既有设计,中栏放整个上下文。

**备选(未选,沿用)**:① 单页 + 右侧抽屉浮层——叠加翼和回放骨不能同屏并看,违 D2;② 三栏固定等宽——资源翼挤占回放骨,窄屏没法退化;③ tab 切换「回放 / 资源」——撕裂「一条主线承载两目的」(D2)。

**取舍**:导航和状态分开,状态只在总览和采集页。标题位置只放身份,统计放进按钮后面——统计性的话不出现在标题或小标题里(会干扰读者),overall 的统计结果归 dashboard;会话标题也不拿大片地方放总结句,改成一个悬停能看到这些信息的按钮。保真事实不进按钮,留在看得见的一行(不变式 4)。

## 页头与页头区

回放台以外每屏一个页头,从左到右只有三样部件:

| 部件 | 来源 | 说明 |
|---|---|---|
| 屏名,或面包屑 | 固定文字;host 页的面包屑 =「流量 › <agent chip> › <host>」,中段是 agent chip(路由里的 harness 经 `harnessKey()`),末段是路由里的 host | 面包屑的每段是链接 |
| 范围控件 | 路由参数(如 `window`) | 只在这一屏有范围时出现;选项由该屏的单元定 |
| 「数据读于 HH:MM:SS」 | 这一屏最后一次成功读取的本地时间 | 读不新了,按 [1.5](1.5-states-aesthetics.md) 的过期规则显示 |

- **页头区里没有句子,也没有数字**(见 Plan 取舍)。统计、结论、覆盖说明、「不全」说明,都放在它们所说明的那张表或卡片里(表注行)。守卫:`test/web-v2/shell.test.mjs`——每一屏、每一种夹具状态下,页头的 DOM 只由上表三样部件组成;页头和第一张表或卡片之间没有文字节点。
- **新鲜度**:一屏的数据来源混在一起时,页头只说「数据读于」;凡是来自具名查询的数,在它自己那张卡片或表的表注行里带「截至 <as_of>」。守卫:各屏单元的测试(`test/web-v2/overview.test.mjs`、`test/web-v2/traffic-model.test.mjs`;设置页 `web/src/screens/settings/StorageScreen.test.tsx` V9、`web/src/screens/settings/PricesAppearance.test.tsx` P3:「数据读于」是那份答案读到的时刻,重读失败时不往后挪)。
- 回放台没有页头,用会话头(§会话头)。

## 编号:步与调用

- **步** = 主对话 lane 的一次推理调用。「第 N 步」= 它在主对话 lane 里按步序(`src/view/step-order.mjs`)的序号 + 1。步头「第 N / M 步」里的 M = 主对话车道头的 `count`([3.5](3.5-query-layer.md) §会话读),所以骨架还没补齐时 M 也是对的。
- 服务端给的调用引用都是记录 id `rid`(`calls[].rid`、`events[].rid`、`segments[].enter`、`loads[].rid`、车道头的 `spawnRid` / `first` / `last`、`cacheBreak.refRid`,[3.5](3.5-query-layer.md) §会话读);步号由前端从手里的骨架行派生,播放头、选中与打开的行都按 `rid` 拿着,步号只用于显示。一条排在播放头之前的晚到行只改计数,不改显示的内容。不在主对话 lane 里的 `rid` **绝不**显示成「第 N 步」。
- 别的 lane 的一次调用叫「调用」:「<lane 词> · 第 k 次调用」,k = 它在自己 lane 里的序号 + 1;lane 词取 [2.1](2.1-track-widget.md) 的 lane 种类表。要放到轴上时写「约在第 N 步」(`replay/lanes.mjs : nearestByTs()`)。
- `meta.calls` 数的是会话里所有的推理调用(`src/query/rows.mjs : sessionFactsOf()` 的 `isModelCall`)。任何地方都写成「模型调用 N 次」,**不写**「N 步」。
- 换算只有一个函数:`replay/lanes.mjs : stepRef()`(新)。守卫:`test/web-v2/session-head.test.mjs`。

## 弹出层

本节是全站弹出层的约定。用它的有:会话头的 ⓘ(本单元)、步头的缓存 / 组成 / ≈ $ 三个按钮([2.2](2.2-call-turn-card.md))、各屏里的 ⓘ(1.7–1.11)。行为只有这一份:未移植的屏用 `core/ui.mjs : popover()` / `infoButton()`(`installUi()` 接线),React 的屏一律用 `web/src/ui/InfoButton.tsx`(React Aria 的非模态 Popover;某屏要更丰富的层内容时给它加内容槽,不另写一份)。

- **触发**:一个 `<button type="button">`,带 `aria-label`、`aria-expanded`、`aria-controls`。
- **打开**:鼠标悬停 300 ms;键盘聚焦时立刻;点击、Enter 或 Space(点开的会一直开着,直到关掉)。
- **关闭**:Esc(焦点回到按钮);点到外面;悬停打开的,鼠标离开按钮和弹出层两者以后;另一个弹出层打开时(一次只开一个);打开它的那一屏卸下时(§键盘「层随屏走」)。
- **弹出层本身**:`role="dialog"`,`aria-labelledby` 指向它的标题;不是模态,不困住焦点;里面的链接和按钮按 Tab 能到;放在按钮下方,放不下就放上方,左右留在视口内 8 px。
- **内容**:只有文字和链接。弹出层里没有改设置的控件。
- **菜单按钮不是悬停弹出层**:像步头的「对比」([2.2](2.2-call-turn-card.md)),只在点击、Enter、Space 或 ↓ 时打开,`role="menu"`。
- **说明气泡**:全页共用一个(`role="tooltip"`),悬停 300 ms 或聚焦时出现,Esc 关掉;目标挂 `aria-describedby`;本身不能聚焦的目标加 `tabindex="0"`。
- 守卫:`test/web-v2/popover.test.mjs`(字符串层:role、aria 属性、弹出层里的链接可聚焦、Esc 处理已接线);悬停 300 ms、聚焦、点击、Esc、点外面五种行为在 `test/web-v2/browser/`(Playwright,`TROCAR_PLAYWRIGHT`)。

### 会话保真行

会话头下面一行安静的字。至少有一条事实时才出现;每条用平话写,条与条之间用「·」隔开。

| 事实 | 来源 | 字 |
|---|---|---|
| 视图被截短 | `session` 回答的 `truncated{shown, total, kept_mb, file_mb}` | 「只显示了最近 <shown> / <total> 次调用(文件 <file_mb> MB)」 |
| 有记录没有解析器能读 | `session` 回答的 `unknown{records, reason, endpoints}`,`records > 0` 时 | 「<records> 条记录没有解析器能读,没有画出来」;`reason` 与 `endpoints` 照原样放进技术细节 |
| 只记了日志的调用 | `session` 回答的 `logged.count > 0` | 「<n> 次调用只记了日志,不在回放里 ›」→ `#/settings/storage?h=<harness>` |
| 背后的文件没读全 | `session` 回答的 `errors[]`(每条 `where` · `reason`;n = `level` 不是 `'note'` 的条数) | 「有 <n> 个采集文件没读全,这个会话可能缺内容 ›」→ `#/settings/storage`,单复数随 n;n = 0 不画这一行;`level:'note'` 的条目(慢读,如 `index-cold`)不是丢失,不进这一行,只进技术细节;`where` 与 `reason` 照原样放进技术细节(依据:[3.5](3.5-query-layer.md) §会话读「每个回答」的 `errors`;D24) |
| 采集缺口(推测) | `/api/status` 的 `failures.since` 与 `failures.groups[]`(每组 `code` · `count` · `first_ts` · `last_ts` · `harness`,[1.6](1.6-cli.md) C.3)× 会话时间(`session` 的 `lanes` 里主对话车道头的 `first` … `last` 那两行的 `ts`) | 「这段时间采集出过错,读到的范围内可能缺调用(推测)· 采集记录 ›」→ `#/capture/log?h=<harness>` |

- 会话保真行 **MUST** 在有事实时看得见,**MUST NOT** 只放进悬停或按钮里(**必拒隐瞒** · 不变式 4;缺口一条承 D38②)。守卫:`test/web-v2/session-head.test.mjs`——五种事实各一个构造夹具,有事实才出现,没有事实时这一行不存在。
- **采集缺口**怎么判:一个失败组的 `first_ts … last_ts` 和会话时间有重叠,且这一组的 `harness`(经 `harnessKey()`)等于会话的 harness 或者没有 agent,才算。只在会话时间和失败组的窗口(`failures.since` 起,截至现在)有重叠时判;窗口外不判,也不说。读不到采集健康时也不判。任何情况下都不写「没有缺口」。守卫:同上(窗口内外、别的 agent 的失败、读不到三种情况)。
- 采集健康只在打开回放台时读一次,回放台不轮询它(轮询归 [1.5](1.5-states-aesthetics.md))。
- `session` 回答的 `unknown.records` 为 0(整个会话一条可回放的调用都没有)不是保真事实,是空状态,归 [1.5](1.5-states-aesthetics.md) 关键状态矩阵。
- 整个数据源的读取问题(`/api/sessions.source`)不在这里说,在总览的「要处理的事」和会话库的表注里([1.7](1.7-overview-dashboard.md)、[1.8](1.8-session-library.md))。

## 点击与选中文字

依据:读者要能从展开的行里选中、复制文字,选完行不能自己折起;[1.9](1.9-capture-page.md) §页头区「重读不打断人」;[1.7](1.7-overview-dashboard.md) §读取与刷新。

- **① 选中文字不是点击**:一次按下如果造出或改动了选区(拖着选、双击 / 三击选词选段、Shift+点击扩选),它松手时浏览器发的 click 到不了任何处理函数,也没有默认动作(`<summary>` 不开合,链接不跳)。按下之前已经有的选区不算:选区原样留着时点按钮、点行头照常生效。键盘发出的点击(Enter / Space)不受影响。弹出层的「点到外面」(§弹出层)也按这条:拖着选外面的文字不关掉钉住的弹出层。
- **② 行只从行头开合**:可展开的行(采集页、采集记录、上下文窗的格、资源与大纲的组)只有行头的点击开合;点在展开的内容里从不开合,里面的链接、按钮、技术细节照常。
- **③ 轮询重画不毁读者的位置**:一块区的 html 和上次画的一样就不重画;只要读者的选区还在某块区里,轮询就不重画这块区,它保持画时的样子;读者清掉选区(或选区移出这块区)之后的第一次轮询把它画成最新答案。页头的「读取于」是屏上数据的时间:有区因选区留着旧数据时,它停在这些区上次画时的时间,不往前走(依据:不变式 4——不冒充最新)。画完之后,读者展开或折起的技术细节保持读者的状态,焦点回到同一个链接或控件(按得到焦点的那个元素自己的 `id` / `aria-controls` / `href` / `data-copy` 认;它自己一个都没有时才认能得焦点的祖先)。读者自己引起的重画(开关的结果、`?h=` 落点、换筛选、换窗)立刻画。
- 落点:未移植的屏是 `core/ui.mjs : installUi()`(① 的捕获阶段守卫)/ `repaint()`(③)。已移植到 React 的屏(总览 [1.7](1.7-overview-dashboard.md),采集、采集记录 [1.9](1.9-capture-page.md),会话库 [1.8](1.8-session-library.md);流量与 host 页 [1.10](1.10-traffic.md),不轮询,③ 只落在重读上)是:可展开的东西只经 React Aria `Disclosure` 的触发按钮开合(①②:拖选与展开内容里的点击到不了触发按钮);`web/src/ui/useSelectionHold.ts`(③:选区在屏的主区里时先不换上新的回答,「读取于」停在屏上那份回答的时刻,选区离开或读者自己操作时立刻换);以稳定 id 作 key 的组件(③:轮询不重建行,展开态、技术细节与焦点随组件留下)。会话库的行是链接:① 由页面级的 `core/ui.mjs : installUi()` 捕获阶段守卫管,③ 是列表上的 `useSelectionHold`。守卫:验收第 25 条。

## Edge cases

- **没有主对话 lane 的会话**:轴落在第一条 lane 上(`replay/replay.mjs` 取 `main`,没有就取第一条);步头写「<lane 词> · 第 k / M 次调用」;任何地方都不出现「第 N 步」;`step=N` 指这条 lane 的第 N 次调用。
- **只有 token 计数的会话、一条可回放调用都没有的会话**:空状态,归 [1.5](1.5-states-aesthetics.md)。
- **会话不存在或不在列表里**(`sessions` 里没有这一行,且 `session` 答 `meta:null`):就地显示「这个会话不在会话列表里」(`labels/shell.mjs : SESSION_NOT_LISTED`)+ 去会话库的真链接(`<a href="#/sessions">`);不画时间线、轨道与步骤条;不跳走;回放台的计时器不再读,直到读者自己的操作(重试、跳转、换会话)读到它为止。
- **超长标题**:省略号截断,全文在说明气泡;会话头不换行撑破(< 900 px 时项目移进弹出层)。
- **图标载不出**:名字 + 与图标同大的空方框;不显示「未识别」的图形。
- **`localStorage` 用不了**(隐私窗口、被禁):侧栏和边界都按默认,不报错。
- **存进去的边界宽度越界**(换了显示器):读回来时夹取。
- **采集健康读不到**(读不出、网络错):会话保真行不判缺口,也不说没有缺口。
- **视图被截短**:保真行说截短;弹出层写明只算了显示的调用。**翻页的会话**:弹出层仍覆盖全部调用。
- **一个会话里有几种线格式**(`provider:'mixed'`):不是「多个 agent」(D37 ①)。
- **同一个会话 id 下混了几个 harness 的记录**(会话现在只按 id 分组):`sessions` 的多 harness 字段 以后 chip 标「多个 agent」;改成按 (harness, id) 分组是 [3.4](3.4-session-identity.md) 的后续。
- **`call=` 指向的调用在一条还没到手的车道里**:播放头先按 `rid` 落到那次调用,画法按 [2.3](2.3-context-window.md) §车道未到手(先保留已画的行,再画它自己骨架里的元数据与按组成定好大小的空框),车道到了就地填上;没有载入控件。
- **认不出的路由**:总览 + 提示。

## Risk / 回滚

- 侧栏、路由、页头都是纯前端,可以按文件回退。
- 图标是数据行:去掉一个图标文件,chip 退回「名字 + 空方框」,不会认错 agent。
- 风险:官方标志的商标与许可。SOURCES.md 逐个记商标归属、出处与再分发条款;没找到明文条款的照用(D76②),条款明文不许再分发或厂商要求撤下的换成 trocar 自绘图形,只改那一个文件与它的 SOURCES.md 行。
- 风险:首页改成总览后,习惯从会话库开始的人要多点一下;深链不受影响。
- 风险:砍掉同名猜测后,真的分叉了的会话不再有提示。3.4 的 fork 树有数据以后,在 Extensions 里接回确证的血缘(不是猜测)。
