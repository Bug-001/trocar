# trocar · RFC 2.5 — 右侧栏 Overview

> **服务意图(A2)**:意图 ①:这场会话一共分几章,每章里有什么,一点就到;兼意图 ② 的轻钩(有变化线时一行「Jump to the change」)。
> **受众**:人(按章找一条提问、一个子 agent、这一步的某段系统提示);agent(据 head 的 `chapters`、车道头、`lane` 的事件与块列表生成条目,**不重解析原始请求、不回退 provider 专属分支**)。
> **前置**:章的边界 = [1.3](1.3-timeline-tracks.md) §章;宿主 = [1.2](1.2-shell-layout.md) §回放台布局的右侧栏;跳转目标 = [2.3](2.3-context-window.md)(`.cblk[data-bi]` · `#cachebrk`);缓存状态 = [2.2](2.2-call-turn-card.md);「第 N 步」= [1.2](1.2-shell-layout.md) §编号;词表 = [1.5](1.5-states-aesthetics.md);提问认定 = [4.4](4.4-server.md) `sessions` 的 `title_source`;资源 = [2.4](2.4-resource-explorer.md)。

## Goal
一章一行。当前章自动展开,展开后列这一章的 Tools、System prompt、Prompts、Sub-agents,这一步有变化线时多一行 Jump to change,点任一条跳到那一步或那一块。它只是导航投影,逐字真相在窗口。

## 定义
- **章**:[1.3](1.3-timeline-tracks.md) §章,来自 head 的 `chapters`。
- **这一章读的步**:当前章读播放头那一步,别的章读它的第一步。Tools、System prompt、Jump to change 都是这一步的。
- **当前章**:播放头所在的章。

## 画什么

| 元素 | 何时出现 | 来源 |
|---|---|---|
| 章行:名字 · 步区间 · 时间 | 多于一章时,一章一行 | `W.partName(k, inferred)`;`s0 + 1`–`s1`;`ts0` 经 `fmtWhen()` |
| 章头的 X → Y | 这一章由一次压缩打开 | 落地步的 `compaction-landed` 事件(真实数字);没有这个事件时不画 |
| 组「Tool definitions」:工具名 · 「MCP」 | 章展开时 | 这一章读的步的 `flat[]`(`sec = tools`) |
| 组「System prompt」:名字 · 缓存标记字形 · 每次都变字形 · 字符数 | 同上 | `flat[]`(`sec = system`) |
| 组「Prompts」+ 个数:提问 · 「step N」 | 同上 | 主对话车道这一章步区间里 `type:'user'` 的事件(`preview`、`rid`,N 经 `stepRef()`);这条线没有这种事件时取这一章读的步的 `flat[].query`,不写步号,`queryBasis:'guess'` 的带「推测」 |
| 组「Sub-agents」+ 个数:任务 · 调用次数 | 这一章有子 agent 时 | `kind:'subagent'` 的车道头(`task`、`count`),按第一次调用的时间归章;`task` 为空写 lane 词 |
| 「Jump to the change ›」 | 这一章读的步有变化线 | 与窗口同一判定(`QUIET_CAUSES`) |
| 一行原因 | 这一章读的步解析不出 / 没有请求 | `unparsed` · `rec` |

- 只有一章时不画章行,这一章的组直接列。
- 当前章自动展开,读者动过的章按读者的:`open = current !== flipped`。组的开合全台一份;默认 Prompts、Sub-agents 开,另外两组合。都不随轮询变。
- 这一章读的步车道未到手:组里是定好大小的空行(`aria-busy="true"`),不写 0;子 agent 的第一行没到手时归不了章,这时 Sub-agents 的个数是空框,不写半截的数;这一章的步没到全时 Prompts 的个数也是空框,已到的行照列。

## 跳转
- 工具、系统提示、没有事件时的提问:这一章读的步上的块序 `fi`。当前章 `jumpToBlockIndex()`;别的章 `s.jumpTo(step, fiJump(fi))`,等车道时走跳转队列。落到折叠提问卡里的块先展开卡(规则同 [2.3](2.3-context-window.md))。
- 提问事件:`s.jumpTo(step, promptJump())`,落到那一步最后一条提问块。
- 子 agent:与点叠加轨上它的第一次调用同一个动作(`selectTick()`,[2.1](2.1-track-widget.md))。
- Jump to the change:`anchorJump('cachebrk')`。
- **条目与窗口读同一份 `flat[]`**,所以点条必落对块。

## 保真边界(承不变式 4,[0.0](0.0-overview.md) §核心不变式 · 必拒隐瞒)
Overview 显示的是**派生导航投影**——`label` / 提问预览(服务端剥掉注入内容、折空白,`query` 至多 90 字,事件的 `preview` 至多 200 字)/ 字符数 / 计数,**非线上 payload 逐字**;它是**导航层**,同会话头([1.2](1.2-shell-layout.md))。逐字真相在窗口([2.3](2.3-context-window.md))。故:
- Tool definitions 组只列**名字**——因为 Overview 是**导航投影**(逐字 schema 在 [2.3](2.3-context-window.md) 窗口),**非**因为没采集;D15 后 schema 逐字捕获(`faithfulness=verbatim`,仅 pre-D15 老 trace = metadata)。**MUST NOT** 让工具条看着像完整工具定义。守卫:验收 #2。
- 提问预览是截断/折空白的**摘要**,**MUST NOT** 让人误以为是块全文;点条落窗口才见逐字(且非 verbatim 块在窗口就地标 faithfulness)。守卫:验收 #2。
- 无需在每条 Overview 条目逐字标注(它本就是导航投影),但 **MUST NOT 让这些投影看起来像线上原始字段**。守卫:验收 #2 + 收尾审查。
- 认不准的东西不写成事实:`queryBasis:'guess'` 的提问行带「推测」;没有提问事件的线不写步号;车道未到手、解析不出来的一步,组下不列条目,不写 0,解析不出来时给一行原因(守卫:验收 #2、#4)。

## 只做导航(MUST)
不出现中栏已有的计数(工具定义 N 个、系统提示 N 块、缓存命中 N%)。除了提问与子 agent 的个数、步号、步区间、调用次数、字符数、压缩的 X → Y 没有别的数字。条目被截断时带 `title`。

## 跨 provider 泛化(承 3.1/3.2)
demo 只跑 Anthropic、且每步现解析 `linearContext(call.rec.request)`、cache % 直读 Anthropic 原生字段名(`cache_read_input_tokens` 等)。**产品改从归一化块列渲染**:分组读 `flat[].sec`(tools/system/messages;Codex `instructions`→system、`input[]`→messages 已由 dissector 归一,`src/dissect/openai.mjs : boardFlat()` / `boardFlatChat()`)、`role`/`kind`/`label`/`name`/`mcp`/`cc`/`volatile`/`query`;「Jump to the change」读服务端的 `cacheBreak.cause`(闭合枚举,与线格式无关)。→ **加 provider 只加 adapter,Overview 零改**(AC-3:前端主干 = `web/` 下的全部文件,[1.1](1.1-product-definition.md))。「step N」靠的提问事件只有 Anthropic 线有(openai 线的 `events` 除压缩外为空),那时只是不写步号;前端不按线格式分支。

## 验收(可跑 check)
1. **章**(`test/web-v2/overview-model.test.mjs`):生成的多章会话上,章行数 = `chapters` 条数,步区间与 `s0`、`s1` 相等;当前章 `open` 真、别的假;换到别的章,新的当前章开、旧的合;读者动过的章跨换步留着;只有一章时没有章行。
2. **条目与跳转**(同上):当前章的工具、系统提示行 = `outlineEntries(s)` 的行;每个 `jump` 落在那一步的块序内;别的章读它的第一步;提问行数 = 这一章步区间里 `type:'user'` 的事件数,步号经 `stepRef()`;没有这种事件的线上提问行来自 `flat[].query`,没有步号;子 agent 归第一次调用所在的章,每条子 agent 车道恰好在一章里。
3. **Jump to change**(同上):出现 iff 这一章读的步 `hasChangeLine()`。
4. **代替态**(同上):车道未到手 → `kids` 为 `null`;解析不出 / 没有请求 → 有原因、没有条目;有子 agent 的第一行没到手 → `agents.partial` 真。
5. **真点**(`test/web-v2/browser/seq/`):序列动作「点 Overview 的一行」之后,不变式 I-jump:播放头或窗口的高亮落在那一行点名的步与块上;拖选文字不开合。
6. **D64**(`test/web-v2/browser/step-perf.test.mjs`,`--desk-next`):Overview 开着时换步线不变。

## Edge cases
- **没有主对话 lane**:章只有一条,不写步号。**压缩步**:Tools 仍是这一步的。**第一次调用**:没有变化线。**超长工具列表**:组折着。
